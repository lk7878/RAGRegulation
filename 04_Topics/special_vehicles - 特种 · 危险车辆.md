# 特种 / 危险车辆（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

本主题（47 notes，ECE=22, CN=24, AU=1）覆盖 **非标准乘用/商用车** 的特定安全法规，包括危险品运输车、大客车整车安全、农林机械、工业车辆、拖拉机和摩托类。

**① 危险品运输专用车辆**
- `ECE R105`：N 类 + O2/O3/O4 类危险品运输车辆特殊结构（电气、防火、制动、限速）
- `GB 21668-2008 / 2025`：危险货物运输车辆结构要求（2025 版大改，含 EV 专项）
- `GB 36220-2018`：运油车辆和加油车辆安全技术条件
- `GB 20300-2018`：爆炸品/剧毒化学品运输车辆

**② 大客车整车结构**
- `ECE R55 / R55 Rev.1 / R55 Rev.2`：机械联结装置（主要为牵引大客车和挂车）— 本主题修订最密集 ECE（Am1–Am12 连续）
- `ECE R111`：罐式商用车侧倾稳定性
- 国内：`GB 28373-2012`（N 类/O 类罐式侧倾稳定）

**③ 农林机械与拖拉机**
- `GB 7121-1986`：农林轮式拖拉机防护装置强度（等效 ISO 3463/5700）
- `GB 15369-1994`：农林拖拉机安全技术要求
- `GB 1593.4-1987`：农用轮式拖拉机三点悬挂装置
- `GB 18447.2-2001`：手扶拖拉机安全要求

**④ 工业车辆 / 特种车辆**
- `GB 10827-1999`：自行式工业车辆安全要求（叉车等）
- `GB 25684.11-2010`：土方机械 — 回填压实机
- `GB 13954-2004`：特种车辆标志灯具（警车/消防车/救护车）
- `GB 16279-1996`：消防车定型试验

**⑤ 电动自行车**
- `GB 17761-1999`：电动自行车通用技术条件（后续由 GB 17761-2018 代替，本库仍保留 1999 旧版）

**⑥ 澳大利亚 ADR 体系**
- `ADR` 索引：澳大利亚设计规则（Australian Design Rules）总目录

**跨区域速查**：
- `GB 21668` + `GB 36220` + `GB 20300` ≈ `ECE R105` + `ADR 系列`（危险品运输）
- `GB 28373` ≈ `ECE R111`（罐式车侧倾稳定）
- `GB 7121` 等效 ISO 3463/5700，对应 `ECE R167`（拖拉机前翻保护）

> 注：部分记录（工业车辆、消防车 / 农林设备）并非严格 "汽车" 法规，但因共享交通 / 车辆监管框架被聚类到此。
