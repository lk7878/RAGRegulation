# 排放与燃料（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

排放与燃料主题包含两条并行主线：**污染物排放**（NOx/HC/CO/PM）与 **CO2/燃料消耗量**（能效管理）。共 98 notes（ECE=82, CN=15, US=1），其中 ECE 以 `R49/R83/R101` 三巨头为核，国内则由 `GB 18352`（轻型汽油）、`GB 17691`（重型柴油）、`GB 19578/20997/30510`（燃料消耗量）四线分治。

**① 尾气污染物排放（传统）**
- `ECE R49`：压燃/点燃发动机污染物排放（重型商用车，对应 Euro VI），本主题修订最密集的 ECE 之一
- `ECE R83`：轻型车型式认证污染物排放（对应 Euro 5/6）
- `ECE R115`：LPG/CNG 改装后系统排放认证
- 国内对应：`GB 18352.6-2016`（国六轻型）、`GB 17691-2018`（国六重型）、`GB 14762`（非道路移动机械）

**② CO2 与燃料消耗量（能效 / 双积分）**
- `ECE R101`：乘用车 CO2 排放与能耗测定（WLTP 协议）— 本主题最大 ECE 标准簇，Am1–Am10 持续跟进 WLTP 更新
- 国内：`GB 19578`（乘用车 CAFC 限值，最新 2024）、`GB 20997`（轻型商用车 CAFC）、`GB 30510`（重型商用车 CAFC）
- 测试方法：`GB/T 19233`（碳平衡法）

**③ 蒸发 / 曲轴箱 / OBD**
- `ECE R83` 附件：蒸发排放测试
- `GB 11340-2005`：点燃式发动机重型车曲轴箱污染物（等效 US EPA 40CFR)
- OBD 诊断：混入 R49/R83/R115，国内 `GB 18285-2018`（在用车排放 OBD）

**④ 专项 / 美国体系**
- `R103`：催化转化器更换件认证
- `FMVSS / CFR 40` 美国联邦体系：由 `FMVSS Series` 汇编 note 单独索引

**⑤ 重点演进**
- 2017–2018：Euro VI-C/D (`R49 Rev6 Am5/6`)、WLTP 切换 (`R101 Rev3 Am1+`)、国六发布
- 2020–2022：`GB 19578-2021`（五阶段油耗）实施，企业 CAFC + NEV 双积分并行
- 2024：`GB 19578-2024 / GB 20997-2024` 六阶段燃耗，限值显著加严 (-15%)
- 2023+：R101 Rev4 / 新增电动及混动 CO2 合规规范

**跨区域速查**：
- `GB 18352` ≈ `ECE R83` + `Euro 6/6d`
- `GB 17691` ≈ `ECE R49` + `Euro VI`
- `GB 19578` ≈ `ECE R101` + `EU 2019/631`
- `GB 30510` 是国内独有重型 CAFC，ECE 无直接等效
