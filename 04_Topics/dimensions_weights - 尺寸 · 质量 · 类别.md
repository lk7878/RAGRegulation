# 尺寸 / 质量 / 类别（Topic Index）

## Overview

尺寸 / 质量 / 类别主题（17 notes，ECE=3, CN=14）关注 **整车外廓限值 + 行李舱容积 + 车辆分类基础定义**，是国内道路运输管理的技术底线。

**① 外廓尺寸与质量限值**
- `GB 1589-2016`：汽车、挂车及汽车列车外廓尺寸、轴荷及质量限值 — 国内核心，上位监管 "大吨小标" 问题
- `ECE R111`：罐式商用车侧倾稳定性（与尺寸 / 质量相关，也在 `special_vehicles`）

**② 车辆运行安全基础**
- `GB 7258-2017` / `GB 7258-2017/XG1-2019`：机动车运行安全技术条件 — 国内最重要的综合性底线，覆盖所有机动车及挂车
- 包含灯光、制动、转向、噪声、排放多个维度的最低要求

**③ 车辆分类与外部凸出物**
- `GB 11566-2009`：乘用车外部凸出物（M1 类外部安全）— 对应 `ECE R26`（在 `interior_protrusions` 主题）

**④ 行李舱 / 内部容积**
- `GB/T 19514-2004 / 2024`：乘用车行李舱标准容积测量方法 — 给三方市场认知提供基准
- `GB/T 19515-2023`：乘用车室内尺寸（H 点和乘员空间）

**⑤ 牵引装置**
- `GB 32087-2015`：轻型汽车牵引装置
- `GB/T 43402/43405-2023`：商用 / 拖挂牵引装置新近发布

**跨区域速查**：
- `GB 7258` 无 ECE 直接对应（国内综合底线标准，ECE 体系按功能分散）
- `GB 1589` ≈ `EU 96/53/EC`（欧盟尺寸质量指令）
- `GB 11566` ≈ `ECE R26`（外部凸出物）
- `GB/T 19514/19515` 参考 `SAE J1100` + `ISO 3832`
