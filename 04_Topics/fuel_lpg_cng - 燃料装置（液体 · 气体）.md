# 燃料装置（液体 / 气体）（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

燃料装置主题（26 notes，ECE=22, CN=4）涵盖 **液体燃料油箱 + 气体燃料 (LPG/CNG/LNG/H2) 储存与改装** 两大类。与 `emissions_exhaust` 主题紧密关联（R115 LPG/CNG 改装排放测试在此）。

**① 液体燃料油箱与防火**
- `ECE R34`：车辆火险预防措施（油箱安装 + 电气装置 + 前/后碰撞试验 + 塑料油箱特殊试验）— 误分类至 `lighting_signaling`，实属本主题
- `GB 18296-2019`：汽车燃油箱及其安装的安全性能要求和试验方法（对应 R34 油箱部分）

**② LPG 系统**
- `ECE R67`：LPG 专用设备 + 整车安装（Part I 部件，Part II 整车）
- 近年 Rev6 (2023) 引入新型 LPG 组件认证流程

**③ CNG 系统**
- `ECE R110`：CNG / LNG 专用设备 + 整车安装 — 本主题 Rev6 + Am1+ 多轮更新

**④ LPG/CNG 改装后排放**
- `ECE R115`：改装系统排放测试（对接 R83/R101/R49 基础法规）— Rev1 Am1–Am4 跟进 WLTC/RDE 测试

**⑤ 氢燃料**
- `ECE R134`：氢燃料电池车辆（HFCV）— 含高压氢系统安全 + 碰撞后泄漏限值 + CHSS 容器认证
- 国内：`GB/T 24549`（氢燃料电池电动汽车安全要求）— 本库未收录

**⑥ 国内合并标准**
- `GB 19239-2013 / 2022`：燃气汽车燃气系统安装规范 — **一条标准覆盖 CNG/LNG/LPG 三种气体燃料**（代替 GB 19239-2013 + GB/T 20734-2006）
- `GB 17259 / GB 17258`：车用 LPG 钢瓶 / CNG 钢瓶技术要求

**⑦ 重点演进**
- 2017–2018：R110 接入 LNG（液化天然气）相关条款，适应物流车 / 重卡需求
- 2020：R115 引入 WLTC 改装后测试方法
- 2022：`GB 19239-2022` 发布，国内气体燃料汽车首次统一要求
- 2023：R67 Rev6，R134 Am5（CHSS 氢瓶新试验）
- 2024+：R134 接入氢内燃机（HICE）支线，国内同步起草

**跨区域速查**：
- `GB 19239` ≈ `ECE R67 + R110`（气体燃料合并）
- `GB 18296` ≈ `ECE R34 油箱部分`
- `GB 17258 / 17259` ≈ `ECE R67 / R110 Part I`（气瓶 / 阀件）
- 氢燃料电池：`GB/T 24549` ≈ `ECE R134`（国内在 GB/T 标准化，未上升强制）
