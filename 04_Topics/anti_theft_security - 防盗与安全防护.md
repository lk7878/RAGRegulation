# 防盗与安全防护（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

防盗与安全防护主题（40 notes）涉及 **未经授权使用防护 + 车辆警报系统 + 防盗器 + 运输专项车辆安全**。ECE 以 `R18/R62/R97/R116` 四条为核，国内以 `GB 15740` 为主，同时捕获欧亚经济联盟 TR CU 体系入口。

**① 乘用车防盗**
- `ECE R18`：机动车防止未经授权使用（转向柱锁、变速器锁等机械装置）
- `ECE R116`：整车防盗 + 警报系统 + 防盗器统一法规（本主题最活跃 ECE，Am1–Am10 持续完善数字钥匙、智能卡、TPMS 集成）
- `ECE R97`：车辆警报系统（VAS）+ 装有警报的汽车（AS）+ 独立防盗器认证
- 国内：`GB 15740-1995 / 2006`（汽车防盗装置，1995 针对 M1；2006 扩展）

**② L 类防盗（摩托车）**
- `ECE R62`：带方向把机动车防止未经授权使用（两轮 + 三轮 + 边车）

**③ 运输安全专项（跨主题）**
- `GB 36220-2018`：运油车 + 加油车辆（与 `special_vehicles` 重叠）
- `GB 20300-2018`：爆炸品 + 剧毒化学品运输车辆

**④ 国家 / 联盟认证体系**
- **俄罗斯 / 欧亚经济联盟**：`TR CU 018/2011` 轮式车辆安全性技术法规（EAEU 统一认证 OTTC），包含噪声/视野/碰撞/GLONASS 定位等一揽子要求 — 2 条 notes 属 `ru-eaeu`
- **韩国 / 独立条款**：1 条 `kr` note

**⑤ 重点演进**
- R116 演进脉络：2005 整合发布 → 2017 Am7 引入远程无钥匙系统防重放 → 2021 Am8 相互认证条款 → 2024+ 数字 UWB 钥匙
- 国内 `GB 15740` 已**明显滞后**（最新 2006 版），与 ECE R116 差距约 10+ 年，应关注修订动向
- `TR CU 018` 是国内企业出口俄罗斯 / 哈萨克斯坦 / 白俄罗斯的必经关卡，近年因地缘动荡高频修订

**跨区域速查**：
- `GB 15740` ≈ `ECE R18 (机械防盗部分)` + `R97 (警报部分，国内合并)`
- `TR CU 018` 是复合体系，涉及本库多数主题，单独作为 `ru-eaeu` 顶层认证框架索引
