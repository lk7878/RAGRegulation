- `GB/T 12676`：商用车及挂车制动 ABS 系统试验（在 `brakes`）
- `GB/T 38796`：汽车操稳试验 / ESC 测试（在 `brakes`）

**④ 演进规律**
- **1990 版**：基础建立，测量工具以机械 / 模拟仪表为主
- **2010 年代**：更新到 GPS + 惯性测量 (IMU)，测量精度大幅提升
- **2020+**：新能源汽车适配（续航 / 能耗替代油耗、热管理扩展到电池）
- 2023 / 2024 大批修订：`GB/T 12538 / 12540 / 12541 / 12542` 全系列对齐 ISO 最新版

**⑤ 国际对标**
- 基础对齐 **ISO 611 / ISO 1176 / ISO 2416 / ISO 4138 / ISO 15037** 系列
- ECE 体系下试验方法分散在各 R 号附件中，国内 GB/T 系列独立成编更便于工程师查询
- SAE 对应 J 系列（如 SAE J1263 等）

**跨区域速查**：
- `GB/T 12540` ≈ `ISO 14792 + ISO 14793` + ECE R79 附件 1 转弯半径
- `GB/T 12534-12547` 整体 ≈ 无 ECE 直接等效，EU 法规通过 2018/858 指向 ISO
- 发动机性能：`GB/T 18297` ≈ `ECE R24`（在 `engine_power_performance`）
