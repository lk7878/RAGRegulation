# 营运 / 商用车管理（Topic Index）

## Overview

营运与商用车管理主题（20 notes，ECE=11, CN=9）聚焦 **商用车 / 营运车辆运营阶段的安全与防护**，与 `crash_impact` 主题互补（后者偏整车碰撞测试，本主题偏营运期装备与综合性能）。

**① 侧下部 / 前下部 / 后下部防护**
- `ECE R58`：商用车后下部防护装置（N2/N3/O3/O4）— Rev2/Rev3 Am1–Am3 持续修订
- 国内：`GB 11567-2017` 侧面 + 后下部（`crash_impact`）、`GB 26511-2011` 商用车前下部

**② 在用营运车辆**
- `GB 18565-2001 / 2016`：道路运输车辆综合性能要求和检验方法 — 国内运输行业主管部门（交通运输部）在用车检验依据，覆盖制动 / 转向 / 灯光 / 排放 / 噪声等综合项

**③ 牵引与联结装置**
- `GB/T 28948-2012`：商用车辆前端牵引装置
- `ECE R55`（在 `special_vehicles`）：机械联结装置 → 跨主题关联

**④ 车辆类型定义**
- `GB/T 3730.1-2001`：汽车和挂车类型的术语和定义（国内行业基础定义）
- `GB/T 15089`：车辆分类（M/N/O/L，国内版 ECE R3730 对应）

**⑤ 客车专项（部分归 bus_coach）**
- `GB 17578-2013`：客车上部结构强度（`crash_impact` 也收录）

**跨区域速查**：
- `GB 18565` 无 ECE 直接对应（在用车检验属营运监管，各国自管）
- `GB 26511` ≈ `ECE R58 后下部` 的镜像（前下部 vs 后下部）
- `GB/T 3730.1` + `GB/T 15089` ≈ `ECE R3730` 车辆分类
