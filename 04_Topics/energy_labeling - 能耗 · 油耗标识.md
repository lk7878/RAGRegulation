# 能耗 / 油耗标识（Topic Index）

## Overview

能耗 / 油耗标识主题（5 notes，全 CN）是 **国内消费端能耗信息公示的法规域**，与 `emissions_exhaust` 的 CAFC 管理形成 "生产端 + 消费端" 双轨。

**① 轻型汽车油耗标识**
- `GB 22757.1-2017 / 2023`：轻型汽车能源消耗量标识 第 1 部分：汽油和柴油汽车 — **强制性**，新车销售需张贴油耗标签
- 数据源：`GB 19578` 型式认证值
- 标识内容：综合工况油耗 + 市区 + 郊区工况 + CO2 排放

**② 重型车能耗标识**
- `GB 27887`：重型商用车能耗标识（部分年份未收录）— 较新发布
- 数据接入 VECTO 或国内 CHTC 重型车工况

**③ 新能源汽车能耗**
- 电动 / 插混 / 氢燃料电池：逐步纳入标识框架（`GB 22757.1-2023` 已含相关章节）

**跨区域速查**：
- `GB 22757.1` ≈ `EU 1999/94/EC` + 各成员国实施细则
- `ECE R101` 给出油耗测定数据，但欧盟各国自定义标签形式
- `US EPA Fuel Economy Label` 另一体系，未在本库
