# 摩托车 / L 类（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

摩托车 / L 类车辆主题（18 notes，ECE=7, CN=11）汇集了 **摩托车专用法规**。国内一套相对独立的 GB 体系与 ECE 平行，但两者对应关系清晰。L 类含 L1/L2（轻便摩托）、L3/L4（两轮摩托 + 边车）、L5/L6/L7（三轮 / 微型四轮）。

**① 整车性能**
- `ECE R72`：摩托车白炽灯前照灯 / 近远光（配合 R57 / R113）
- `ECE R60`：摩托车和轻便摩托车操纵件、信号装置位置（Rev1 最新）
- 国内：`GB 15365-2008`（操纵件 / 指示器 / 信号装置图形符号）

**② 摩托车专用零部件**
- 防盗：`GB 17353-2014`（摩托车和轻便摩托车防盗装置）（对应 `ECE R62`，在 `anti_theft_security`）
- 喇叭：`GB 15742-2019`（含摩托车喇叭性能及装车要求）
- 前照灯：`GB 5948-1998`（白炽丝光源前照灯配光）、`GB 16897-2022`（制动软管含摩托）

**③ 噪声与油耗**
- `GB 16169-2000`：摩托车和轻便摩托车加速行驶噪声限值（对应 `ECE R41`/`R63`，在 `noise`）
- `GB 15744-2008`：摩托车燃油消耗量限值
- `GB 16486-2008`：轻便摩托车燃油消耗量限值

**④ 外部凸出物**
- `GB 20074-2017`：摩托车和轻便摩托车外部凸出物

**⑤ 后视 / 视野**
- `GB 17352-2010`（在 `brakes` 主题，实为后视镜）：摩托车和轻便摩托车后视镜

**⑥ 重点演进**
- 国内摩托车 2008 大修订年（`GB 15365/15744/16486` 同期发布，国 III 排放阶段同步）
- 2017–2019：国 IV 排放 `GB 14622`（在 `emissions_exhaust`）+ 整车法规同步修订
- 2020+：电动摩托车 (`GB 24155-2020`) 快速崛起 → 见 `electronics_emc`

**跨区域速查**：
- `GB 15742` ≈ `ECE R28`（喇叭）
- `GB 17353` ≈ `ECE R62`（L 类防盗）
- `GB 16169` ≈ `ECE R41`（摩托噪声）
- `GB 20074` ≈ `ECE R26 附件` 摩托外部凸出物
- 摩托车前照灯：`GB 5948 / 16897` ≈ `ECE R57 / R72 / R113`
