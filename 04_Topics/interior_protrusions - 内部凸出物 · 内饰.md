# 内部凸出物 / 内饰（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

内部凸出物与内饰主题（13 notes，ECE=10, CN=3）关注 **乘员舱内部安全边界**：凸出物角度 / 圆角半径 / 能量吸收材料 / 电动车窗自动反向、内饰材料燃烧性等。

**① 内部凸出物核心**
- `ECE R21`：车辆内部装备（乘员舱内部构件 + 仪表板 + 电动车窗 + 天窗）— Rev2 Am1–Am3 持续修订
- 关键要素：5mm 以上尖锐点需圆角半径 ≥2.5mm、能量吸收测试、电动关窗反力限值
- 国内：`GB 11552-1999 / 2009`（乘用车内部凸出物，最新 2009）

**② L 类 / 三轮车专项**
- `ECE R61`：商用车外部凸出物（N 类驾驶室前方）— Am1/Am2 更新

**③ 内饰材料阻燃性**
- `GB 8410-2006`：汽车内饰材料的燃烧特性 — 国内独有完整标准，代替 GB 8410-1994；覆盖 M1 乘用车及客车内饰
- ECE 对应：`ECE R118`（在 `bus_coach` 主题）针对客车内饰燃烧

**④ 重点演进**
- 电动车窗反力限值（R21 Rev2 Am1）— 防夹手指事故
- 2020+：R21 针对智能座舱大屏、硬件突出物的新关注点

**跨区域速查**：
- `GB 11552` ≈ `ECE R21`（乘用车内部凸出物）
- `GB 8410` ≈ `US FMVSS 302`（非 ECE 对应，国内参考美国体系）
- `ECE R61` 无国内直接对应（国内 N 类外部凸出物含在 `GB 7258` 总则中）
