# 总体型式认证 / 通用要求（Topic Index）

## Overview

本主题（22 notes，ECE=16, EU=3, CN=2, ZA=1）聚焦 **整车型式认证的框架性法规**，不涉及具体零部件或性能，而是规定 **认证流程、车型分类、机构资质、一致性证书 (COC)** 等顶层要求。

**① 框架性认证文件**
- `ECE R0`：1958 年协定下的整车型式认证框架（Rev3/Rev4 持续更新车辆类别定义）
- `ECE R122`：M、N、O 类车辆采暖系统认证 — 与整车框架挂钩的典型子法规（Am1–Am6 持续完善电暖系统、余热回收）

**② 地区性入市框架**
- **EU**：`2007/46/EC`（框架指令，2018 后被 EU 2018/858 取代）— 定义欧盟整车型式批准 (WVTA) + 一致性证书 COC + 生产一致性 PoCoP
- **ASEAN**：东盟汽车市场技术法规指南（`ASEAN-UNKNOWN` 汇编）— 各国渐进采纳 ECE 清单
- **南非**：NRCS 管理 + SANS 标准体系（VC 系列技术规范）

**③ 国内准入**
- `GB 15084` 等具体法规 → `CCC 认证`（强制性产品认证 `certification_admin` 主题）
- 工信部 CMVR 准入 → 公告管理 `公告管理办法` + 生产一致性监管（国内独有）

**跨区域速查**：
- 国内 CCC + 公告 ≈ `ECE 1958 协定` 下的 E-mark + 附录
- `2007/46/EC` ≈ `ECE 1958 + 1998 协定` 双轨合并（欧盟视角）
- 南非 SANS ≈ `ECE 法规等同采用`（非成员但参照）
- 东盟：2020+ 进入 "渐进接受 UN R" 阶段，各国节奏不同（泰国 / 马来西亚较早，越南 / 印尼较晚）
