# 挂车 / 联结装置（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

挂车 / 联结装置主题（2 notes，ECE R102）专注 **牵引车-挂车机械/液压联结装置**。本主题与 `special_vehicles` 主题的 `ECE R55`（整体牵引装置）形成互补：R55 偏 M/N 牵引设计通用要求，R102 专注 **近距离联结装置（CCD）** 特种挂车场景。

**① 核心法规**
- `ECE R102`：A 型紧密连结装置（Close-coupling Device, CCD）及装有 CCD 的车型认证 — 用于重型牵引 + 挂车（N3-O4）形成准刚性列车
- `ECE R147`：（未收录本库，在修订中）农业拖拉机 + 挂车联结装置

**② 与其它主题关系**
- `special_vehicles` → `ECE R55`：牵引装置通用（五轮 / 牵引球 / 牵引销）
- `dimensions_weights` → `GB 1589`：汽车列车外廓 / 轴荷限值（联结后整体）
- `commercial_operations` → `GB/T 28948`：商用车前端牵引装置

**③ 国内对应**
- `GB 4606`：重型牵引鞍座（Fifth-wheel Coupling）
- `GB 15083`：乘员座椅（在 `restraints_airbags`）— 提到座椅锁止机构，非联结装置

**跨区域速查**：
- `GB 4606` ≈ `ECE R55 第 II 部分`（牵引鞍座 / Fifth Wheel）
- 紧密连结装置 `ECE R102` 无国内直接对应（国内 CCD 使用率远低于欧洲物流车）
