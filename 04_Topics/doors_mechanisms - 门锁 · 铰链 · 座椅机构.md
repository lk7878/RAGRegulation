## Overview

门锁 / 铰链 / 座椅机构主题（7 notes，ECE=5, CN=2）聚焦 **车门锁具强度**，是碰撞防护中 **乘员不被抛射** 的关键环节。

**① 车门门锁与铰链**
- `ECE R11`：汽车门锁及车门保持件认证（Rev3 Am1 最新 2019-06 发布）— 纵向负荷 / 横向负荷 / 惯性负荷、安全弹开测试
- 国内：`GB 15086-1994 / 2013`（门锁 + 门铰链性能 + 试验方法）

**② 全球技术法规 GTR**
- `UN GTR No.1`：门锁和门保持件 — WP.29 首批全球技术法规之一，GTR 框架下国家自愿转化

**③ 座椅机构**
- 头枕 / 座椅固定 / 座椅强度 → 在 `restraints_airbags` 主题
- 本主题只保留门相关

**④ 与 `crash_impact` 的关联**
- 侧面碰撞 R95 / 后碰撞 R32 / 正面 R94 测试中，要求车门不得脱开
- 大客车紧急门：`ECE R107 附件`
