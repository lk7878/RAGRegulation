# 轮胎与车轮（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

轮胎与车轮主题覆盖 **轮胎产品认证 + 车轮性能 + 防飞溅与滚阻噪声** 三条主线（103 notes，ECE=85, CN=18）。核心 ECE 为 `R30/R54/R64/R106/R108/R117`，国内以 `GB 518/9743/9744/36581` 对应。

**① 轮胎产品认证（按车辆类型）**
- `ECE R30`：乘用车 / 轻载充气轮胎（M1/N1）— 本主题最基础法规
- `ECE R54`：商用车及挂车充气轮胎（C 型，N2/N3/O3/O4）
- `ECE R64`：应急备胎 / T-type
- `ECE R106`：农业 / 林业 / 拖拉机用轮胎（近年 Am5–Am10 修订密集）
- `ECE R75`：摩托车轮胎
- 国内：`GB 518-2020`（摩托车）、`GB 9743`（轿车）、`GB 9744-2015`（载重）、`GB/T 2978`（轿车配合 GB 9743）

**② 特种轮胎 / 翻新件**
- `ECE R108`：乘用车翻新轮胎（retreaded）
- `ECE R109`：商用车翻新轮胎
- 雪地 / 特殊用途：R30 Rev3 Am5、R108 Am4（阿尔卑斯符号），R117 Rev4 Am6（ice grip 冰面抓地）

**③ 车轮（轮毂）**
- `GB 36581-2018`：汽车车轮动态弯曲疲劳 + 动态径向疲劳 + 冲击试验（乘用 / 轻商）
- `GB 26149-2017`：轿车轮胎气压监测系统 TPMS
- ECE 对应：散见 R30 附件（不单独发 R）

**④ 轮胎运行性能**
- `ECE R117`：滚动阻力 / 湿地抓地 / 噪声 / 冰雪抓地（标签四大指标，对应 EU Tyre Labelling）— 2022 Am6 引入 ice grip 冰抓等级
- 国内：`GB/T 23674` / `GB/T 30985`（湿地抓地测量）— 未在本簇

**⑤ 辅助装置**
- 防飞溅系统 / 挡泥板：`GB 34659-2017`，`ECE R117`（部分含）
- TPMS：`ECE R64 Rev2`，`GB 26149-2017`

**⑥ 重点演进**
- 2013：`R106 Rev2` 发布，接入农林轮胎新速度符号
- 2018–2022：R108/R109/R117 Amendments 同步欧盟 Tyre Labelling 2.0（2021/740）
- 2020–2024：国内 `GB 518-2020`、`GB 9744-2015` 修订，覆盖新能源 / 高性能市场
- 持续：R106/R117 几乎每半年一次 Am，是本主题最活跃法规

**跨区域速查**：
- `GB 9743` ≈ `ECE R30`（乘用轮胎）
- `GB 9744` ≈ `ECE R54`（商用轮胎）
- `GB 518` ≈ `ECE R75`（摩托轮胎）
- `GB 36581` 无 ECE 直接对应（轮毂独立发条）
- `GB 26149` ≈ `ECE R64 Rev2`（TPMS）
