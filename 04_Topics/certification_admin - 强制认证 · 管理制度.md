# 强制认证 / 管理制度（Topic Index）

## Overview

强制认证 / 管理制度主题（4 notes）聚焦 **国内 CCC (China Compulsory Certification) 认证实施规则**，是汽车及零部件进入中国市场的必经关卡。

**① CCC 认证核心规则**
- `CNCA-C11-01:2020`：强制性产品认证实施规则（汽车）— CNCA（国家认证认可监督管理委员会）发布
- 覆盖整车 (M1/M2/M3/N/O/L) 和重要零部件（如轮胎、反光器、燃油箱等约 30 类）
- 认证模式：型式试验 + 初始工厂检查 + 获证后监督

**② 与其他体系对比**
- ECE：`1958 协定` 下的 E-mark（自愿，互认）
- EU：`2018/858` 指令下的 WVTA（强制，整车）
- US：`FMVSS` 自我认证（厂家自证 + DOT 抽查）
- 中国 CCC：**强制 + 第三方认证**（CQC / CCAP / CCAT 等机构），侧重产品级

**③ 认证机构生态**
- 主管：**CNCA**（监管发证规则）
- 指定认证机构：**CQC**（中国质量认证中心）等，出具证书
- 指定检测机构：**CATARC / CNIC** 等，出具试验报告

**跨区域速查**：
- CCC 证书 ≠ ECE E-mark，但部分 CCC 技术要求 **直接引用 GB/GB/T 标准**（而 GB 等同采用 ECE）→ 间接通用
- **双认证趋势**：国内厂家出口常同时申请 CCC + ECE，充分利用检测报告互认
- 2023+：EU 新要求 `Carbon Border Adjustment Mechanism (CBAM)` 对汽车出口影响待观察
