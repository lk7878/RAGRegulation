# 车速 / 限速装置（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

车速 / 限速装置主题（8 notes，ECE=5, CN=3）聚焦 **车速显示与主动限速装置**，包含车速表精度与限速系统要求。

**① 车速表**
- `ECE R39`：车速表 + 里程表及其安装（Rev2 Am1–Am2 持续修订）— 测量精度要求、温度影响补偿
- 国内：`GB 15082-2008`（汽车用车速表）

**② 车速限制系统**
- `ECE R89`：车速限制装置 / 可调限速装置
- `GB 24545-2019`：车辆车速限制系统技术要求及试验方法 — 覆盖最高车速限制 + 可调速限制
- 应用：大客车、营运货车、危险品车强制装配

**③ 最高车速测定**
- `GB/T 12548-2016`：车速表测试

**④ 重点演进**
- 2022：R39 Am2 引入新段 5.5.2 对里程表显示单位
- 国内 2019 `GB 24545` 实施，所有新生产商用车强制安装限速器
- EU：2022+ 新车强制配 ISA（Intelligent Speed Assistance），R89 对接

**跨区域速查**：
- `GB 15082` ≈ `ECE R39`（车速表）
- `GB 24545` ≈ `ECE R89`（车速限制装置）
- ISA 高阶：`ECE R89 升级版` 与 `EU 2019/2144` 对齐
