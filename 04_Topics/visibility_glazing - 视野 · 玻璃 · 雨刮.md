# 视野 / 玻璃 / 雨刮（Topic Index）

> 本页由 Stage 4 聚类脚本自动生成。Overview 段可由 Cascade 迭代完善。

## Overview

视野、玻璃与雨刮主题（46 notes，ECE=26, CN=20）涵盖驾驶员**直接视野**、**间接视野（后视镜 / CMS）**、**玻璃材料**、**除霜除雾 / 雨刮清洗** 四个子域，直接关系驾驶员感知安全。

**① 安全玻璃材料**
- `ECE R43`：安全玻璃材料（钢化 / 夹层 / 塑料 / 玻璃-塑料）认证 — 覆盖 L/M/N/O/T 类，Rev4 Am1–Am5 持续更新
- 国内：`GB 9656`（汽车安全玻璃）

**② 后视镜 / 间接视野装置（IVS）**
- `ECE R46`：后视镜及其整车安装
- `GB 15084-2022`：机动车辆间接视野装置（**合并后视镜 + 摄像机-监视器 CMS**，与 R46 现代化版本对齐）

**③ 直接视野 / A 柱遮挡**
- `ECE R125`：驾驶员前方视野（180° 直接视野）— Rev2 Am1 引入 **camera-monitor 可替代后视镜** 重大变更
- `GB 11562-2014`：汽车驾驶员前方视野要求及测量方法（M1 类）

**④ 雨刮 / 洗涤 / 除霜除雾**
- `ECE R45`：前灯清洗装置
- 国内：`GB 11555-2025` 最新除霜除雾（M1）；`GB/T 11556`（雨刮洗涤系统性能）
- 国内独有：`GB 11555` 独立覆盖除霜除雾（ECE 无单独 R，分散在 R46/R125）

**⑤ 罩盖 / 关联视野装置**
- `GB 11568-2011`：汽车罩(盖)锁系统 — 因影响前方视野第二锁止位置
- 转向柱布置影响视野：见 `crash_impact` 主题的 `ECE R12`

**⑥ 重点演进**
- 2016：R125 Rev2 Am1 开放 **CMS 替代后视镜**（Mercedes Actros 等车型首发）
- 2022：`GB 15084-2022` 大改，合并后视镜 + CMS 规范，国内正式接受 CMS
- 2025：`GB 11555-2025` 除霜除雾标准更新，测试条件对齐 WLTP 风洞环境

**跨区域速查**：
- `GB 9656` ≈ `ECE R43`（安全玻璃材料）
- `GB 15084` ≈ `ECE R46 + R125 Annex (CMS)`（间接视野整合）
- `GB 11562` ≈ `ECE R125`（直接视野）
- `GB 11555` 独立，`ECE R46` 第 15 节部分涵盖类似要求
