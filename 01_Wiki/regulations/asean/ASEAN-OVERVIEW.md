# 东盟汽车市场技术法规和认证制度发展情况

## 1. 东盟地区汽车市场及其特点
东盟（东南亚国家联盟）包括十个国家：老挝、柬埔寨、缅甸、泰国、越南、马来西亚、新加坡、文莱、菲律宾、印度尼西亚。已成为世界第三大自由贸易区。

### 1.1 发展不均衡，一体化市场有差距
- 各国经济发展、汽车产业政策、市场准入制度、技术法规体系、税费政策差异大。
- 排放控制水平不一（如新加坡欧IV，部分国家刚进入欧II）。
- 2010年1月1日起，东盟6个老成员国（泰国、马来西亚、新加坡、文莱、菲律宾、印度尼西亚）之间对所有商品（包括汽车）实施零关税。
- 目标：2015年建立统一汽车产品市场准入管理制度和技术法规体系。

### 1.2 二手车市场现状及对中国出口的影响
- 许多国家曾受日本二手车冲击，现普遍限制或禁止进口（如印尼、泰国、菲律宾），但对二手专用车进口常免于限制。
- 二手车限制/取缔可能为中国汽车出口腾出市场空间。

### 1.3 左舵车与右舵车市场
- 左舵车市场：菲律宾、越南、老挝、柬埔寨、缅甸。
- 右舵车市场：马来西亚、文莱、印度尼西亚、泰国、新加坡。
- 出口企业需针对不同市场设计产品。

### 1.4 东盟与中国的零关税
- 2011年1月1日起，中国与东盟实施自由贸易协定。
- 与6个老成员国对93%产品实施零关税，但**汽车整车产品不在此列**。
- 汽车产品被列为敏感产品：
    - 乘用车、轻型商用车：高度敏感产品（长期维持较高关税）。
    - 其他汽车产品：一般敏感产品（2020年1月1日关税降至5%以下）。
- 特种用途车（专用车）、车身、大部分底盘和许多汽车零部件被列为正常产品，关税将较快降为零。

## 2. 东盟汽车产品市场准入管理

### 2.1 总体情况及各国主管机关
- 尚未建立统一的市场准入管理制度，各国“各自为政”。
- 多数国家正从检验制度向国际通行的**型式批准制度**发展。
- 各国负责汽车产品市场准入管理的主要政府机关多为运输部门的陆路运输局（司）。

**东盟十国汽车产品市场准入管理机关：**

| 序号 | 国家 | 汽车产品市场准入管理机关 |
| :--- | :--- | :--- |
| 1 | 新加坡 | 陆路运输管理局（LTA）<br>国家环境署（NEA） |
| 2 | 泰国 | 陆路运输部（DLT）汽车工程局<br>泰国工业标准研究院（TISI）—汽车零部件认证 |
| 3 | 马来西亚 | 运输部陆路运输司（陆运局）<br>车辆型式批准委员会（VTA）<br>标准与工业研究院 SIRIM—汽车零部件认证 |
| 4 | 印度尼西亚 | 运输部陆路运输总局（MOT/DGLT）<br>环境部（MOE） |
| 5 | 菲律宾 | 交通运输部陆路运输办公室（DOTC/LTO）<br>环境与自然资源部环境管理局（DENR/EMB） |
| 6 | 越南 | 贸易和工业部产品标准局（DTI/BPS）<br>运输部注册局（VR） |
| 7 | 缅甸 | 联邦铁道部道路运输管理局（RTAD）<br>第二工业部汽车与柴油发动机工业公司（MADI） |
| 8 | 文莱 | 陆路运输局 |
| 9 | 柬埔寨 | 公共工作和运输部陆路运输司 |
| 10 | 老挝 | 公共工作和运输部<br>科学技术与环境局<br>工商部 |

### 2.2 东盟各国的汽车认证流程
- 各国正改革原有检验制度（“台台检”），参照欧盟模式建立型式批准制度。
- **新加坡**：最为完善，2003年建立电子化汽车型式批准系统（VITAS），实现网络化全流程管理。
- **马来西亚**：发展最快，不断采用ECE法规，建立型式批准制度。
- **印尼和泰国**：正在或考虑改革，泰国进度靠前（已对轿车、轻型载货车、摩托车建立型式批准，中重型商用车仍为检验制度）。
- **缅甸等**：仍维持原有检验制度。
- **东盟统一进程**：由东盟标准与质量顾问委员会下属汽车产品工作组负责，计划通过采用联合国ECE法规实现统一准入管理制度和技术法规体系（原定2015年，有延迟）。
- **专用车管理**：相对宽松，上装部分通常不在车辆管理部门职权内，由各国标准化部门管理，多未列入强制认证。危险物品运输车辆需满足UN/ECE的ADR协议。

### 2.3 东盟地区的汽车技术法规一体化进程
- 目标：2020年完成统一市场准入管理制度和技术法规体系，各成员国统一采用ECE法规，实施型式批准制度。
- 已就首批统一采用的19项ECE法规达成一致（原计划2015年实施）。

**东盟计划统一采用的ECE汽车技术法规项目（首批19项）：**

| 序号 | 单项法规涉及的汽车零部件或系统 | UNECE 法规号 |
| :--- | :--- | :--- |
| 1 | 商用车的制动系统 | R13 |
| 2 | 轿车制动系统 | R13H |
| 3 | 安全带固定点 | R14 |
| 4 | 安全带 | R16 |
| 5 | 座椅 | R17 |
| 6 | 头枕 | R25 |
| 7 | 轿车气压轮胎 | R30 |
| 8 | 车速表 | R39 |
| 9 | 安全玻璃 | R43 |
| 10 | 后视镜 | R46 |
| 11 | 商用车排放 | R49 |
| 12 | 汽车噪声 | R51 |
| 13 | 商用车气压轮胎 | R54 |
| 14 | 转向装置 | R79 |
| 15 | 轿车排放 | R83 |
| 16 | L类车辆排放 | R40 |
| 17 | L类车辆噪声 | R41 |
| 18 | L类车辆轮胎 | R75 |
| 19 | 声响报警装置 | R28 |

- **实施程度不确定**：例如，ECE R13H要求强制装备ESC和BAS，但东盟各国汽车产业水平参差不齐，2020年后强制安装难度大。
- **一体化特点**：与欧盟不同，首批19项ECE法规旨在构建**检测报告和认证的互认体系**，而非所有国家共同采用完全相同的法规清单。例如，泰国汽车出口马来西亚，19项内的项目检测报告互认，19项外的项目仍需满足马来西亚要求（马来西亚是《1958年协定书》缔约方，可通过ECE认证获得准入）。
- **未来计划**：第二批统一实施的ECE法规计划扩大至32项。
