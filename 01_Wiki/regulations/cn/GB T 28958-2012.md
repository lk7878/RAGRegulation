# 乘用车低温性能试验方法

## 前言
本标准根据GB/T 1.1—2009给出的规则起草。
本标准由国家发展和改革委员会提出。
本标准由全国汽车标准化技术委员会归口。
**本标准起草单位**：东北林业大学交通学院、哈尔滨哈飞汽车工业集团有限公司、国家汽车质量监督检验中心(襄樊)、重庆长安汽车股份有限公司、黑河市黑河汽车寒区试验基地管理委员会、黑河红河谷汽车测试中心有限公司。
**本标准主要起草人**：韩大明、尹雪峰、储江伟、陈晓涛、芦维强、王晓娟、孙莉、熊恭祥、朱鑫、邱刚、刘利华、赵鑫宏。

## 1 范围
本标准规定了乘用车低温性能试验的术语和定义、试验条件、试验方法等。
本标准仅适用于乘用车，其他车辆可参照执行。

## 2 规范性引用文件
下列文件对于本文件的应用是必不可少的。凡是注日期的引用文件，仅注日期的版本适用于本文件。凡是不注日期的引用文件，其最新版本（包括所有的修改单）适用于本文件。
- GB 11555 汽车风窗玻璃除霜和除雾系统的性能和试验方法
- GB/T 12534—1990 汽车道路试验方法通则
- GB/T 12535 汽车起动性能试验方法

## 3 术语和定义
下列术语和定义适用于本文件。
**3.1 低温性能 low temperature performance**
在规定的低温环境下，乘用车辆的工作能力。

## 4 试验仪器及精度
**4.1** 综合气象仪（气压、温度和风速计）2.5级精度。
**4.2** 温度计（-50℃~100℃，±1.5℃或1.5级精度）。
**4.3** 电液密度计（密度±0.005）。
**4.4** 测力计（0.5级精度）。
**4.5** 方向盘测力计（0.5级精度）。
**4.6** 行驶记录仪（可自动记录起动和行驶时的电流、电压、转速和时间）：
    a) 电流表（0A~1000A，2.5级精度）；
    b) 电压表（0V~30V，1.0级精度）；
    c) 发动机转速表（1级精度），里程参数（0.5级精度）；
    d) 计时器（0h~24h，±1s及0s~60s，±0.2s）。

## 5 试验条件
**5.1** 试验应在低温环境（试验室或自然条件）下进行。静态试验环境温度在-30℃以下，道路行驶试验环境温度平均不低于-20℃。静态试验前，试验车辆应保证在环境温度下停放8h以上方可试验。
**5.2** 为保证试验的准确性，被考核的零部件均应达到设计要求，性能参数调至规定范围。
**5.3** 按汽车的使用说明书或有关技术条件的规定，选用各系统相应牌号的燃料、润滑油、冷却液及其他工作液。
**5.4** 应使用制造商规定的蓄电池、起动电缆和搭铁电缆。各线路连接可靠，蓄电池工作良好。
**5.5** 试验车辆准备按GB/T 12534—1990中4.1、4.2的规定执行。
**5.6** 装载质量按GB/T 12534—1990中3.1.1、3.1.2的规定执行。
**5.7** 车辆应按产品规范加装标准配置。
**5.8** 轮胎气压按GB/T 12534—1990中3.2的规定执行。

## 6 试验方法
### 6.1 静态试验
**6.1.1** 试验前，试验车辆应保证在环境温度下停放8h以上方可试验。
**6.1.2 部件检验**
按表1（检验项目及要求）中所列的项目对车辆进行主观评价，并对表面外观质量及操纵情况等进行检验。

**表1 检验项目及要求**
| 检查项目 | 检验要求 |
| :--- | :--- |
| 门锁测力 | 外开锁扣手操纵力不大于30N，内开锁扣手操纵力不大于15N |
| 开门、关门 | 开关过程中无卡、碰、紧、异响等异常现象 |
| 发动机罩锁、后行李箱锁 | 动作灵活，无误锁和动作滞缓等现象 |
| 座椅调节机构、座椅头枕调节、座椅后枕屏、后座椅扶手 | 转换应灵活，无卡住现象 |
| 安全带 | 自收灵活，卡位清晰、可靠 |
| 玻璃升降器 | 运行平稳，无偏斜、出槽、卡、紧、异响等现象 |
| 内后视镜、外后视镜 | 调节应灵活，无卡住现象 |
| 后行李箱开启、关闭 | 后行李箱开启、举升机构应能自行将后行李箱举至最大开度，并能稳定地停留在位置上。关闭时，用力不大于30N |
| 各类开关 | 开关的档位转换应灵活，无卡住现象，定位应明确可靠。对自动复位档位的开关，当外力消除后应能自动复位 |
| 各类橡胶件、塑料件 | 不得有裂纹和影响使用性能及外形美观的变形。检查制动油管、轮胎等是否冻裂，分泵皮碗是否过度收缩 |
| 踏板机构 | 应活动自如，不得有阻滞现象，放松踏板后应能完全复位 |
| 驻车制动 | 转换应灵活，无卡住现象 |
| 换挡杆 | 转换应灵活，无卡住现象 |
| CD/DVD机 | 各功能键操作正常，液晶屏显示清晰、完整 |
| 喇叭 | 在规定的技术条件下，发音正常，无嘶哑和振扰声 |
| 仪表 | 应满足各类仪表的技术条件 |
| 仪表板 | 表面应平整，无变形，各附件与主体联接应紧固、可靠 |

**6.1.3 汽车起动性能**
汽车起动性能试验方法按GB/T 12535规定执行。

**6.1.4 动力转向系统冷态试验**
**6.1.4.1 全行程转向试验**
试验要求：
a) 试验时，车辆的车窗和发动机罩盖应关闭。
b) 起动发动机，怠速运转10s时，将发动机转速升高到1500r/min，稳定5s后，以18r/min的速度转动方向盘完成一个全行程转向（方向盘从中间位置向左转到极限位置，再向右转到另一极限位置，然后转回到中间位置）。在转动的过程中，转动尽可能地平稳，并记录方向盘最大输入转矩和最大操舵力。
c) 在5min内反复进行6.1.4.1 b)的试验，每次试验间隔15s。试验过程中，同时对车内、外转向系统噪音进行主观评价并记录。

**6.1.4.2 全行程转向延迟试验**
试验要求：
a) 试验时，车辆的车窗和发动机罩盖应关闭。
b) 起动发动机，怠速运转5min，其他操作及记录同6.1.4.1 b)。间隔15s，重复试验共4次。

**6.1.5 除霜和除雾**
试验时，暖风应调节到最大档并使发动机保持怠速运转，要求：
a) 前风窗玻璃应满足GB 11555的规定。
b) 侧窗、后窗、后视镜（如有对应的除霜和除雾装置或其他要求时），20min内侧、后窗的玻璃应达到视野清晰，满足行车条件。
c) 试验过程中，允许在玻璃外面喷洒水雾帮助结霜，并在一定范围内重复试验三次，记录霜冻完全除尽的时间及区域。

### 6.2 道路行驶试验
**6.2.1 试验道路总里程**
动态行驶试验总里程为30000km。各种道路（坏路、山路、冰雪路）的里程分配为各10000km。

**6.2.2 试验车速**
试验车速根据道路情况确定，以确保行车安全为前提条件。

**6.2.3 试验道路种类**
**6.2.3.1 坏路**：路基坚实，路面凸凹不平的道路。有明显的搓板波，分布均匀的鱼鳞坑。
**6.2.3.2 山路**：平均坡度不大于4%。
**6.2.3.3 冰雪路面**：路面至少应有冰渣或雪（雪路要求积雪厚度达到60mm以上）。冰雪混合路；单侧冰路与水泥或沥青路面；单侧雪路与水泥或沥青路面；完全冰路或雪路面。道路里程平均分配。

**6.2.4 道路行驶试验主要检查项目**
**6.2.4.1 车辆的低温使用性能**：
    a) 车辆的操纵稳定性的主观评价；
    b) 制动性能测试主观评价。
**6.2.4.2 零部件的工作状态评价**：
    a) 内外饰件及电器件、橡塑件：检查在动态过程中是否产生异响、松动和损坏等现象。
    b) 各联接处密封情况：在每次行驶试验前后，应检查水箱、水泵、缸体、缸盖、暖风装置等所有联接处，不得有渗、漏水（油）现象。
    c) 车辆正常行驶中，检查暖风机工作（暖风调节到最大档），前风挡玻璃应满足6.1.5 a)的规定。

### 6.3 道路试验后的静态试验
在完成6.2道路行驶试验后，重复6.1的静态试验（或按生产商规定的保养期内），其中重复冷起动试验应满足GB/T 12535的规定。
