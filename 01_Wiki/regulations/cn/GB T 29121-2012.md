# 道路车辆 乘用车列车 横向稳定性试验

**标准编号**: GB/T 29121-2012/ISO 9815:2010
**发布日期**: 2012-12-31
**实施日期**: 2013-07-01
**归口单位**: 全国汽车标准化技术委员会 (SAC/TC114)
**起草单位**: 中国汽车技术研究中心、安徽江淮汽车股份有限公司、北汽福田汽车股份有限公司、汉阳专用汽车研究所
**主要起草人**: 王学平、张铜柱、王颖、李玉刚、张丽丽、胡钢

## 范围
本标准规定了乘用车列车的横向稳定性试验方法。
本标准适用于 ISO 3833 中界定的乘用车、轻型货车及其与挂车组成的列车。
横向稳定性试验可以确定牵引车辆—挂车列车因确定的转向脉冲引起的偏航振荡阻尼特性。首先，列车稳定向前行驶，之后，通过单脉冲转向制造车辆的横向摆动，方向盘保持固定一段时间，使得列车的摆动逐渐消除。测试在几个不同的速度下进行。如果出现非周期性的震荡，应规定稳定测试循环。

## 术语、定义和符号
ISO 3833、ISO 8855 界定的以及下列术语和定义适用于本文件。

### 3.1 横摆铰接角 yaw articulation angle
Δψ
X_C 相对于 X_T 的转角，每部分X轴间的夹角。极性由牵引车辆相对挂车旋转角度决定。
注：下标字母 C 和 T 分别表示牵引车和挂车。例如，牵引车中轴系统的纵轴为 X_C，牵引车横向加速度为 a_Y C；挂车中轴系统的纵轴为 X_T，挂车横向加速度为 a_Y T。

### 3.2 平均坡度 (meangradient of the test track)
G
车辆运行轨道两点间垂直高度的变化量除以两点间水平距离，该两点应尽可能靠近车辆分别在时间 t_2 和 t_Δψn 行驶的那部分试验轨道。
注：该坡度无单位。如果车辆沿坡向上行驶为正，向下行驶为负。

## 测试指标
在进行试验时，应对下列参数进行测试：
- 方向盘转角，δ_H；
- 牵引车辆的纵向车速，v_X；
- 挂车的横向加速度，a_Y T；
- 牵引车辆和挂车之间的横摆铰接角，Δψ；

下列参数宜进行测试：
- 牵引车辆的横摆角速度，dψ_C/dt；
- 挂车的横摆角速度，dψ_T/dt。
注：上述参数并不是试验的全部测试参数。

## 试验条件
### 5.1 概述
试验的一般条件应满足 ISO 15037-1 的要求，其他条件见以下条款。

### 5.2 测试设备
应使用适当的传感器监测条款4给出的测量参数。ISO 15037-1 要求的测量和记录设备应同时应用于牵引车辆和挂车。ISO 15037-1 中没有规定的，典型的操作范围和最大允许误差见表1。
可以选用辅助转向设备。

**表1 典型的操作范围和最大允许误差**
| 参数 | 范围 | 传感器和记录仪的累计误差 |
| :--- | :--- | :--- |
| 横摆铰接角 | ±20° | ±0.2° |

### 5.3 试验路面
试验路面除了满足 ISO 15037-1 的要求外，在被试车辆行驶方向上的平均坡度应在 1% 以内，试验路面的宽度应不小于 8m。
当平均坡度接近允许的最大值时，试验应分别从两个方向进行。

### 5.4 风速
风速要满足 ISO 15037-1 的要求，并且不超过 2.5 m/s。应记录风速的大小和方向。

### 5.5 载荷状态
#### 5.5.1 牵引车
牵引车的空载总质量由整车整备质量、驾驶员质量和检测设备质量（驾驶员质量和检测设备质量合计不超过 150kg）构成。检测设备的安放位置应保证使其对车辆的横摆惯量的影响最小。
应在牵引车处于最大载荷状态和部分载荷状态下重复进行试验。对于最大总质量状态，车辆的满载总质量由整车整备质量、客舱中的每个座位上加 68kg 以及按 ISO 2416 配备最大的行李舱载荷施加在牵引车挂接装置上的静态载荷构成。仪器质量包括在总质量中。应保证车辆的转动惯量与正常使用时一致。
牵引车的满载总质量不能超过最大设计总质量。在考虑牵引车挂接装置上静态载荷的情况下，前后轴的载荷也不能超过相应的最大设计值。如果使用了分布载荷连接装置，应在连接装置结合后，对各个轴的载荷进行测量。

#### 5.5.2 挂车
挂车应加载至允许的最大总质量或列车达到最大设计总质量，取二者中的较小值。如果挂车允许不同的载荷分配，则载荷分配应使得横摆转动惯量、质心高度以及牵引装置上的静态载荷具有代表性。
试验可以在其他任何载荷状态下进行。
试验时，应对挂车的质量、质心位置以及横摆转动惯量等进行测量并记录。

#### 5.5.3 挂接装置上的静态载荷
##### 5.5.3.1 试验在挂接装置处于最大静载荷状态下进行。该载荷通过牵引车、挂车或挂接装置本身的最大允许载荷确定，取三者中的较小值。但是，如果该载荷导致牵引车的后轴载荷超过制造商的规定的最大值，则应适当减小作用于该挂接装置上的静态载荷。
##### 5.5.3.2 作为静态载荷作用于挂接装置上的部分挂车重量对列车的横摆阻尼有很大的影响。典型的情况如：当作用于挂接装置上的静态载荷减小时，阻尼随之减小。因此，也应在挂接装置处于可能的最小静态载荷时进行试验。

#### 5.5.4 分布载荷挂接装置的调整
当挂车质量比较大时，经常需要使用分布载荷挂接装置来修正由于作用于挂接装置上的静态载荷而产生的牵引车的纵向摇摆角。此时将挂接装置转移到牵引车后轴上的载荷的一部分重新分配到牵引车前轴或挂车的车轴上。在这种情况下，铰接角阻尼增加，而由横向加速度产生的牵引车转向不足将减小。
分布载荷挂接装置通常包括一个增加铰接角阻尼的机械装置。应按照牵引车、挂车和挂接装置制造商的要求对挂接机构及其辅助装置进行安装和调整。
如果制造商没有给出使用分布载荷挂接装置的具体要求，应按照下面的程序进行安装和调整：挂接挂车前，分别在牵引车前、后轴中心线位置测量在试验载荷状态下车身上的点与地面的垂直距离。挂接挂车后，调节挂接装置的偶合力矩，使上述两个值的总变化量均在 10mm 以内。
如果静载状态的推荐值不适合分布载荷挂接装置，则连接装置处的载荷取牵引车重量的 8.4%。
试验时记录偶合力矩。为此，必须分别在挂车挂接前、挂车挂接后和分布载荷挂接装置调整后测量牵引车前、后轴的轴荷（对确定的牵引车重量，牵引车和挂车在水平状态下测量轴荷）。如果牵引车和挂车的轮胎与地面的接触面不在同一个平面内，则偶合力矩会发生变化。
偶合力矩按下式计算：
M_Y eq = F_ZwfC (l_C + e_C) + F_ZwrC (e_C) - m_C g (d_C + e_C)
其中：
- M_Y eq — 由分布载荷挂接装置产生的力矩；
- F_ZwfC — 挂车连接、分布载荷挂接装置作用时牵引车前轮上的载荷总和；
- F_ZwrC — 挂车连接、分布载荷挂接装置作用时牵引车后轮上的载荷总和；
- g — 重力加速度；
- m_C — 牵引车质量；
- l_C — 牵引车轴距；
- d_C — 牵引车重心与后轴中心线的水平距离；
- e_C — 后悬，后轴中心线与挂接点的水平距离。

## 试验方法
### 6.1 概述
试验开始前，应对被试车辆进行预热。每次试验都应按照 ISO 15037-1 的要求，从稳定的、正对行驶方向开始。

### 6.2 试验程序
#### 6.2.1 速度
首先按 50 km/h 进行试验，然后逐步增加试验车速（即，从 ISO 15037-1:2006 6.2.1 到本标准的 7.2.3 的 t_Δψn）。
当处于阻尼 ≥0.15 的速度范围时，每次的速度增量 ≤10 km/h。
当处于阻尼小于 0.15 的速度范围时，每次的速度增量 ≤5 km/h。最高试验车速至少是计算零阻尼车速的 90%。
当列车接近低阻尼时应预警。此时，初始试验应在车速低于 50 km/h 的情况下进行。
在整个试验过程中，应按照 ISO 15037-1:2006 6.2.1 的要求保持车速，而且，在时间从 t_2 到 t_Δψn 期间，平均纵向加速度在 ±0.1 m/s² 的范围内。

#### 6.2.2 转向脉冲
通过方向盘的一个脉冲输入使牵引车和挂车开始出现横向摆动。
方向盘的输入脉冲幅度应使挂车重心处的侧向加速度的最大振幅达到 (4±1) m/s²。如果不能产生 (4±1) m/s² 的加速度，输入的转向脉冲应尽可能在挂车的重心处产生最大的侧向加速度。在挂车重心处产生的最大侧向加速度振幅应记录在附录 B 的试验报告中。
图 1 和图 2 给出了两种类型的方向盘转角和铰接角时间历程曲线。
其中：
- t_0：方向盘转角振幅首次超过其最大振幅的 10% 的时间，单位为秒 (s)；
- t_1：出现峰值后，方向盘转角振幅首次降低至其最大振幅的 10% 的时间，单位为秒 (s)；
- t_2：特定时间，单位为秒 (s)，在此之后方向盘转角保持在要求的变化范围内。
转向脉冲的周期（如 t_0 ~ t_1 的周期）不能超过 0.5 s。
转向脉冲输入完成后，方向盘可以按图 1 的方式直接回到其原始位置，也可以按图 2 的方式回到其原始位置后，再转动一定的量，以保证挂车回到其初始的行驶线路上。在转向脉冲以及适当的方向修正完成以后，方向盘应保持在车辆向前行驶的位置不变。任何方式的方向修正的持续时间 (t_2 - t_1) 都不能超过 1.5 s。从 t_2 以后，与车辆向前行驶的位置比较，方向盘转角偏差的平均值，即 |δ_H1|，不能超过其最大振幅的 10%。这个平均值偏差的最大振幅，即 |δ_H2|，不能超过其最大振幅的 5%。

#### 6.2.3 试验次数
在最小试验车速与 90% 零阻尼车速之间，每 10 km/h 的范围内，至少要进行 5 次有效的试验。在超过 90% 零阻尼车速的范围内，至少要进行 3 次有效的试验。

## 数据分析
### 7.1 概述
由于数据很多，应采用计算机进行数据分析。
应显示铰接角随时间的变化，并可用肉眼监视。不能代表试验的结果应舍去。

### 7.2 独立的试验
#### 7.2.1 车辆实际纵向加速度
每个试验都应确定车辆实际纵向加速度 α_E (m/s²)，其值为牵引车纵向加速度总和的平均值（即，单位时间内牵引车纵向速度的变化），也是车辆在坡道上重力加速度的纵向分量。计算公式如下：
α_E = (v_X(t_Δψn) - v_X(t_2)) / (t_Δψn - t_2) + G × g
其中：
- g — 重力加速度，单位为米每二次方秒 (m/s²)；
- v_X(t_i) — 牵引车分别在时间 t_Δψn 和 t_2 的速度；
- t_Δψn — 按 7.2.3 的规定。
α_E 在 ±0.1 m/s² 范围内试验为有效。理想的是在给定的试验速度下 α_E 平均值在 ±0.05 m/s² 内。无论如何，应报告各试验的 α_E 值。

#### 7.2.2 试验速度
按下述公式确定试验速度：
v = (∫_{t_2}^{t_Δψn} v_X(t) dt) / (t_Δψn - t_2)

#### 7.2.3 铰接角摆动阻尼
见图 1 和图 2 铰接角时间历程：
- Δψ_1：时间 t_2 后第 1 个零点后的首个波峰的振幅（以第三波峰为典型）；
- Δψ_n：(Δψ_{n-1} ± Δψ_n) 至少为 (Δψ_1 ± Δψ_2) 的 10% 的最后一个波峰的振幅；
- Δψ_2 ~ Δψ_{n-1}：Δψ_1 和 Δψ_n 确定的波峰间波峰的振幅；
- t_Δψn：Δψ_n 发生的时间，s；
Δψ_1 至 Δψ_n 的所有振幅和 t_Δψn 均应从铰接角时间历程中确定。
注：Δψ_1 至 Δψ_n 的所有振幅均为绝对值。
按下述公式计算振幅比率的平均值：
r = (1/(n-2)) × ( (Δψ_1 + Δψ_2)/(Δψ_2 + Δψ_3) + (Δψ_2 + Δψ_3)/(Δψ_3 + Δψ_4) + (Δψ_3 + Δψ_4)/(Δψ_4 + Δψ_5) + … + (Δψ_{n-2} + Δψ_{n-1})/(Δψ_{n-1} + Δψ_n) )
根据下式计算阻尼 D：
D = ln(r) / √(π² + (ln(r))²)
至少应在 7 个振幅的基础上计算 r（即 n ≥ 7）。如果不能实现，应注明 D 值相应的 n 值。

#### 7.2.4 横摆速率
测到牵引车和挂车的横摆车速后，可以根据下列公式计算横摆速率：
R_ψ = (1/(n-1)) × ( (dψ_C1/dt + dψ_C2/dt)/(dψ_T1/dt + dψ_T2/dt) + (dψ_C2/dt + dψ_C3/dt)/(dψ_T2/dt + dψ_T3/dt) + (dψ_C3/dt + dψ_C4/dt)/(dψ_T3/dt + dψ_T4/dt) + … + (dψ_C(n-1)/dt + dψ_C n/dt)/(dψ_T(n-1)/dt + dψ_T n/dt) )
其中：
- dψ_C i/dt — 牵引车横摆最大振幅，i = 1 和 n；
- dψ_T i/dt — 挂车横摆最大振幅，i = 1 和 n。

### 7.3 零阻尼速度
零阻尼速度即为阻尼为 0 时的速度。该值从附录 B 中阻尼—试验速度图得出。与数据拟合最佳的直线应由以下的数据衰减得到：
D = C_0 + C_1 × v
其中：
- C_0 — 无量纲衰减系数；
- C_1 — 衰减系数，单位为小时每千米 (h/km)；
- v — 零阻尼速度，即 v_zd，v_zd = - C_0 / C_1。
应以零阻尼车速 90% 的试验速度至少进行三次试验。如果以上要求不能满足或出于安全的原因不能以零阻尼车速 90% 的速度行驶，“零阻尼车速”不能用来表示结果（见附录 B）。

### 7.4 参考阻尼车速
参考阻尼车速为阻尼水平为 0.05 时的速度。D 为 0.05 时的车速为参考阻尼车速 v_0.05，应由以下公式确定：
v_0.05 = (0.05 - C_0) / C_1

### 7.5 参考车速阻尼
参考车速阻尼 D_80 是车速为 80 km/h 的阻尼，由以下公式确定：
D_80 = C_0 + 80 × C_1

## 数据的表达
### 8.1 通用数据
通用数据应按照 ISO 15037-1:2006 附录 A 和本标准的附录 A 记录。ISO 15037-1:2006 附录 A 的相关部分由牵引车完成。该附录中的三项和载荷条件有关的项目应记录两次，即：测得的轴荷、试验质量下的总高（仅牵引车）和重心高度（仅牵引车），一次仅为牵引车，一次为牵引挂车后测得的数据。

### 8.2 试验条件
试验条件应依据 ISO 15037-1:2006 的附录 B 进行记录。该附录中涉及到轮胎的记录应扩展为包括牵引车辆和挂车的轮胎。

### 8.3 试验结果
试验结果应按附录 B 记录，包括每个试验结果的列表和铰接角阻尼 D 和试验速度 v 关系图。
