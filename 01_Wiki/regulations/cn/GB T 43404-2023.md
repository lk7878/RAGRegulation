# 轻型汽车道路负载 底盘测功机再现

## 前言
本文件按照GB/T 1.1—2020《标准化工作导则 第1部分：标准化文件的结构和起草规则》的规定起草。
本文件修改采用ISO 10521-2:2006《道路车辆 道路负载 第2部分：底盘测功机再现》。
本文件与ISO 10521-2:2006相比做了下述结构调整：
- 增加了滑行法和扭矩仪法的适用条件（见第1章，对应ISO 10521-2:2006中6.1和6.2的悬置段）。
- 将5.2.1对滚筒的要求细分为5.2.1.1和5.2.1.2。
- 将5.3.1对惯量设定的要求细分为5.3.1.1、5.3.1.2和5.3.1.3。
- 将5.4.2车辆设置的要求细分为5.4.2.1、5.4.2.2和5.4.2.3。
- 将5.4.3车辆预处理的要求细分为5.4.3.1和5.4.3.2。

本文件与ISO 10521-2:2006的技术差异及其原因如下：
- 更改了标准的适用范围（见第1章），依据GB 18352.6的有关要求，适用范围明确了最大设计总质量超过3500kg但不超过4500kg的M1、M2和N2类汽车参照执行。
- 用规范性引用的GB/T 3730.1替换了ISO 3833（见第3章），以适应我国的技术条件，增加可操作性。
- 增加了GB/T 15089、GB 18352.6的规范性引用（见第3章），与适用范围部分的描述相对应，以适应我国的技术条件，增加可操作性。
- 增加了术语“目标行驶阻力”“模拟行驶阻力”（见第3章），便于后文理解使用。
- 更改了道路载荷、行驶阻力、基准速度、模拟道路载荷、旋转质量的定义（见第3章），便于后文理解使用。
- 更改了仪器设备要求的表达方式，增加了底盘测功机力、底盘测功机当量惯量要求，更改了车速、时间、车轮扭矩的准确度要求（见表1），相关要求是保证后续试验准确性的重要指标，并与现行标准的要求保持一致。
- 增加了最高基准速度的要求（见5.1.2），明确了纯电动汽车的最高基准速度以适用于纯电动汽车开展试验。
- 更改了室内温度要求（见5.2.2），采用以摄氏度为单位的表述方式更便于试验操作。
- 更改了底盘测功机当量惯量的设定方法（见5.3.1），根据底盘测功机类型进行了细分。
- 增加了车辆设置的要求（见5.4.2），与相关标准要求保持一致，更利于标准执行使用。
- 更改了车辆在底盘测功机上的预热方法（见5.4.3），明确了预热车辆的行驶工况，便于实际操作。
- 更改了滑行试验的要求（见6.1.1.2），细化了对于能量回收系统的操作要求，适应新能源车辆的执行。
- 用规范性引用的ISO 10521-1替换了ISO 10521-1:2006（见6.1.1.2和6.2.1.2），以适应道路负载的测量方法的更新和优化。
- 增加了校核方式的选择（见6.1.1.3.2、6.1.1.3.3），便于固定运转法的使用。
- 更改了行驶阻力的符号表示（见6.2.1.3），符合对力矩的理解，避免产生歧义。
- 增加了模拟行驶阻力的计算方法（见A.2），更利于标准执行使用。
- 删除了悬置段（见A.2），符合国标的编写方式，更利于标准执行使用。

本文件做了下列编辑性改动：
- 将标准名称改为《轻型汽车道路负载 底盘测功机再现》。

- 更改了扭矩仪法底盘测功机设定载荷调整的公式（见B.2）。

## 1 范围
本文件规定了汽车在底盘测功机上开展道路负载再现的方法。
本文件适用于最大设计总质量不超过3500kg的汽车，最大设计总质量超过3500kg、但不超过4500kg的M1、M2和N2类汽车参照执行。
本文件所述滑行法设定底盘测功机载荷条款，适用于滑行法或风洞法测得的试验车辆道路载荷的设定。
本文件所述扭矩仪法设定底盘测功机载荷条款，适用于扭矩仪法测得的试验车辆行驶阻力的设定。

## 3 术语和定义
GB/T 3730.1、GB/T 15089、GB 18352.6和ISO 10521-1界定的以及下列术语和定义适用于本文件。

### 3.1 道路载荷 roadload
在滑行法或者等效方法测量中阻碍车辆行驶的阻力，包括传动系统的摩擦阻力。

### 3.2 行驶阻力 running resistance
通过安装在车辆驱动轮上的扭力计测得的与车辆行驶方向相反的阻力矩。

### 3.3 目标道路载荷 target roadload
用以在底盘测功机上要复现的道路载荷。

### 3.4 目标行驶阻力 target running resistance
用以在底盘测功机上要复现的行驶阻力。

### 3.5 底盘测功机设定载荷 chassis-dynamometer setting load
在底盘测功机功率吸收单元上设定的载荷。

### 3.6 模拟道路载荷 simulated roadload
通过底盘测功机加载，以力的形式再现道路实际测得的道路载荷。

### 3.7 模拟行驶阻力 simulated running resistance
通过底盘测功机加载，以力的形式再现道路实际测得的行驶阻力。

### 3.8 基准速度 reference speed
用于确定道路载荷或底盘测功机载荷的车辆行驶速度。

### 3.9 速度范围 speed range
从20km/h起始，以10km/h步长增加至最高基准速度。

### 3.10 系数控制底盘测功机 chassis dynamometer of coefficient control
由给定道路载荷的近似多项式系数来确定吸收特性的底盘测功机。

### 3.11 多边形控制底盘测功机 chassis dynamometer of polygonal control
由几个速度点给定载荷值来确定吸收特性的底盘测功机。

### 3.12 旋转质量 rotation mass
车辆在道路上空挡行驶时，车上所有旋转零部件和车轮的等效有效质量。
注1：能通过试验或者计算的方法确定旋转质量。
注2：能根据车辆整备质量加上100kg的3%进行旋转质量估算。

## 5 试验准备
### 5.1 参数设置
#### 5.1.1 试验前，应根据后续试验目的确定以下参数（下列参数需与后续测试项目保持一致）：
a) 目标道路载荷或目标行驶阻力；
b) 速度范围；
c) 基准速度。

#### 5.1.2 最高基准速度根据以下规定确定。
a) 最高基准速度应为130km/h，纯电动汽车可调整为120km/h。道路载荷确定和底盘测功机的设定应在相同的基准速度点进行。
b) 如果最高基准速度加上14km/h后，大于或等于试验车辆的最高车速，在进行道路载荷测定或者在底盘测功机上设定阻力时，应将该速度剔除，此时次高基准速度成为车辆的最高基准速度。

### 5.2 实验室条件
#### 5.2.1 滚筒
##### 5.2.1.1 底盘测功机滚筒应为洁净、干燥、无异物的粗糙表面，可在车上或车内放置配重防止车轮打滑，应记录配重情况。
##### 5.2.1.2 多滚筒底盘测功机，滚筒应在与后续试验中相同的耦合或非耦合状态下进行。底盘测功机的转速应在与功率吸收单元耦合的滚筒法上进行测量。

#### 5.2.2 室内温度
实验室温度应设置为23℃±5℃，或根据试验特殊需求设置。

### 5.3 底盘测功机准备
#### 5.3.1 惯量设定
##### 5.3.1.1 应按照5.3.1.2和5.3.1.3设定当量惯量，若无法进行设定，应采用相邻的较大一级当量惯量进行设定，但最多不能超过10kg。
##### 5.3.1.2 车辆在四轮驱动底盘测功机上进行试验，若前后轴同时旋转，底盘测功机的当量惯量应设定为相应的车辆试验质量。
##### 5.3.1.3 车辆在两轮驱动底盘测功机上进行试验，底盘测功机的当量惯量应设定为车辆试验质量加上不影响测量结果的车轮的有效惯量，或旋转质量的50%。

#### 5.3.2 底盘测功机预热
应按照底盘测功机制造商说明书，或其他合适的方法对底盘测功机进行预热，直到内部摩擦损失能稳定为止。

### 5.4 车辆准备
#### 5.4.1 轮胎压力调整
测试前轮胎压力应调整到推荐值，推荐值应与后续测试相同。如果使用小直径滚筒，可增大胎压以确保试验安全，通常宜增大50%。

#### 5.4.2 车辆设置
##### 5.4.2.1 被测车辆应安装在底盘测功机滚筒的正中位置上，并以安全的方式固定。单个滚筒时，轮胎接触点与滚筒顶部水平距离应在±25mm或滚筒直径的±2%范围内，以较小者为准。
##### 5.4.2.2 使用扭矩仪法进行测量，轮胎压力应调整到轮胎动力学半径的±0.5%之内。若调整导致轮胎压力超过了5.4.1规定的范围，则不应使用扭矩仪法测量。
##### 5.4.2.3 轮胎动力学半径按A.2.1计算的80km/h基准速度下或各基准速度下轮胎动力学半径的平均值。

#### 5.4.3 车辆预热
##### 5.4.3.1 可按相似车型的底盘测功机设定载荷，或根据测量方法的不同选择6.1.1.1或6.2.1.1规定的初始载荷设置预热时底盘测功机的功率吸收单元。
##### 5.4.3.2 车辆在底盘测功机上应进行充分预热，使其达到稳定状态。宜以不低于80km/h的速度匀速行驶不低于20min，或行驶1~2个完整的CLTC循环（对于最大设计总质量大于3500kg的车辆，改为行驶CHTC循环）。
注1：CLTC（China light-duty vehicle test cycle），中国轻型汽车测试工况。
注2：CHTC（China heavy-duty vehicle test cycle），中国重型汽车测试工况。

## 6 设定底盘测功机载荷
### 6.1 滑行法设定底盘测功机
#### 6.1.1 底盘测功机载荷设定
##### 6.1.1.1 初始载荷设定
对系数控制底盘测功机，应根据公式（1）给出的初始系数A_d、B_d和C_d对底盘测功机的功率吸收单元进行调整。
`F_d = A_d + B_d v + C_d v^2` ………(1)
式中：
- F_d——底盘测功机设定载荷，单位为牛（N）；
- v——底盘测功机滚筒速度，单位为千米每小时（km/h）。

初始载荷可按照以下方法设定：
a) 参数计算，计算公式如下：
    1) 单轴底盘测功机按公式（2）计算。
 `A_d = 0.5 × A_t`
 `B_d = 0.2 × B_t`
 `C_d = C_t` ………(2)
 式中：A_t、B_t和C_t——目标道路载荷系数，由目标道路载荷按A.1.2计算。
    2) 双轴底盘测功机按公式（3）计算。
 `A_d = 0.1 × A_t`
 `B_d = 0.2 × B_t`
 `C_d = C_t` ………(3)
b) 经验值，可使用类似车辆的设定值。

对多边形控制底盘测功机，在底盘测功机功率吸收单元上，对每个基准速度点都应设置足够的载荷。

##### 6.1.1.2 滑行
将变速器挡位置于空挡或使动力系统处于断开状态，应屏蔽产生驱动或阻止汽车滑行的力的装置（如能量回收系统等）及其功能。
应按照ISO 10521-1的规定进行底盘测功机上的滑行试验。

##### 6.1.1.3 校核
###### 6.1.1.3.1 基准速度下目标道路载荷按公式（4）计算。
`F_tj = A_t + B_t v_j + C_t v_j^2` ………(4)
式中：
- F_tj——基准速度v_j下的目标道路载荷，单位为牛（N）；
- v_j——j点基准速度，单位为千米每小时（km/h）。

###### 6.1.1.3.2 应按照6.1.1.3.3的规定设定底盘测功机载荷。如果车辆利用自身动力加速，加速度和速度乘积的最小值约为6 m²/s³。

###### 6.1.1.3.3 底盘测功机设定可采用两种不同的方法。
- **固定运转法**：测功机在软件控制下进行四次滑行，在完成第一次正常滑行后，应将基于B.1计算得到的测功机设定系数作为第二次滑行的设定值。随后的三次滑行可固定使用第一次正常滑行得到的系数，也可使用按B.1的计算调整后得到的测功机设定系数。
    按公式（5）计算测功机的设定系数A、B和C。
    `A = A_t - (∑_{n=1}^{4} (A_Sn - A_dn)) / 3`
    `B = B_t - (∑_{n=1}^{4} (B_Sn - B_dn)) / 3`
    `C = C_t - (∑_{n=1}^{4} (C_Sn - C_dn)) / 3` ………(5)
    式中：
    - A_Sn、B_Sn和C_Sn——第n次运行的模拟道路载荷系数；
    - A_dn、B_dn和C_dn——第n次测功机设定系数；
    - n——包括第一次稳定滑行在内的测功机滑行次数。
- **迭代法**：采用最小二乘法计算两次连续滑行所得的模拟道路载荷（按A.1.3计算），在给定速度范围内，结果偏差应满足6.1.1.3.4的要求。如果不满足要求，应按6.1.1.4的规定对测功机的设定参数进行调整，继续进行滑行试验，直到满足上述要求偏差为止。

###### 6.1.1.3.4 使用公式（6）计算每个基准速度v_j下，模拟道路载荷F_sj相对于目标道路载荷F_tj的误差ε_j。
`ε_j = |F_sj - F_tj| / F_tj × 100%` ………(6)

除非法规另有明确规定，否则两次连续滑行各基准速度下的误差应满足以下要求：
- v_j ≥ 50km/h时，ε_j ≤ 3%；
- 20km/h < v_j < 50km/h时，ε_j ≤ 5%；
- v_j ≤ 20km/h时，ε_j ≤ 10%。

若任一基准速度下的误差不满足上述条件，则按照6.1.1.4调整底盘测功机。

##### 6.1.1.4 调整
根据B.1规定的步骤调整底盘测功机设定载荷，然后重复6.1.1.2和6.1.1.3。

### 6.2 扭矩仪法设定底盘测功机
#### 6.2.1 扭矩仪法设定底盘测功机
##### 6.2.1.1 初始载荷设定
对系数控制底盘测功机，应根据公式（7）给出的初始系数A_d、B_d和C_d对底盘测功机的功率吸收单元进行调整。
`F_d = A_d + B_d v + C_d v^2` ………(7)
式中：
- F_d——底盘测功机设定载荷，单位为牛（N）；
- v——底盘测功机滚筒速度，单位为千米每小时（km/h）。

初始载荷可按照以下方法设定。
a) 参数计算，计算公式如下：
    1) 单轴底盘测功机按公式（8）计算。
 `A_d = 0.5 × a_t / r'`
 `B_d = 0.2 × b_t / r'`
 `C_d = c_t / r'` ………(8)
 式中：
 - r'——车轮动力学半径，单位为米（m），按A.2.1计算；
 - a_t、b_t和c_t——目标行驶阻力系数，由目标行驶阻力按A.2.2计算。
    2) 双轴底盘测功机按公式（9）计算。
 `A_d = 0.1 × a_t / r'`
 `B_d = 0.2 × b_t / r'`
 `C_d = c_t / r'` ………(9)
b) 经验值，可使用类似车辆的设定值。

对多边形控制底盘测功机，在底盘测功机功率吸收单元上，每个基准速度点都要设置足够的载荷。

##### 6.2.1.2 车轮扭矩测量
应按照ISO 10521-1的规定在底盘测功机上测量扭矩。

##### 6.2.1.3 校核
###### 6.2.1.3.1 基准速度下目标行驶阻力按公式（10）计算。
`M_tj = a_t + b_t v_j + c_t v_j^2` ………(10)
式中：
- M_tj——基准速度v_j下的目标行驶阻力，单位为牛米（N·m）；
- v_j——j点基准速度，单位为千米每小时（km/h）。

###### 6.2.1.3.2 使用公式（11）计算每个基准速度v_j下，模拟行驶阻力M_sj相对于目标行驶阻力M_tj的误差ε_j。
`ε_j = |M_sj - M_tj| / M_tj × 100%` ………(11)

在所有基准速度下，模拟行驶阻力与目标行驶阻力之间的偏差应满足以下要求：
- v_j ≥ 50km/h，ε_j ≤ 3%；
- 20km/h < v_j < 50km/h时，ε_j ≤ 5%；
- v_j ≤ 20km/h时，ε_j ≤ 10%。

若任一基准速度下的误差不满足上述条件，则按照6.2.1.4调整底盘测功机。

##### 6.2.1.4 调整
根据B.2规定的步骤调整底盘测功机设定载荷，然后重复6.2.1.2和6.2.1.3。

## 附录A（规范性）底盘测功机模拟道路载荷的计算
### A.1 滑行法模拟道路载荷的计算
#### A.1.1 使用公式（A.1）计算所测道路载荷。
`F_mj = (1/3.6) × (TM + m_r) × (2Δv / Δt_j)` ………(A.1)
式中：
- F_mj——基准速度v_j的测量载荷，单位为牛（N）；
- TM——车辆试验质量，单位为千克（kg）；
- m_r——旋转质量，单位为千克（kg）；
- Δv——基准速度与测量上限或下限的速度差，不超过5km/h；
- Δt_j——速度v_j对应的滑行时间，单位为秒（s）。

#### A.1.2 将F_mj通过最小二乘法计算得出公式（A.2）所示模拟道路载荷系数A_S、B_S和C_S。
`F_S = A_S + B_S v + C_S v^2` ………(A.2)

#### A.1.3 按公式（A.3）计算每个基准速度点v_j下的模拟道路载荷F_Sj。
`F_Sj = A_S + B_S v_j + C_S v_j^2` ………(A.3)

### A.2 扭矩仪法模拟行驶阻力的计算
#### A.2.1 用公式（A.4）和公式（A.5）计算每个基准速度v_j下的算术平均速度v_jm和算术平均扭矩C_jm。
`v_jm = (1/k) ∑_{i=1}^{k} v_ji` ………(A.4)
`C_jm = (1/k) ∑_{i=1}^{k} (C_ji - C_js)` ………(A.5)
式中：
- v_jm——算术平均速度，单位为千米每小时（km/h）；
- C_jm——算术平均扭矩，单位为牛米（N·m）；
- v_ji——第j个基准速度点，第i个数据集的实际车速，单位为千米每小时（km/h）；
- k——单个测量中，数据集的个数；
- C_ji——数据中第i项的扭矩，单位为牛米（N·m）；
- C_js——速度偏移补偿项，由公式（A.6）给出。
    `C_js = (m_st + m_r) α_j r'` ………(A.6)
    速度偏移补偿项与算术平均扭矩之比应不大于0.05，如果α_j不大于±0.005 m/s²，可将其忽略。
    式中：
    - m_st——试验开始时车辆的质量，单位为千克（kg），应在预热程序开始前测量，但不能更早。
    - m_r——旋转质量，单位为千克（kg）。
    - α_j——平均加速度，单位为米每二次方秒（m/s²），按公式（A.7）计算。
    - r'——车轮动力学半径，单位为米（m），按公式（A.8）计算。
 `α_j = (1/3.6) × (k∑_{i=1}^{k} t_i v_ji - ∑_{i=1}^{k} t_i ∑_{i=1}^{k} v_ji) / (k∑_{i=1}^{k} t_i^2 - (∑_{i=1}^{k} t_i)^2)` ………(A.7)
 式中：t_i——第i个数据集的采样时间，单位为秒（s）。
 `r' = (1/3.6) × (v_jm / (2πN))` ………(A.8)
 式中：N——驱动轮转动频率，单位为每秒（s⁻¹）。

#### A.2.2 将C_jm通过最小二乘法计算模拟行驶阻力系数a_S、b_S和c_S。
`M_S = a_S + b_S v + c_S v^2` ………(A.9)

#### A.2.3 按公式（A.10）计算每个基准速度点v_j的模拟行驶阻力M_Sj。
`M_Sj = a_S + b_S v_j + c_S v_j^2` ………(A.10)

## 附录B（规范性）底盘测功机设置载荷的调整
### B.1 滑行法底盘测功机设定载荷调整
若底盘测功机上载荷是通过滑行法设定的，则底盘测功机设置载荷应按公式（B.1）和公式（B.2）调整。
`F_dj* = F_dj - (F_Sj - F_tj) = (A_d + A_t - A_S) + (B_d + B_t - B_S) v_j + (C_d + C_t - C_S) v_j^2` …………(B.1)
`A_d* = A_d + A_t - A_S`
`B_d* = B_d + B_t - B_S`
`C_d* = C_d + C_t - C_S` ………(B.2)
式中：
- F_dj——测功机载荷设定值，单位为牛（N）；
- F_dj*——测功机新载荷设定值，单位为牛（N）；
- F_Sj——基准速度v_j时的模拟道路载荷，单位为牛（N）；
- F_tj——基准速度v_j时的目标道路载荷，单位为牛（N）；
- A_d*、B_d*和C_d*——测功机新的设定系数。

### B.2 扭矩仪法底盘测功机设定载荷调整
若底盘测功机上载荷是通过扭矩仪法设定的，则底盘测功机设置载荷应按公式（B.3）和公式（B.4）调整。
`F_dj* = F_dj - (M_Sj - M_tj)/r' = {A_d + (a_t - a_S)/r'} + {B_d + (b_t - b_S)/r'} v_j + {C_d + (c_t - c_S)/r'} v_j^2` ………………(B.3)
`A_d* = A_d + (a_t - a_S)/r'`
`B_d* = B_d + (b_t - b_S)/r'`
`C_d* = C_d + (c_t - c_S)/r'` ………(B.4)
式中：
- M_Sj——基准速度v_j时的模拟行驶阻力，单位为牛米（N·m）；
- M_tj——基准速度v_j时的目标行驶阻力，单位为牛米（N·m）；
- A_d*、B_d*和C_d*——测功机新的设定系数；
- r'——车轮动力学半径，单位为米（m），由A.2.1计算得出。
