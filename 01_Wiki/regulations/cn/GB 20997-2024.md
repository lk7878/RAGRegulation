# GB 20997-2024 轻型商用车辆燃料消耗量限值及评价指标

## 1. 范围
本文件规定了轻型商用车辆燃料消耗量的限值、企业平均燃料消耗量计算方法及评价指标、生产一致性要求、同一型式判定和实施日期。
本文件适用于所有最大设计车速大于或等于50 km/h的N1类和最大设计总质量不超过3 500 kg的M2类车辆，包括能够燃用汽油或柴油燃料的车辆、纯电动车辆、燃料电池车辆以及燃用气体燃料和醇醚类燃料的车辆。
本文件不适用于作业类专用汽车。

## 3. 术语和定义
GB/T 15089、GB/T 17350、GB 18352.6—2016、GB/T 19596和GB 27999—2019界定的术语和定义适用于本文件。

## 4. 型式认证的申请
对某一车型或系族燃料消耗量的型式认证申请应由制造商或其法定代表人提出。
申请时应附有附录 A~附录 C 规定的相应车型的型式认证申请的报告，但不填写其中 A.7、B.7、C.5.3、C.6.3、C.7.3、C.7.4的内容。
应向负责型式认证试验的检测机构提交代表认证车型或系族的样车。

## 5. 燃料消耗量的确定
- **汽油、柴油、两用燃料及双燃料车型**：应按GB/T 19233—2020，采用全球统一轻型车测试循环（WLTC）确定车型燃料消耗量型式认证值。
- **可外接充电式混合动力车型**：应按GB/T 19753—2021，采用WLTC确定车型OVC-HEV燃料消耗量型式认证值及OVC-HEV电量消耗量型式认证值；电量消耗量应按GB/T 37340折算为相应燃料消耗量。**2030年及以前，由电量消耗量折算的燃料消耗量按零计算**。
- **不可外接充电式混合动力车型**：应按GB/T 19753—2021，采用WLTC确定车型NOVC-HEV燃料消耗量型式认证值。
- **纯电动车型**：应按GB/T 18386.1—2021确定能量消耗量型式认证值，并按GB/T 37340折算成对应的汽油燃料消耗量。**2030年及以前，其燃料消耗量按零计算**。
- **燃料电池车型**：应按GB/T 43252—2023确定能量消耗量。**2030年及以前，其燃料消耗量按零计算**。
- **压缩天然气车型**：应按照GB/T 29125确定气体燃料消耗量，并换算为汽油燃料消耗量。
- **液化天然气、液化石油气车型**：应按照GB/T 29125确定气体燃料消耗量，并换算为汽油燃料消耗量。
- **甲醇车型**：应按照QC/T 1130—2021确定甲醇燃料消耗量型式认证值和当量汽油或柴油燃料消耗量。对其他醇醚燃料车型，应按照QC/T 1130—2021确定醇醚燃料消耗量型式认证值和当量汽油或柴油燃料消耗量。
- **CO₂排放量参考值**：车型燃料消耗量限值及目标值对应的 CO₂ 排放量参考值分别按照 GB 19578—2021 中的 7.3 及 GB 27999—2019中的4.2.3公式计算。

## 6. 燃料消耗量限值
### 6.1 总则
- 能够燃用汽油或柴油燃料的轻型商用车辆，燃料消耗量限值按照6.2进行计算，结果圆整（四舍五入）至小数点后两位。
- 确定的车型燃料消耗量型式认证值应不高于6.2中的相应限值。
- 检测机构将确定的车型燃料消耗量型式认证值与相应限值进行比较，并将结果记录在附录A~C规定的相应车型的型式认证报告中。

### 6.2 车型燃料消耗量限值
#### 6.2.1 燃用汽油的N1类车型
燃料消耗量限值应按式(1)计算：
```
FC_L = {
    6.09, (TM ≤ 1190)
    0.00233 × (TM - 1750) + 8.13, (1190 < TM ≤ 2850)
    9.00, (TM > 2850)
}
```
式中：TM ——测试质量，kg；FC_L ——车型燃料消耗量限值，L/100 km。

#### 6.2.2 燃用柴油的N1类车型
燃料消耗量限值应按式(2)计算：
```
FC_L = {
    5.19, (TM ≤ 1190)
    0.00201 × (TM - 1750) + 6.81, (1190 < TM ≤ 2850)
    7.65, (TM > 2850)
}
```

#### 6.2.3 燃用汽油的M2类车型
燃料消耗量限值应按式(3)计算：
```
FC_L = {
    5.85, (TM ≤ 1190)
    0.00225 × (TM - 1750) + 9.35, (1190 < TM ≤ 2850)
    10.98, (TM > 2850)
}
```

#### 6.2.4 燃用柴油的M2类车型
燃料消耗量限值应按式(4)计算：
```
FC_L = {
    5.03, (TM ≤ 1190)
    0.00288 × (TM - 2098) + 7.65, (1190 < TM ≤ 2850)
    9.82, (TM > 2850)
}
```

### 6.3 具有特殊结构车型的说明
对于具有自卸结构的车辆，其限值是6.2中的相应限值乘以1.05，求得的数值结果圆整（四舍五入）至小数点后两位。

## 7. 企业平均燃料消耗量计算方法及评价指标
### 7.1 总则
- 车型燃料消耗量目标值按照7.2进行计算。对于纯电动、燃料电池、压缩天然气、液化天然气、液化石油气、醇醚等燃料类型车型，按照 7.2.1 计算 N1 类车型燃料消耗量目标值、按照 7.2.3 计算 M2 类车型燃料消耗量目标值。结果圆整（四舍五入）至小数点后两位。
- 对采用一种或多种循环外技术/装置的车辆，在计算7.4规定的企业平均燃料消耗量时，其车型燃料消耗量可相应减去一定额度（具体另行确定）。
- 企业平均燃料消耗量应满足7.5中相应的年度要求。

### 7.2 车型燃料消耗量目标值
#### 7.2.1 燃用汽油的N1类车型
燃料消耗量目标值应按式(5)计算：
```
T = {
    4.87, (TM ≤ 1190)
    0.00204 × (TM - 1750) + 5.70, (1190 < TM ≤ 2850)
    7.33, (TM > 2850)
}
```
式中：TM ——测试质量，kg；T ——车型燃料消耗量目标值，L/100 km。

#### 7.2.2 燃用柴油的N1类车型
燃料消耗量目标值应按式(6)计算：
```
T = {
    3.64, (TM ≤ 1190)
    0.00170 × (TM - 1750) + 4.77, (1190 < TM ≤ 2850)
    6.09, (TM > 2850)
}
```

#### 7.2.3 燃用汽油的M2类车型
燃料消耗量目标值应按式(7)计算：
```
T = {
    4.11, (TM ≤ 1190)
    0.00270 × (TM - 2098) + 6.56, (1190 < TM ≤ 2850)
    8.59, (TM > 2850)
}
```

#### 7.2.4 燃用柴油的M2类车型
燃料消耗量目标值应按式(8)计算：
```
T = {
    3.54, (TM ≤ 1190)
    0.00209 × (TM - 2098) + 5.37, (1190 < TM ≤ 2850)
    6.89, (TM > 2850)
}
```

### 7.3 企业平均燃料消耗量目标值（T_CAFC）
企业在某年度需要达到的企业平均燃料消耗量目标值应依据7.2规定的车型燃料消耗量目标值与对应年度生产或进口量乘积之和，除以该企业轻型商用车年度生产或进口总量计算得出。
```
T_CAFC = Σ(T_i × V_i) / Σ(V_i)
```
式中：T_CAFC ——企业平均燃料消耗量目标值，L/100 km；i、n ——车型序号；T_i ——第i个车型对应的燃料消耗量目标值，L/100 km；V_i ——第i个车型的年度生产或进口量。

### 7.4 企业平均燃料消耗量（CAFC）
#### 7.4.1 计算公式
企业在某年度的企业平均燃料消耗量用该企业根据第5章确定的各车型的燃料消耗量与对应的年度生产或进口量乘积之和，除以该企业轻型商用车年度生产或进口总量与车型核算倍数之积计算得出。
```
CAFC = Σ(FC_i × V_i) / Σ(V_i × W_i)
```
式中：CAFC ——企业平均燃料消耗量，L/100 km；FC_i ——第i个车型的燃料消耗量，L/100 km；V_i ——第i个车型的年度生产或进口量；W_i ——第i个车型对应的倍数。

#### 7.4.2 纯电动、燃料电池及满足GB/T 34598的PHEV车型倍数
- 2026年~2027年：W_i = 1.4
- 2028年~2029年：W_i = 1.2
- 2030年及以后：W_i = 1

#### 7.4.3 其他车型（燃料消耗量不大于目标值）倍数
- 2026年~2027年：W_i = 1.2
- 2028年~2029年：W_i = 1.1
- 2030年及以后：W_i = 1

#### 7.4.4 其他车型
除7.4.2及7.4.3规定的车辆外，W_i = 1。

### 7.5 企业平均燃料消耗量年度要求
自2026年起，各企业平均燃料消耗量与企业平均燃料消耗量目标值的比值不应大于下表规定的数值。

| 年度 | 企业平均燃料消耗量与企业平均燃料消耗量目标值的比值 |
| :--- | :--- |
| 2026年 | 124% |
| 2027年 | 124% |
| 2028年 | 115% |
| 2029年 | 115% |
| 2030年及以后 | 100% |

## 8. 生产一致性
- 汽油、柴油、两用燃料及双燃料车型：应满足GB/T 19233—2020有关生产一致性的要求。
- 混合动力车型：应满足GB/T 19753—2021有关生产一致性的要求。
- 纯电动车型：应满足GB/T 18386.1—2021有关生产一致性的要求。
- 其他车辆：应按照GB/T 19233—2020中规定的统计方法和合格数判定规则进行。

## 9. 同一型式判定
车型燃料消耗量如符合下述规定，则视为同一型式：
a) 发动机基本特性、参数和部件相同；
b) 排气污染控制装置相同；
c) 车身前部形状相同（对M2类及N1类客厢式车辆）或驾驶室前部形状相同（对N1类非客厢式车辆）；
d) 驱动型式相同；
e) 变速器型式相同；
f) 每一档位总传动比相同或变化不超过8%；
g) 由选装轮胎滚动周长不同引起的总速比变化不超过8%；
h) 基准质量和测试质量相同或减少，且基础车型燃料消耗量满足视同车型对应的限值要求；
i) 最大总质量相同或减少，且基础车型燃料消耗量满足视同车型对应的限值要求。

对于混合动力车型，除上述要求外，还应符合下列条件：
a) 混合动力汽车分类相同；
b) 储能装置单体型号、生产企业相同；
c) 储能装置总成总标称电压、总标称容量相同；
d) 驱动电机/发电机的型号、位置、数量、生产企业相同；
e) 控制系统软件版本号和硬件型号及生产企业相同（不影响结果时允许软件版本号变更）；
f) 冷却型式相同。

对于同一二类底盘形成的普通货车以及具有厢式、罐式、仓栅式等结构的车辆，在满足相关条件时，可以相互视同。
