# GB 4660-1994 汽车前雾灯配光性能

## 1 主题内容与适用范围
本标准规定了汽车前雾灯配光性能、试验方法和检验规则。
本标准适用于M、N类汽车使用的各种类型的前雾灯。

## 2 引用标准
GB 4599 汽车前照灯配光性能
GB 4785 汽车及挂车外部照明和信号装置的数量、位置和光色

## 3 术语
### 3.1 前雾灯
在雾、雪、雨或尘埃弥漫等有碍可见度的情况下，为改善车辆前部道路照明和使迎面来车易于发现车辆的灯具。

## 4 前雾灯同一型式的规定
在以下主要方面没有差异的前雾灯被视为同一型式：
a. 商品名称和商标；
b. 光学系统的特性；
c. 包括能通过反射、折射或吸收改变光学效果的外加附件；
d. 半封闭式前雾灯使用的灯泡型式。

## 5 一般规定
### 5.1
前雾灯应设计和制造成在正常使用条件下，即使受到振动，仍能保证满足使用要求和符合本标准的配光性能要求。
### 5.2
对于半封闭式前雾灯的灯泡安装，应满足即使在黑暗中也能将灯泡装在正确的位置上，即定位卡脚能准确进入定位槽中（尺寸配合适当），并当灯泡装错位置时会明显歪斜。
### 5.3
前雾灯的光色和色度特性应符合GB 4785的规定。

## 6 前雾灯使用的封闭式灯光组和灯泡要求
### 6.1
封闭式灯光组的电压和功率应参照半封闭式前雾灯使用的灯泡规定。
### 6.2
半封闭式前雾灯使用的灯泡产品应符合表1的规定。
**表1 半封闭式前雾灯用灯泡参数**
| 类别 | 灯泡型号 | 标称电压, V | 标称功率, W | 试验电压, V | 在试验电压下 | 灯头型号 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | 功率 | 光通量, lm |
| 白炽灯 | F2 | 12/24 | 35 | 13.2/28.0 | 35±10% | 650±20% (注) | BA20s |
| 卤钨灯 | H1 | 12/24 | 55 | 13.2/28.0 | 68 max | 1450±15% (注) | P14.5s |
| | H2 | 12/24 | 55 | 13.2/28.0 | 68 max | 1750±15% (注) | X511 |
| | H3 | 12/24 | 55 | 13.2/28.0 | 68 max | 1000±15% (注) | PK22s |
| | H4(近光灯丝) | 12/24 | 70 | 13.2/28.0 | 84 max | 1200±15% (注) | P43t-38 |
*注：括号内的数据仅适合轿车以外的车辆使用。光通量公差：F2为±20%，H1/H2/H3/H4为±15%（括号内为±20%）。*

## 7 配光性能
### 7.1
配光性能应在前雾灯基准中心前25m，过HV点的铅垂配光屏幕上测定。
### 7.2
灯光投射到配光屏幕上，在v-v线左侧和右侧，应产生宽度不小于225cm清晰的水平明暗截止线。
### 7.3
配光屏幕上各测试区域照度限值应符合表2的规定。
**表2 配光屏幕照度限值**
| 测试区域 | 区域范围 | 照度限值, lx |
| :--- | :--- | :--- |
| | | 最大值 | 最小值 |
| A区 | 距v-v线两侧225cm的垂直线与h-h线以及距其75cm的水平线所围成的区域 | 1.0 | 0.15 |
| B区 | 距v-v线两侧1250cm的垂直线与h-h线以及距其150cm的水平线所围成的区域(A区除外) | 1.0 | — |
| C区 | 距v-v线两侧1250cm的垂直线与距h-h线向上150cm以上区域，但其中h-h线向上15°(669.9cm)以上区域的发光强度不得大于200cd | 0.5 | — |
| D区 | 距v-v线两侧450cm的垂直线与距h-h线向下75cm和150cm的水平线所围成的区域 | 1.5³ | — |
| E区 | 距v-v线两侧450cm和1000cm的垂直线与距h-h线向下75cm和150cm的水平线所围成的区域 | 0.5³ | — |
*注1：具体区域划分见标准中图示。*
*注2：各区边界线上的照度限值，应符合所在区域要求；两区共有的边界线上的照度限值，则应符合较严格的限值要求。*
*注3：该区域内任意一条垂直线上，应至少能找到一点符合本限值要求。*
### 7.4
前雾灯无论白色或黄色，其配光实测照度均应符合表2的规定。
### 7.5
在B和C区内，其水平方向相邻间的照度应无明显的陡变，不致影响良好的可见度。
### 7.6
配光屏幕上照度测试的有效面积，应包含在边长为65mm的正方形内。

## 8 试验方法
### 8.1
试验暗室、装置及设备应符合GB 4599的规定。
### 8.2 配光测试时的电压和光通量
#### 8.2.1
封闭式前雾灯，配光测试均规定在标称电压下进行。
#### 8.2.2
半封闭式前雾灯，配光测试应由标准灯泡，在表3规定的配光光通量下进行。
**表3 半封闭式前雾灯配光测试用光通量**
| 类别 | 灯泡型号 | 在12V左右的光通量, lm |
| :--- | :--- | :--- |
| 白炽灯 | F2 | 520 |
| 卤钨灯 | H1 | 1150 |
| | H2 | 1300 |
| | H3 | 1100 |
| | H4(近光灯丝) | 750 |
### 8.3
配光测试前应将灯泡或封闭式灯光组以测试时的电压点燃，使其性能趋于稳定。
### 8.4 配光测定前的照准
#### 8.4.1 垂直方向
应使光束的明暗截止线置于h-h线下50cm。
#### 8.4.2 水平方向
应使光束的最亮区域中心置于v-v线上。

## 9 检验规则
### 9.1
前雾灯配光性能检验有两种：
a. 型式检验；
b. 产品一致性检验。
### 9.2
半封闭式前雾灯配光性能检验应装以标准灯泡，在有异议时，允许更换标准灯泡重新测定。
### 9.3
半封闭式前雾灯装置的灯泡，应是经认证的产品。
### 9.4 前雾灯配光性能的型式检验
#### 9.4.1
前雾灯同一型式判定要求，按本标准第4章的规定。
#### 9.4.2
产品制造者应提供：
a. 足以识别该型式前雾灯特性的图纸一式三份，包括配光镜详细的特性结构图；
b. 前雾灯样灯2只（半封闭式前雾灯还应包含灯泡）。
#### 9.4.3
每只样灯均应符合本标准第5和6章的规定。
#### 9.4.4
按本标准第8章的试验方法进行试验，每只样灯均应符合本标准第7章的规定。
### 9.5 前雾灯配光性能的产品一致性检验
#### 9.5.1
对已经型式检验合格的产品，以随机抽取的样灯来判定其产品的一致性，抽样方法另行规定。
#### 9.5.2
随机抽取的样灯，应符合本标准的第5和6章的规定。
#### 9.5.3
按本标准第8章试验方法，随机抽取的样灯，应符合本标准第7章的规定。
