# 汽车风窗玻璃刮水器、洗涤器的性能要求及试验方法

## 1 主题内容与适用范围
本标准规定了汽车风窗玻璃刮水器、洗涤器的性能要求和试验方法。
本标准适用于M1类汽车。

## 2 引用标准
GB 11556 汽车风窗玻璃除霜系统的性能要求及试验方法

## 3 术语
### 3.1 刮水器刮片
装有刮水胶条用以刮刷风窗玻璃外表面的部件。
### 3.2 刮水器刮刷面积
刮水器刮片刷过的风窗玻璃外表面上的面积。
### 3.3 喷嘴
将洗涤液引向风窗玻璃外表面的器件。喷嘴方向是可调的。
### 3.4 喷射性
在洗涤器系统正常工作情况下喷嘴喷射洗涤液至风窗玻璃目标位置上的能力。
### 3.5 洗涤液
硬度低于205g/t的水并加入适量商用添加剂的水溶液。
### 3.6 目标位置
由汽车制造厂家规定的，洗涤液喷射到风窗玻璃外表面上的位置。

## 4 性能要求
每辆汽车均须装备刮水器和洗涤器。

### 4.1 风窗玻璃刮水器系统
#### 4.1.1
刮水器的刮刷面积应覆盖A区域的98%以上，B区域的80%以上。A、B区域按GB 11556中第5章有关规定进行确定。
#### 4.1.2
刮水器系统至少应具备两种刮刷频率。高频必须不小于45次/min，低频不得小于20次/min，且高频与低频之差应不小于15次/min（刮水器工作时刮片的一个往返运动为一次）。
#### 4.1.3
刮水器关闭时，刮片应自动返回至其初始位置。
#### 4.1.4
刮水器工作时能承受15s的外力阻挡负荷，之后所有部件仍能工作。
#### 4.1.5
刮水器系统在外界温度-18±3℃的干燥风窗上应能持续工作2min。对刮刷面积不作特定要求。

### 4.2 风窗玻璃洗涤器系统
#### 4.2.1
洗涤器应有能力在常温下供给足够的液体，将占A区域60%以上的面积清洗干净。
#### 4.2.2
洗涤器应能承受喷嘴被堵塞时的负荷，经过堵塞试验后，洗涤器仍具有喷射性。
#### 4.2.3
洗涤器应能承受温度试验，在经过5.2.3、5.2.4、5.2.5、5.2.6试验后，该系统仍具有喷射性。
#### 4.2.4
洗涤器贮液罐容量不得小于1L。

## 5 试验方法
### 5.1 风窗玻璃刮水器系统
#### 5.1.1 试验条件（另有规定的试验条件除外）
a. 环境温度应在10~40℃之间；
b. 风窗玻璃应保持潮湿；
c. 蓄电池电压不得低于额定电压，且不能超过额定电压2V；
d. 发动机转速必须接近但不得超过最大功率转速的30%；
e. 接通近光前照灯；
f. 让暖风系统（或冷气系统），通风系统，除霜除雾系统在最大负荷下工作。

#### 5.1.2 刮刷频率试验
刮水器在湿风窗玻璃上预先工作20min后，检测其刮刷频率。

#### 5.1.3 刮刷面积试验
a. 用甲醇，酒精或其他等效的去污剂彻底除去风窗外表面上的油渍和污染物；
b. 干燥后用3%~10%的氨水清洗，待干后再用软棉布擦净整个风窗外表面；
c. 在风窗外表面上均匀地涂上附录A（补充件）规定的试验用混合液，并使之干燥；
d. 起动刮水器，采用低频率使其工作5~10个工作循环后停止。在风窗玻璃外表面上绘出实际刮刷面积轮廓线；
e. 计算出实际刮刷面积占A、B区域面积的百分比。

#### 5.1.4 刮水器系统强度试验
刮水器在高频状态下工作，在刮水器刮臂处施加一阻力使刮臂停摆并持续15s，系统应符合4.1.4的要求。

#### 5.1.5 低温性能试验
汽车在-18±3℃的环境温度中至少放置4h，风窗玻璃表面干燥，刮水器在高频速度下工作应符合4.1.5的要求。

### 5.2 风窗玻璃洗涤器系统
#### 5.2.1 洗涤器洗涤能力试验
a. 在10~40℃的环境中将洗涤器贮液罐注满洗涤液，调节洗涤器喷嘴，使其对准风窗外表面的目标位置；
b. 试验过程中应无明显的风作用，其他试验条件同5.1.1中的c,d,e,f各项规定；
c. 风窗玻璃外表面按5.1.3中a,b,c项规定进行处理；
d. 开动洗涤器和刮水器，用高频速度使刮水器工作10个工作循环，测定并计算被清洗视野区域的面积百分比。

#### 5.2.2 洗涤器系统强度试验
a. 洗涤器系统注满水，在20±2℃的环境中至少放置4h；
b. 蓄电池电压不得低于额定电压，且不能超过额定电压2V；
c. 堵住所有喷嘴，在1min内开关洗涤器6次，每次至少持续3s；
d. 验证洗涤器系统的喷射性。

#### 5.2.3 洗涤器系统冻结强度试验
a. 蓄电池电压不得低于额定电压，且不得超过额定电压2V；
b. 洗涤器系统注满水，在-18±3℃的环境中至少放置4h，使洗涤器中的水全部结冰；
c. 在1min内开关洗涤器6次，每次至少持续3s；
d. 在20±2℃的环境中让该系统里的冰全部融化。然后，按5.2.2规定进行试验。

#### 5.2.4 洗涤器系统冻结-解冻温度循环试验
洗涤器系统注满水，在-18±3℃的环境中至少放置4h，使洗涤器系统中的水全部结冰，此后将装置置于20±2℃的环境中，直至冰块全部融化，以这样的冻结-融化作为一个循环，反复进行6个循环。然后，按5.2.2规定进行试验。

#### 5.2.5 风窗洗涤器系统低温试验
洗涤器系统内注满洗涤器的低温风窗洗涤液，该液体成分是50%甲醇或异丙醇和50%硬度不大于205g/t的水，将系统放置在-18±3℃的环境中至少4h，使整个系统的温度处于稳定状态。然后，按5.2.2中的b,c,d项规定进行试验。

#### 5.2.6 洗涤器系统高温试验
a. 洗涤器系统注满水，将系统放置在80±3℃的环境中至少8h，然后放在20±2℃的环境中，使整个系统的温度处于稳定状态。按5.2.2规定进行试验；
b. 洗涤器系统注满水，将系统放置在80±3℃的环境中至少8h（如果该系统的任何部件均不在发动机仓内，则温度为60±3℃）。然后按5.2.2中的b,c,d项规定进行试验。

### 5.3
应在同一个风窗洗涤器上进行5.2.2~5.2.6规定的全部风窗洗涤器试验。

## 附录A 汽车风窗玻璃刮水器、洗涤器试验用混合液规格（补充件）
试验用混合液应由下列物质组成（体积百分比）：92.5%硬度不大于205g/t的水；5%饱和食盐水溶液(NaCl)；按表A1和表A2配成的2.5%灰尘。

**表A1 试验用灰尘成分**
| 成分 | 质量分配, % |
| :--- | :--- |
| SiO2 | 67~69 |
| Fe2O3 | 3~5 |
| Al2O3 | 15~17 |
| CaO | 2~4 |
| MgO | 0.5~1.5 |
| 总碱量 | 3~5 |
| 烧失量 | 2~3 |
注：1)“总碱量”的英文名称为“Alkalis”。 2)“烧失量”的英文名称为“Ignition Loss”。

**表A2 灰尘颗粒尺寸的分配**
| 颗粒度，μm | 质量分配, % |
| :--- | :--- |
| 0~5 | 12±2 |
| 5~10 | 12±3 |
| 10~20 | 14±3 |
| 20~40 | 23±3 |
| 40~80 | 30±3 |
| 80~200 | 9±3 |
