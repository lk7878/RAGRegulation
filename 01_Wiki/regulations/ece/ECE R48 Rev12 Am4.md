**Amendment Details**

This document is **Amendment 4** to **Revision 12** of **Addendum 47** to **UN Regulation No. 48**. It forms **Supplement 8 to the 06 series of amendments**.

*   **Date of Entry into Force:** 22 June 2017
*   **Document Date:** 26 July 2017
*   **Authentic Legal Text:** ECE/TRANS/WP.29/2016/80

**Amended Provisions**

This amendment modifies specific paragraphs and annexes concerning tell-tale requirements and conspicuity markings.

**1. Tell-tale Requirements (Paragraph Revisions)**

The amendment updates several paragraphs to clarify or modify tell-tale (indicator) requirements for various lighting functions, consistently adding a clause making a failure-indicating tell-tale mandatory if required by the relevant component regulation.

*   **Paragraph 6.7.8. (Stop Lamps):** Tell-tale is optional. However, if a failure tell-tale is required by the component regulation, it is mandatory. If fitted, it must be a non-flashing warning light that activates upon stop lamp malfunction.
*   **Paragraph 6.9.8. (Front Position Lamps):** Circuit-closed tell-tale is mandatory (non-flashing). This requirement is waived if panel lighting can only be turned on with front position lamps, or if the light-signalling system operates per paragraph 6.2.7.6.2. A failure-indicating tell-tale is mandatory if required by the component regulation.
*   **Paragraph 6.10.8. (Rear Position Lamps):** Circuit-closed tell-tale is mandatory and must be combined with the front position lamp tell-tale. The requirement is waived if the light-signalling system operates per paragraph 6.2.7.6.2. A failure-indicating tell-tale is mandatory if required by the component regulation.
*   **Paragraph 6.13.8. (End-Outline Marker Lamps):** Tell-tale is optional. If fitted, its function must be performed by the tell-tale for the front and rear position lamps. A failure-indicating tell-tale is mandatory if required by the component regulation.
*   **Paragraph 6.19.8. (Daytime Running Lamps):** Closed-circuit tell-tale is optional. A failure-indicating tell-tale is mandatory if required by the component regulation.

**2. Conspicuity Markings on Flexible Bodywork (Paragraph 6.21.1.2.4.)**

The amendment clarifies the installation rules for conspicuity markings (line markings) on vehicles with flexible bodywork material:
*   If the bodywork is **partially flexible**, the line marking must be installed on rigid part(s) of the vehicle. The remaining portion of the conspicuity markings may be fitted on the flexible material.
*   If the bodywork is **fully flexible**, the line marking may be fitted on the flexible material.

**3. Annex 1 Updates (Item 9.)**

New sub-items are inserted into the approval form (Annex 1) to document the presence of the newly mandated failure-indicating tell-tales for specific lamp categories:
*   9.9.1.: Tell-tale indicating failure (as per component regulation) fitted for **Stop Lamps**.
*   9.11.1.: Tell-tale indicating failure (as per component regulation) fitted for **Front Position Lamps**.
*   9.12.1.: Tell-tale indicating failure (as per component regulation) fitted for **Rear Position Lamps**.
*   9.15.1.: Tell-tale indicating failure (as per component regulation) fitted for **End-Outline Marker Lamps**.
*   9.21.1.: Tell-tale indicating failure (as per component regulation) fitted for **Daytime Running Lamps**.

For each, the entry is to be marked "yes" or "no" as applicable.
