# UN Regulation No. 75 - Revision 2 - Amendment 5

## 概述
本文件是《关于采用轮式车辆、其装备和部件的统一技术法规以及基于这些联合国法规批准互认条件的协定》框架下，对**联合国第75号法规（关于L类车辆充气轮胎认证的统一规定）第2版**的第5次修正案（Supplement 18）。本修正案于2020年1月11日生效。

## 主要修订内容
本修正案主要针对适用于高速（速度超过240 km/h）的轮胎，修订了标识、额定载荷与速度的关系以及相应的测试要求。

### 1. 定义与标识 (Definitions and Markings)
*   **2.31.3.**：修订了高速轮胎的字母代码标识规则。
    *   适用于最高速度超过240 km/h但低于270 km/h的轮胎，应使用字母代码 **"V"** 标识。
    *   适用于最高速度达到或超过270 km/h的轮胎，应使用字母代码 **"Z"** 标识。
    *   该字母代码应置于轮胎尺寸规格中，结构指示之前。
*   **3.1.14.**：要求适用于速度超过240 km/h的轮胎，应标记相应的字母代码 **"V"** 或 **"Z"**。
*   **3.1.15.**：新增要求，适用于速度超过240 km/h但低于270 km/h的轮胎，应在括号内标记在210 km/h速度下适用的负荷指数，以及参考速度类别符号 **"V"**。
*   **3.1.16.**：新增要求，适用于速度超过270 km/h的轮胎，应在括号内标记在240 km/h速度下适用的负荷指数，以及参考速度类别符号 **"W"**。

### 2. 性能要求 (Performance Requirements)
*   **2.36.3.**：修订了速度类别符号为 **"V"** 的轮胎，在速度超过210 km/h但不超过240 km/h运行时，最大额定载荷相对于其负荷指数对应质量的百分比规定（见下表）。
*   **2.36.4.**：新增规定，适用于速度类别符号为 **"V"** 且字母代码为 **"V"** 的轮胎（速度超过240 km/h但低于270 km/h），其最大额定载荷相对于其负荷指数对应质量的百分比规定（见下表）。
*   **2.36.5.**：新增规定，适用于速度类别符号为 **"W"** 且字母代码为 **"Z"** 的轮胎（设计速度达270 km/h及以上），其最大额定载荷相对于其负荷指数对应质量的百分比规定（见下表）。
*   **2.36.6.**：重新编号并修订了原2.36.4.条款，规定适用于速度类别符号为 **"W"** 且字母代码为 **"Z"** 的轮胎（设计速度超过270 km/h），在超过270 km/h速度下运行时，最大额定载荷的计算方法。

**额定载荷与速度关系表摘要：**

| 适用条款 | 轮胎标识 (速度类别符号 / 字母代码) | 速度范围 (km/h) | 最大额定载荷 (百分比) 示例 |
| :--- | :--- | :--- | :--- |
| 2.36.3. | V / (未指定) | 210 | 100% |
| | | 220 | 95% |
| | | 230 | 90% |
| | | 240 | 85% |
| 2.36.4. | V / V | 240 | 85% |
| | | 250 | 80%* |
| | | 260 | 75%* |
| | | 270 | 70%* |
| 2.36.5. | W / Z | 240 | 100% |
| | | 250 | 95% |
| | | 260 | 85% |
| | | 270 | 75% |

*注：带*的数值适用于轮胎制造商规定的最高速度以下，且该最高速度应低于270 km/h。对于中间速度，允许对最大额定载荷进行线性插值。*

### 3. 认证与测试 (Approval and Testing)
*   **4.1.15.**：修订了申请批准时需提交的信息，对于字母代码为 **"V"**（速度>240 km/h但<270 km/h）或 **"Z"**（速度>270 km/h）的轮胎，需提供轮胎制造商允许的最高速度及在该速度下的承载能力。
*   **6.2.1.1.**：修订了负载/速度测试要求，针对上述高速轮胎，需分别在括号内标记的条件和制造商规定的最大条件（如适用）下进行测试。
*   **7.1.4.**：允许对上述高速轮胎进行批准扩展（针对不同的最大速度和/或载荷），但需提供新的测试报告。
*   **附件7 (Annex 7)**：修订了高速耐久性试验程序，包括试验载荷（制造商规定最大载荷的65%）、初始试验速度和最大试验速度的确定方法。

### 4. 过渡条款 (Transitional Provisions)
*   **12.**：新增过渡条款。
    *   自本修正案（原法规Supplement 18）正式生效之日起，各缔约方不得拒绝根据其授予或接受型式批准。
    *   自**2020年9月1日起**，各缔约方不得对不符合本修正案规定的轮胎根据原法规版本授予型式批准。
    *   对于在**2020年8月31日之前**首次获得型式批准的轮胎，各缔约方可在不考虑本修正案规定的情况下继续批准其扩展。
