**Amendment Details**

This document constitutes **Amendment 10** to **UN Regulation No. 83, Revision 5** (Addendum 82). It provides uniform provisions concerning the approval of vehicles with regard to the emission of pollutants according to engine fuel requirements.

**Key Dates**
*   **Date of Entry into Force:** 29 May 2020
*   **Document Date:** 1 July 2020

**Authentic Text Reference**
The authentic and legally binding text for this amendment is: **ECE/TRANS/WP.29/2019/127**.

**Specific Amendments**

This amendment modifies the following sections of UN Regulation No. 83:

1.  **Annex 7, Paragraph 7.4.4.3.**
    *   **Change:** Allows for an alternative purge test procedure at the manufacturer's request, provided it is presented to and accepted by the Technical Service during the type approval procedure.

2.  **Annex 8, Paragraph 3.2.1.**
    *   **Change:** Specifies that the start of engine, start of sampling, and operation of the first cycle shall be in accordance with **Table A4a/1 and Figure A4a/1 in Annex 4a** to this Regulation.

3.  **Appendix 1 to Annex 11, Paragraph 6.5.3.5**
    *   **Change:** Details requirements for fault code identification when a fault is registered.
 *   The manufacturer must identify the fault using an appropriate ISO/SAE controlled fault code from specified standards relating to "emission related system diagnostic trouble codes".
 *   If such identification is not possible, manufacturer-controlled diagnostic trouble codes may be used according to the same standard.
 *   Fault codes must be fully accessible by standardized diagnostic equipment.
 *   The vehicle manufacturer must provide details of any emission-related diagnostic data (e.g., PIDs, OBD monitor IDs, Test IDs) not specified in the standard listed in paragraph 6.5.3.2.(a) but related to this Regulation to a national standardization body.

4.  **Annex 14, Paragraph 3.1.1.**
    *   **Change:** Requires two tests under specified conditions for vehicles with electrical energy/power storage devices:
 *   **Condition A:** Test started with a **fully charged** device.
 *   **Condition B:** Test started with the device in **minimum state of charge** (maximum discharge of capacity).
 *   Refers to Appendix 1 for the State of Charge (SOC) profile during the Type I test.

5.  **Annex 14, Paragraph 3.2.1.**
    *   **Change:** Significantly expands requirements for testing hybrid vehicles, specifying two test conditions and detailed operating mode selection criteria:
 *   **3.2.1.1. Condition A:** Test started with a **fully charged** electrical energy/power storage device.
 *   **3.2.1.2. Condition B:** Test started with the device in **minimum state of charge** and carried out in a **charge-sustaining** operating condition (maintaining a neutral charging balance on average).
 *   **3.2.1.3.** Excludes certain operating modes from testing (e.g., 'charge mode', 'maintenance mode', 'mountain mode') if agreed with the authority and justified by the manufacturer. The Technical Service must ensure emission limits are not exceeded in all hybrid modes (except 'maintenance mode').
 *   **3.2.1.4.** Provides detailed rules for selecting the operating mode for both Condition A and Condition B, prioritizing a single, always-selected mode if it exists, or otherwise selecting the most energy-consuming (for A) or fuel-consuming (for B) mode.
