# UN Regulation No. 75 - Pneumatic Tyres for L-Category Vehicles

## 概述
本法规规定了用于L类车辆（摩托车、轻便摩托车等）的新充气轮胎的统一技术要求和批准条件。本次修订2/修正案2于2015年10月8日生效，主要引入了针对全地形（AT）轮胎的具体规定。

## 适用范围
本法规适用于L类车辆的新充气轮胎。
**不适用于**：
- 专门为“非公路”使用设计并标有“NHS”（非公路服务）的轮胎类型。
- 专门为竞赛设计的轮胎类型。

## 主要修订内容 (Rev.2/Amend.2)
本次修正案主要增加了关于全地形（AT）轮胎的规定。

### 1. 定义新增
- **2.16.4**: 为全地形（AT）轮胎增加了前缀“AT”（例如：AT 18x11-8）。
- **2.34**: 定义了“AT（全地形）轮胎”：指主要为L6和L7类车辆装备而设计的低压轮胎。

### 2. 技术要求新增
- **3.1.15**: 规定了全地形（AT）轮胎的参考充气压力标识符号：
    | 符号 | 参考充气压力 (kPa) |
    | :--- | :--- |
    |  | 25 |
    |  | 35 |
    |  | 45 |
- **4.1.16**: 要求全地形（AT）轮胎上必须标有上述参考充气压力符号。

### 3. 尺寸规格 (Annex 5, Table 8)
新增了“全地形车辆（AT）用轮胎”尺寸表，包含了从AT16x6-8到AT27x12-12等多种规格的详细尺寸参数（测量轮辋宽度代码、断面宽度、外直径最小值/名义值/最大值、最大总宽度）。

**注**：对于子午线结构的轮胎，用字母“R”代替尺寸中的“-”（例如：AT16x6 R 8）。对于本表中未包含的轮胎规格，可参考指定的国际轮胎标准（ETRTO、TRA、JATMA或STRO）中的相关尺寸数据。

### 4. 测试条件 (Annex 6 & Annex 7)
在轮胎强度试验（ Annex 6）和轮胎耐久性试验（ Annex 7）的测试条件表中，增加了全地形（AT）轮胎的测试充气压力要求，对应上述三种压力符号（, , ）分别为25 kPa (0.25 bar)、35 kPa (0.35 bar)和45 kPa (0.45 bar)，适用于所有速度等级。

### 5. 负荷-速度特性 (Annex 8)
新增了用于速度符号为“F”的全地形轮胎（AT）的负荷-速度变化表：
| 速度 (km/h) | 负荷能力变化 (%) |
| :--- | :--- |
| 50及以下 | +12 |
| 60 | +7 |
| 70 | +3 |
| 80 | 0 |
| 90 | -5 |
| 100 | -10 |
| 110 | -15 |
| 120 | -20 |
| 130 | -25 |
