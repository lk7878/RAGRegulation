# Amendment 4 to UN Regulation No. 122

**Document Reference:** E/ECE/324/Rev.2/Add.121/Amend.4− /ECE/TRANS/505/Rev.2/Add.121/Amend.4
**Date:** 2 November 2018
**Entry into Force:** 16 October 2018
**Authentic Legal Text:** ECE/TRANS/WP.29/2018/27

This document constitutes **Amendment 4** to **UN Regulation No. 122**, which contains uniform provisions concerning the approval of vehicles of categories M, N and O with regard to their heating systems.

## Amendment Content

The amendment modifies paragraph **6.2.1.** of the regulation.

### Revised Paragraph 6.2.1.

"6.2.1. The following table indicates which annexes apply to each type of heating system within each vehicle category:

| Heating system | Vehicle category | Annex 4 Air quality | Annex 5 Temperature | Annex 6 Exhaust | Annex 8 LPG safety |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Engine waste heat - water | M | | | | |
| | N | | | | |
| | O | | | | |
| Engine waste heat - air<br>See Note 1 | M | Yes | Yes | | |
| | N | Yes | Yes | | |
| | O | | | | |
| Engine waste heat - oil | M | Yes | Yes | | |
| | N | Yes | Yes | | |
| | O | | | | |
| Gaseous fuel heater -<br>See Note 2 | M | Yes | Yes | Yes | Yes |
| | N | Yes | Yes | Yes | Yes |
| | O | Yes | Yes | Yes | Yes |
| Liquid fuel heater<br>See Note 2 | M | Yes | Yes | Yes | |
| | N | Yes | Yes | Yes | |
| | O | Yes | Yes | Yes | |
| Electric heater<br>See Note 2 | M | | Yes | | |
| | N | | Yes | | |
| | O | | Yes | | |

**Note 1:** Heating systems which comply with the requirements of Annex 3 are exempt from these test requirements.
**Note 2:** Heaters located outside the passenger compartment, using water as a transfer medium, are deemed to comply with Annexes 4 and 5."
