# 法规概述
本法规（ECE R52）规定了用于搭载不超过22位乘客（不含司机）的小型公共汽车（M2和M3类车辆）在结构方面的统一认证要求。法规旨在确保此类车辆在乘客安全、出口、内部布置、防火等方面的基本安全性能。

# 适用范围
1.  适用于单层刚性车辆类别M2和M3，设计并制造用于搭载有座椅和站立的乘客，除司机外容量不超过22位乘员的小型公共汽车。
    1.1  对于搭载行为受限的乘客有关技术法规不在本法规范围内。在本法规的有关附录正式修正之前，签约方可以使用附加的要求来确保在这种情况下车辆和乘客的安全。

# 核心定义
*   **车辆**：M2和M3类别下的单层机动车，设计并制造用于搭载有座椅和站立的乘客，其容量除司机外不超过22人。分为：
    *   **A型**：允许搭载站立乘客。
    *   **B型**：不允许搭载站立乘客。
    *   **低地板车辆**：车内至少有35%的面积能够用于站立的乘客，并且形成一个单独的区域，该区域内没有台阶，并且至少能够通过一个距地面只有一阶台阶的乘客门就可到达。
*   **乘客门**：驾驶员坐在座椅上进行正常操作的情况下由乘客使用的车门。
*   **安全门**：除乘客门之外附加的车门，在特殊情况下，特别是在紧急情况下为乘客提供出口。
*   **安全窗**：1扇没有安装玻璃的车窗，只有在紧急情况下才可以用作乘客的出口。
*   **安全出口**：安全门、安全窗或者安全顶窗。
*   **出口**：乘客门或者安全出口。
*   **通道**：为乘客提供的通过空间，使之可以从任何一个座椅或者某排座椅到达任何其它座椅或其它排座椅或引道，以及从引道到达任何乘客门或者车内楼梯。
*   **引道**：从乘客门通往车辆最高的台阶(通道的边缘)的延伸空间。
*   **净重 (MK)**：在行驶条件下空车的质量，加上75kg驾驶员体重、制造厂规定的油箱容量的90%燃油的质量以及冷却液、润滑液、工具和备胎的质量。
*   **空载质量 (MV)**：在净重(MK)基础上，加上乘务员质量（每位75kg）、附加液体箱90%容积的质量等。
*   **技术允许最大质量 (MT)**：由车辆制造厂公布的车辆最大满载质量。
*   **乘客舱**：提供给乘客使用的空间，不包括用固定的设施间隔出来的空间，如酒吧、厨房、卫生间或者行李间。

# 技术要求摘要
## 5.1 车轴的负荷分配和负荷条件
*   规定了车辆在空载和负载（按5.1.4定义）两种状态下，前轴需承担的最小负荷比例。
*   **表：前轴最小负荷比例**
    | 负荷状况 | A级 | B级 |
    | :--- | :--- | :--- |
    | 空载 | 20% | 25% |
    | 负载 | 25% | 25% |

## 5.2 乘客区域
*   定义了乘客可利用的总面积S0和站立乘客有效面积S1（仅A型车）的计算方法，需扣除驾驶舱、台阶、低矮区域等面积。

## 5.3 乘客容量
*   乘客总数N的计算需同时满足面积和质量的约束条件。
*   **表：计算参数取值**
    | 等级 | Q(kg) | Ssp(m²/站立乘客) | L(kg/m³) | R(kg/m²) |
    | :--- | :--- | :--- | :--- | :--- |
    | A | 68 | 0.125 | 100 | 75 |
    | B | 71 | (非站立乘客) | 100 | 75 |
*   车内前门附近应有明显标志，标明座椅数(Ps)、客容量(N)和轮椅数（如有）。

## 5.4 车体的强度
*   （仅B型车辆）车体结构在车顶必须具有足够的强度，能承受均匀分布的静力负荷等于车辆的技术允许最大载重。

## 5.5 火灾保护
*   对发动机舱材料、燃油加油孔位置和密封性、油箱固定与防护、燃油供给系统、安全开关、电气设备与线束、电池、灭火器与急救设施、材料耐热性等提出了详细要求。

## 5.6 出口
### 5.6.1 数量
*   每个车辆至少要有2个出口（1扇乘客门+1扇安全门，或2扇乘客门）。
*   动力操作门必须能在紧急情况下手动打开才被视为出口。
*   **表：安全出口及安全顶窗最低数量**
    | 乘客数量 | 出口数量 | 安全顶窗可替代的安全出口数量 |
    | :--- | :--- | :--- |
    | | | 允许 | 要求 |
    | ≤16 | 3 | 1 | |
    | >16 | 4 | 1 | |
*   双门计为2个出口，双窗计为2个安全窗。

### 5.6.2 位置
*   乘客门应位于临近路边一侧或车辆尾部。
*   车辆每一侧至少有一个出口。
*   乘客舱前半部分和后半部分都至少有一个出口。
*   除非安装了顶窗，否则车辆前部或尾部至少要有一个出口。

### 5.6.3 最小尺寸
*   **表：出口最小尺寸要求**
    | 出口类型 | 尺寸要求 | 备注 |
    | :--- | :--- | :--- |
    | **乘客门** | **入口高度**：A级 165cm，B级 150cm | 测量从门中心上水平面到最低台阶上部的高度。 |
    | | **开口高度**：允许5.7.1.1条规定的双样板通过 | 门上角圆角半径≤15cm。 |
    | | **宽度**：单门 65cm，双门 120cm | B级车门高140-150cm时，单门最小宽度75cm。在扶手、车轮拱形等部位允许宽度减少。 |
    | **安全门** | 高度：125cm，宽度：55cm | 车轮拱形部位宽度可降至30cm（若40cm以上高度能保证55cm宽）。门上角圆角半径≤15cm。 |
    | **安全窗** | 开口面积：4,000 cm² | 可记录为50cm×70cm矩形。若无符合尺寸的安全窗，可在车尾提供，允许尺寸为35cm×155cm矩形（圆角半径≤25cm）。 |
    | **安全顶窗** | 开口面积：4,000 cm² | 可记录为50cm×70cm矩形。 |
*   对于适用5.7.1.9条的车辆（小容量B型车），乘客门和安全门的尺寸要求可降低（如开口高度110cm）。

### 5.6.4 - 5.6.10 各类出口的详细技术要求
*   对乘客门（手动、动力操作、自动）、安全门、安全窗、安全顶窗、伸缩台阶的开启方式、控制、安全防护（如防夹）、标志等做出了具体规定。

## 5.7 内部布置
*   对乘客门、安全门、安全窗、安全顶窗的通道空间尺寸和测试方法（使用特定样板或圆柱体量规）进行了详细规定。
*   规定了通道的坡度限制（纵向：A型≤8%，B型≤12.5%；横向≤5%）。
*   规定了台阶的最高/最低高度、最小深度、坡度等要求。
*   对乘客座椅（包括折叠座椅）的乘坐空间、尺寸、间距、脚踏空间等提出了具体要求。
*   要求引道和通道覆盖防滑材料。

## 5.8 内部人工照明
*   要求为乘客舱、台阶、出口通道、出口标志和控制器、障碍位置提供照明。

## 5.9 扶手和把手
*   规定了强度、尺寸、安装位置、颜色对比等一般要求。
*   对A型车辆（站立区）、乘客门附近以及为残疾人设置的扶手和把手有特殊要求。

## 5.10 阶梯井的保护
*   当急刹车时乘客可能被抛入阶梯井时，应安装不低于80cm高的保护措施。

## 5.11 对司机的保护
*   司机应受到保护，以防急刹车时被行李架上物品砸伤。

## 5.12 活门
*   地板活门应安全装配，需工具或钥匙才能打开，突出物高度≤8mm，边缘应为圆角。

## 5.13 倒车灯
*   所有车辆应在乘客门的后边沿安装符合第48号法规的倒车灯。

# 认证与管理
*   **认证申请**：由制造厂或其代表提交，需包含车型描述、图纸、质量参数、乘客容量计算等文件。
*   **认证批准**：符合第5条要求的车型应获认证，并分配认证号（前两位代表修正本系列）。
*   **认证标志**：应清晰、易认、耐久地粘贴在车辆显著位置，包含圆圈E+国家代号、法规号R52及认证序号、车型符号(A或B)。
*   **生产一致性**：带有认证标志的车辆必须符合已认证车型的要求。
*   **认证更改与扩展**：车型修改需通知发证部门，可能导致需要进一步试验报告。
*   **处罚**：不符合生产一致性要求可能导致认证被撤销。
*   **过渡规定**：对01系列修正本的采用设置了时间表。

# 附录
