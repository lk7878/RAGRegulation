# ECE R107 - 关于 M2或M3类车辆一般结构认证的统一规定

## 概述
本法规适用于除司机以外，可以搭载22名以上有座位或站立乘客的M2或M3系列双层客车的设计和制造认证。法规规定了车辆稳定性、火灾防护、出口、内部布置、机动性等方面的详细技术要求，并包含A类和B类两种认证选择。

## 核心定义
*   **车辆类型**：I型（允许频繁流动的站立乘客）、II型（主要供有座位乘客，允许有限站立）、III型（仅供有座位乘客）。
*   **双层车辆**：至少有一部分采用双层结构为乘客提供乘车空间，上层不得提供站立空间。
*   **铰接车辆**：拥有两个或多个通过铰链永久连接的刚性车厢，乘客舱相互连通。
*   **低地板车辆**：车内至少有35%的面积形成无台阶的单独站立区域，并至少有一个乘客门可通过一级台阶登上。
*   **出口**：包括乘客门、安全门、安全窗、安全顶窗和车内楼梯。
*   **净重 (MK)**：行驶条件下空车质量，含驾驶员（75kg）、90%燃油、冷却液、润滑液、工具和备胎。
*   **空载质量 (MV)**：净重基础上，加上乘务员质量（如适用，每位75kg）、附加液体箱90%容量质量，以及厨房/卫生间设施的满容净水箱质量。

## 主要技术要求

### 5.1 车轴负荷分配
规定了车辆在空载和负载条件下，前轴或轴系必须承担的最小负荷百分比（例如，I型刚体车辆负载时需≥25%）。

### 5.2 & 5.3 乘客区域与容量计算
*   详细定义了乘客区域面积（S0）和站立乘客区域面积（S1）的计算方法，需扣除驾驶舱、台阶、低矮区域等。
*   乘客总容量（N）的计算需同时满足面积公式（N ≤ Ps + S1/Ssp）和质量公式（N ≤ (MT - MV - L*V) / Q），并确保各轴负荷不超过技术允许最大值。
*   不同类型车辆的参数（Q, Ssp, L）如下：
    | 类型 | Q (kg) | Ssp (m²/站立乘客) | L (kg/m³) |
    | :--- | :--- | :--- | :--- |
    | I    | 68     | 0.125              | 100       |
    | II   | 71(*)  | 0.150              | 100       |
    | III  | 71(*)  | （无站立乘客）     | 100       |
    (*) 含3kg手提行李重量。

### 5.4 稳定性测试
车辆向两侧倾斜至28°时不得翻车。测试负载条件为：空载 + 上层每个座位加载Q + 上层过道中乘务员负荷（如适用）。也可通过附录7的计算方法证明稳定性。

### 5.5 火灾防护
*   **发动机舱**：限制可燃材料使用，需有排泄孔防止油液积聚，热源需有耐热材料屏障隔离。
*   **燃油系统**：加油孔须在车外，有防火要求；油箱需安全固定、通过液压测试、耐腐蚀、有泄压装置；油路需受保护，泄漏时燃油应滴落路面。
*   **应急开关**：司机易触及，操作时应能同时停止发动机、切断电池（部分电路除外）并开启危险警告灯。
*   **电气系统**：电缆需绝缘良好、有保护、配备保险丝；高电压电路需有手动隔离开关；内部照明至少两个独立电路。
*   **灭火与急救**：需配备符合标准的灭火器和容量≥7dm³的急救箱存放空间。

### 5.6 出口
*   **数量与位置**：根据乘客总数（N）和车辆类型（I/II/III）规定了最低乘客门数量。安全出口（安全门、窗、顶窗）数量根据车厢或楼层内乘客数确定（如9-16人需3个）。出口需沿车辆长度方向合理分布，上层前后端需有安全出口。
*   **最小尺寸**：
    | 出口类型 | I型 | II/III型 | 备注 |
    | :--- | :--- | :--- | :--- |
    | 乘客门高度 | 180/175 cm (A/B类) | 165 cm | 宽度：单门65cm，双门120cm |
    | 安全门 | 高125cm，宽55cm | - | - |
    | 安全窗面积 | 4000 cm² | 4000 cm² | 可内接50cm×70cm矩形 |
    | 安全顶窗面积 | 4000 cm² | 4000 cm² | 可内接50cm×70cm矩形 |
*   **技术要求**：对乘客门（手动/动力/自动）、安全门、安全窗、安全顶窗、伸缩台阶的开启方式、控制器、防夹功能、标记等有详细规定。

### 5.7 内部布置
*   **通道**：对乘客门、安全门、安全窗、安全顶窗的通道空间，以及车辆内部的通道（使用特定圆柱体量规测试）尺寸有明确规定，因车辆类型和楼层而异。
*   **台阶与楼梯**：规定了各级台阶的最大高度、最小深度，以及车内楼梯的宽度、防回落要求。
*   **乘客座椅**：详细规定了座椅最小宽度、深度、高度、座椅间距、上方自由空间等。
*   **其他**：要求提供与司机的联络方式，内部车门需满足紧急开启要求，内部需有足够照明。

### 5.10 机动性
车辆应能在方向盘每侧行程内，在半径12.5m的圆圈内运动，且最外侧点不超出圆圈。运动通道宽度限为7.2m。

### 5.12 扶手和把手
对扶手把手的强度、尺寸、安装位置（为站立乘客、车门、楼梯、残疾人专用座位等）提出了具体要求。
