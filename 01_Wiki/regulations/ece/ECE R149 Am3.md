# UN Regulation No. 149 - Amendment 3

**Document:** E/ECE/TRANS/505/Rev.3/Add.148/Amend.3
**Date of Entry into Force:** 30 September 2021
**Authentic Text:** ECE/TRANS/WP.29/2020/46

This document constitutes **Amendment 3** to UN Regulation No. 149, concerning the approval of road illumination devices (lamps) and systems for power-driven vehicles.

## Summary of Amendments

This amendment introduces changes to the technical requirements and approval marking provisions of UN Regulation No. 149.

## Detailed Amendments

### 1. Paragraph 4.13.
Amended to read:
> "4.13. If applicable, the lamp shall be so made that, if a light source and/or a LED module has failed, a failure signal in order to comply with the relevant provisions of UN Regulation No. 48 is provided."

### 2. Table 8, Part A (Passing-beam luminous intensities for RH traffic)
Amended. Key values include:
*   **B50L:** 350 cd (for Class A, B, D)
*   **BR:** 1,750 cd
*   **Zone III:** 625 cd
*   **50R:** Min 5,100 cd (Class A), 10,100 cd (Class B), 12,500 cd (Class D)
*   **75R:** Min 5,100 cd (Class A), 10,100 cd (Class B), 12,500 cd (Class D)
*   **50V:** Min 5,100 cd (Class B), 7,500 cd (Class D)
*   **50L:** Max 13,200* cd (Class A, B), 18,480 cd (Class D)
*   **75L:** Max 10,600 cd
*   **25L1:** Max 18,800 cd (Class D)
*   **25L2 / 25R1:** Min 1,250 cd (Class A), 1,700 cd (Class B), 2,500 cd (Class D)
*   **Segment I (A to B):** Min 3,750 cd
*   **Imax R (Vertical above 1.72D, right of V-V line):** Max 43,800 cd
*   **Imax L (Left of V-V line):** Max 31,300 cd

### 3. Table 9, Part B (Passing-beam photometric requirements - bending mode)
Amended. Specific replacement lines include:
*   **Line 1 (B50L):** Values range from 504 to 790 cd.
*   **Line 7 (Zone III):** Value is 880 cd (as specified in Table 11).
*   **Line 13 (50 L):** Values are 1,700 cd or 3,400 cd.
*   **Line 18 (Imax):** Min/Max values range from 5,100 cd to 79,300 cd.

### 4. Annex 4, Figure A4-IX
Amended to show passing beam test points and zones for Class BS headlamp(s).

### 5. Annex 7, Paragraph 1.
*   **Paragraph 1.(a)** amended regarding measurement points for headlamps with asymmetrical passing-beam.
*   **Paragraph 1.(d)** amended regarding measurement points for Adaptive Front-lighting Systems (AFS).

### 6. Annex 7, Paragraph 2.1.2.2.1.
*   **Paragraph (a)** amended to specify passing-beam measurement points (excluding AFS): 50R - B50L – 25L2 for RH traffic; 50L - B50R – 25R2 for LH traffic.
*   **Paragraph (b)** amended to specify passing-beam measurement points for AFS: 50V, B50L and 25LL (for Class C and other specified classes).

### 7. Annex 13 (Arrangement of approval marks)
Comprehensively amended with new examples and explanatory text for:
1.  **Approval mark of a single road illumination device** (e.g., an AFS installation unit).
2.  **Approval mark of grouped, combined or reciprocally incorporated lamps** (including examples with front position lamps, headlamps, fog lamps, and direction indicators).
3.  **Identification code of light source modules.**
4.  **Additional lighting units designed to provide bend lighting.**

The annex provides detailed illustrations (Figures A13-I to A13-VII) and notes explaining the meaning of symbols, arrows, scores above letters, and numerical codes within the approval marks, particularly for systems with multiple installation units (like AFS) and for indicating compliance with bending lighting provisions.
