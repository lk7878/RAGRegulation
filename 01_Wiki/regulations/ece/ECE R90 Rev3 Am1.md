# UN Regulation No. 90 Revision 3 – Amendment 1

**Uniform provisions concerning the approval of replacement brake lining assemblies, drum-brake linings and discs and drums for power-driven vehicles and their trailers**

*Supplement 1 to the 02 series of amendments*
*Date of entry into force: 18 November 2012*

## 1. Scope and Definitions
This Regulation applies to the basic braking function of replacement parts (brake lining assemblies, drum-brake linings, discs, and drums) for power-driven vehicles and their trailers.

**Note:** References to Regulations Nos. 13, 13-H, or 78 in this Regulation shall also be deemed to refer to any other international rule (e.g., 71/320/EEC) that applies the same technical requirements. References to specific sections shall be interpreted accordingly.

### 2.2 Test Group Definition for Brake Drums (Paragraph 5.3.6.2.2.1.)
Brake drums may be grouped together as test groups on the basis that each permitted test group range is from the smallest inside diameter to the smallest inside diameter +10 per cent and by no more than 40mm on the shoe width of the drum.

### 2.3 Marking and Information Requirements (Paragraph 6.2.)
Every unit sold shall be provided with at least the following information:
- Manufacturer name or trade name.
- Approval number (e.g., E2-90R02 Cxxxx/yyyy).
- **Part number** (new requirement).
- Indication for traceability.
- Minimum thickness (disc) / maximum inside diameter (drum).

## 3. Annex 11 (Vehicles of Categories M and N) - Key Amendments

### 3.1 Test Overview (Paragraph 1.)
The tests required are detailed according to vehicle category. For vehicles of categories M1, N1, the test matrix includes vehicle tests and alternative dynamometer tests for performance, comparison with original parts, and integrity tests.

### 3.2 Test Mass for Multi-Axle Vehicles (Paragraph 3.2.1.2.)
When testing brake discs and drums for vehicles with more than 2 axles: `m = 0.55 * m_axle`, where `m_axle` is the maximum permitted mass of the axle.

### 3.3 Alternative Dynamometer Performance Test Procedure (Paragraph 3.3.)
A detailed step-by-step procedure is specified, including bedding-in (burnishing), dynamic friction property tests, Type 0 (engine disconnected/connected), Type I, and optional Type II tests. The sequence involves multiple re-burnishing steps.

### 3.4 Service Braking System Test Specifications
- **Type-0 test (simulation engine disconnected):** Specifies initial speeds, deceleration requirements (≥ 6.43 m/s² for M1/N1; ≥ 5 m/s² for M2/M3/N2/N3), and pressure/torque limits.
- **Type I test (fade test):** Specifies heating procedure parameters (speed, deceleration, number of applications) for different vehicle categories (M1, M2, N1, M3/N2/N3). Hot performance must be ≥ 75% (M1/N1) or ≥ 60% (M2/M3/N2/N3) of cold Type 0 performance, with minimum deceleration values. Includes a free-running test requirement.
- **Type II test (for vehicles with endurance braking systems):** Specifies heating procedure (dragging at constant torque) and hot performance requirement (≥ 3.75 m/s²).
- **Type-0 test (simulation engine connected):** Specifies initial speeds for different categories and deceleration requirements (≥ 5.76 m/s² for M1/N1; ≥ 4 m/s² for others).

### 3.5 Integrity Tests
- **Brake disc thermal fatigue test (Paragraph 4.1.1.1.2.):** Specifies test program for M1/N1 vehicles (sequential applications, braking interval 70s, deceleration 5.0 m/s², cycles from v_max to 20 km/h).
- **Brake disc high load test (Paragraph 4.1.2.):** Specifies applicability (new disc or disc from dynamometer test for interchangeable parts; new disc with original caliper/linings for equivalent parts). Test programs are provided for M1/N1 and M2/M3/N2/N3 vehicles, including number of applications, deceleration/pressure targets, and damage criteria (e.g., radial cracks > 2/3 of friction surface height).
- **Brake drum thermal fatigue test (Paragraph 4.2.1.):** Specifies bedding-in procedure and test program (sequential applications, deceleration 3.0 m/s², cycles from 130 to 80 km/h).
- **Brake drum high load test (Paragraph 4.2.2.):** Similar applicability rules as for discs. Test programs are provided for different vehicle categories, including bedding-in, number of applications, deceleration targets, and damage criteria.

## 4. Annex 12 (Vehicles of Categories O) - Key Amendments
Amendments parallel those in Annex 11, tailored for trailers (categories O1, O2, O3, O4). Key changes include:
- **Test mass:** `m = 0.55 * m_axle`.
- **Service brake test specifications:** Type 0 (laden), Type I (downhill test), and Type III (fade test for O4) procedures are detailed with specific speed, deceleration, and performance retention requirements.
- **Integrity tests (thermal fatigue and high load):** Test parameters (e.g., speeds, number of cycles, deceleration values) are specified for brake discs and drums applicable to trailer categories.

## 5. Annex 13 (Communication Form) - Amendments
Updates to the model communication form for approval, including:
- New marking requirements (Part number).
- Expanded test bench data fields (location).
- Revised and expanded tables for reporting vehicle test and inertia dynamometer test results for various vehicle categories (M, N, O) and braking system types (hydraulic, pneumatic).
- Specific result tables for service brake performance (Type 0, I, II, III, parking brake) including parameters like speed, pressure, deceleration, brake force, and free-running test outcome.
- Field for reporting high load test results (cycles without damage).
- Separate fields for dates of vehicle test and inertia dynamometer test.

---
*This note summarizes the first amendment to Revision 3 of UN Regulation No. 90, which introduces modifications to test procedures, sample matrices, marking requirements, and communication forms for the approval of replacement braking system components.*
