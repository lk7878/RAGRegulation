本文件是《1958年协定》框架下，关于农林业车辆照明和光信号装置安装认证的统一技术规定（UN Regulation No. 86）的第3版修订3（即01系列修正案的补充3）。本修正案于2021年12月8日发布，2021年9月30日生效。具有法律效力的权威文本为：ECE/TRANS/WP.29/2021/37。

### 主要修订内容
本修正案对UN R086的多个段落和附录进行了修订，主要涉及条款编号调整、定义更新以及对引用其他UN法规版本的更新。

#### 条款修订摘要
1.  **条款重编号**：将原条款2.3.至2.16.及其子条款重新编号为2.2.至2.15.。
2.  **定义更新**：
    *   **2.14. "慢速车辆（SMV）后部标记板"**：更新了定义，明确其为带有截角、具有特定图案的三角形板，表面覆有逆反射和荧光材料或装置（1类）；或仅覆有逆反射材料或装置（2类）（参见UN法规第69号或第150号）。
3.  **一般要求修订**：
    *   **5.10.**：修订了关于防止灯光混淆（前向不发红光，后向不发白光）的要求及验证方法。
    *   **5.11.**：修订为**5.20.**，明确了根据UN法规第148、149和/或150号早期修正系列批准的装置，若相关变更索引（定义见UN R048）无差异，则被视为等同于根据最新修正系列批准的装置，可在车辆型式认证时安装，无需更新装置批准文件和标记。
4.  **装置规格引用更新**：
    *   对第6条（关于各种灯具和装置的规定）下的多个子条款进行了修订，统一将引用的UN法规更新为允许使用替代的最新相关法规（主要是UN R148, R149, R150）。涉及装置包括：
 *   6.1. 远光灯（UN R098, R112, R113 或 R149）
 *   6.2. 近光灯（UN R098, R112, R113 或 R149）
 *   6.3. 前雾灯（UN R019 或 R149）
 *   6.4. 倒车灯（UN R023 或 R148）
 *   6.5. 转向指示灯（UN R006 或 R148）
 *   6.7. 制动灯（UN R007 或 R148）
 *   6.8. 前位灯（UN R007 或 R148）
 *   6.9. 后位灯（UN R007 或 R148）
 *   6.10. 后雾灯（UN R038 或 R148）
 *   6.11. 驻车灯（UN R077, R007 或 R148）
 *   6.12. 示廓灯（UN R007 或 R148）
 *   6.14. 后回复反射器（非三角形）（UN R003 或 R150）
 *   6.15. 侧回复反射器（非三角形）（UN R003 或 R150）
 *   6.16. 后牌照板照明装置（UN R004 或 R148）
 *   6.17. 前回复反射器（非三角形）（UN R003 或 R150）
 *   6.18. 侧标志灯（UN R091 或 R148）
 *   6.19. 日间行车灯（UN R087 或 R148）
 *   6.20. 弯道照明灯（UN R119 或 R149）
 *   6.21. 醒目标记（UN R104 或 R150）
 *   6.22. SMV后部标记板（UN R069 或 R150）
 *   6.24. 机动灯（UN R023 或 R148）
 *   6.25. 后回复反射器（三角形）（UN R003 或 R150）
 *   6.26. 信号板和信号膜（UN R070, R104 或 R150）
5.  **SMV后部标记板具体规定（6.22.）**：详细规定了该装置的选用条件（仅适用于最高设计车速≤40 km/h的车辆，其他车辆禁止）、数量、布置、位置（宽度、高度、长度）、几何可见性和方向，均需符合UN R069的附录15或UN R150的附录25。
6.  **机动灯验证（6.24.9.2.）**：更新了安装符合性验证方法，可通过图纸、模拟进行，或若安装条件符合UN R023的6.2.2.条或UN R148的5.10.2.条（如附件1第9段通讯文件中所述），则视为满足要求。

#### 附录修订
*   **附录1，第6项**：修订为“等效灯具：是/否²（参见条款2.2.1.）”。
*   **附录5**：删除了带删除线的“4”。
*   **附录6，第2段**：修订为“每个面板或膜应符合UN法规第70号（5类）、或UN法规第104号（F类）、或UN法规第150号（5类或F类）的规定。”
