# UN Regulation No. 51 (Revision 3, 03 series of amendments)

## 法规概述
本法规包含关于机动车辆（至少四个车轮）声音排放的统一规定，适用于M类和N1类车辆。其规范旨在重现车辆在城市交通正常行驶时产生的声音水平。

## 适用范围
适用于M类和N1类车辆。

## 关键定义
*   **车辆型式核准**：指就声音方面对车辆型式的核准。
*   **车辆型式**：指在以下基本方面无差异的一类机动车辆：
    *   **按附件3第3.1.2.1段测试的车辆**：发动机舱的形状或材料及其隔音；发动机类型；额定最大净功率及相应额定发动机转速；消声系统。
    *   **按附件3第3.1.2.2段测试的车辆**：发动机舱的形状或材料及其隔音；发动机类型；额定发动机转速(S)；具有相同类型发动机和/或不同总传动比的车辆可视为同一型式。
*   **运行状态下的车辆质量 (m_ro)**：包括驾驶员、燃料和液体、标准设备的质量。
*   **技术允许最大装载质量 (M)**：基于其结构特征和设计性能分配给车辆的最大质量。
*   **额定最大净功率 (P_n)**：根据第85号法规测量的发动机功率。
*   **额定发动机转速 (S)**：发动机根据第85号法规达到其额定最大净功率时声明的发动机转速。
*   **功率质量比指数 (PMR)**：用于计算加速度的无量纲数值量。
*   **消声系统**：用于限制发动机、其进气和排气产生声音的完整组件集。
*   **替换消声系统**：拟用于车辆上的消声系统或其部件的任何部分，不同于根据本法规提交型式核准时安装在该车辆上的型式部件。

## 技术要求
### 声音水平限值 (第6.2.2条)
测量值（按附件3规定，数学四舍五入到最接近的整数值）不得超过以下限值：

#### 载客车辆
| 车辆类别 | 条件 | 限值 (dB(A)) |
| :--- | :--- | :--- |
| **M1** | PMR ≤ 120 | 72 / 70 / 68 |
| | 120 < PMR ≤ 160 | 73 / 71 / 69 |
| | PMR > 160 | 75 / 73 / 71 |
| | PMR > 200, 座位数 ≤ 4, R点高度 < 450mm | 75 / 74 / 72 |
| **M2** | M ≤ 2.5 t | 72 / 70 / 69 |
| | 2.5 t < M ≤ 3.5 t | 74 / 72 / 71 |
| | M > 3.5 t; P_n ≤ 135 kW | 75 / 73 / 72 |
| | M > 3.5 t; P_n > 135 kW | 75 / 74 / 72 |
| **M3** | P_n ≤ 150 kW | 76 / 74 / 73 |
| | 150 kW < P_n ≤ 250 kW | 78 / 77 / 76 |
| | P_n > 250 kW | 80 / 78 / 77 |

#### 载货车辆
| 车辆类别 | 条件 | 限值 (dB(A)) |
| :--- | :--- | :--- |
| **N1** | M ≤ 2.5 t | 72 / 71 / 69 |
| | M > 2.5 t | 74 / 73 / 71 |
| **N2** | P_n ≤ 135 kW | 77 / 75 / 74 |
| | P_n > 135 kW | 78 / 76 / 75 |
| **N3** | P_n ≤ 150 kW | 79 / 77 / 76 |
| | 150 kW < P_n ≤ 250 kW | 81 / 79 / 77 |
| | P_n > 250 kW | 82 / 81 / 79 |

**注**：表中三列限值分别对应第一阶段、第二阶段和第三阶段。

### 附加规定
*   **附加声音排放规定 (ASEP)**：适用于配备内燃机的M1和N1类车辆。车辆在典型道路行驶条件下的声音排放不得显著偏离型式核准测试结果。具体要求见附件7。
*   **特殊车辆限值调整**：
    *   设计用于越野使用的车辆，限值增加：M3和N3类增加2 dB(A)，其他类别增加1 dB(A)。
    *   轮椅无障碍车辆和装甲车辆，限值增加2 dB(A)。
    *   仅配备汽油发动机的M3类车辆，限值增加2 dB(A)。
*   **含纤维材料的排气系统**：需满足附件4的要求。

## 测试方法
声音测量方法详见附件3，包括：
*   **行驶车辆测量**：根据车辆类别（M1/N1/M2≤3.5t 与 M2>3.5t/M3/N2/N3）采用不同的测试条件（如加速度测试、恒定速度测试、目标发动机转速和车速）。
*   **静止车辆测量**：提供参考值。
*   **压缩空气噪声测量**：适用于技术允许最大装载质量超过2,800 kg且配备相应制动设备的车辆（附件5）。
*   **测试场地和环境条件**：符合ISO 10844:2014。
*   **车辆测试质量**：根据车辆类别有不同的计算方法（见附件3第2.2.1条）。

## 符合性生产
*   应符合《1958年协定》附录2的规定。
*   必须满足附件6规定的最低符合性生产控制程序要求。
*   授予型式核准的当局可每两年核查一次各生产设施的符合性控制方法。

## 过渡性条款 (第11条)
*   **第一阶段**：自2016年7月1日起，缔约方仅对满足第一阶段要求的车辆型式授予核准。
*   **第二阶段**：自2020年7月1日起（N2类自2022年7月1日起），缔约方仅对满足第二阶段要求的车辆型式授予核准。
*   **第三阶段**：自2024年7月1日起（N2、N3、M3类自2026年7月1日起），缔约方仅对满足第三阶段要求的车辆型式授予核准。
*   详细的新车核准和已核准车型扩展的接受截止日期见法规正文。
