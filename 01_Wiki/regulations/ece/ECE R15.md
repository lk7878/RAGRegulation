# 法规概述
本法规（ECE R15）规定了关于装备点燃式发动机或压燃式发动机车辆的发动机气体污染物排放、点燃式发动机功率测量方法以及车辆燃油消耗测量方法方面的统一认证规定。法规源于联合国1970年3月20日协议，最新版本为1984年6月1日生效的04系列修正本的补充件（Rev.1/Add.14/Rev.3/Amend.1），文本为1999年2月的第1版。

# 主要内容
## 1. 适用范围 (第1条)
- **主要范围**：适用于所有以点燃式发动机为动力的车辆和以压燃式发动机为动力的N1类及M1类车辆的气体污染物排放。
- **除外情况**：不适用于以点燃式二冲程发动机为动力的车辆、两轮机动车辆、空载质量小于400kg的三轮机动车辆和设计速度不超过50km/h的两轮或三轮机动车辆。
- **辅助范围**：
    - ECE规程可用于测量点燃式发动机的输出功率。
    - ECE规程可用于测量M1类车辆的燃油消耗。

## 2. 定义 (第2条)
关键定义包括：
- **车辆认证**：就发动机气体污染物排放限值方面的车辆型式认证。
- **车辆型式**：在主要方面没有差异的车辆，包括根据基准质量确定的当量惯量以及发动机和车辆特性。
- **基准质量**：车辆“空载质量”加100kg后的质量。
- **空载质量**：运行状态的车辆在不搭载乘务员、乘客或货物，装满油箱并装载常用工具和备用轮胎时的质量。
- **气体污染物**：一氧化碳(CO)、碳氢化合物(HC，假定碳氢比为CH1.85)和氮氧化物(NOx，以二氧化氮(NO2)当量表示)。
- **最大总质量**：车辆制造厂规定的技术上允许的车辆最大质量。
- **冷起动装置**：临时加浓空气/燃料混合气，便于冷态起动发动机的装置。
- **辅助起动装置**：不通过加浓发动机的空气/燃油混合气，来帮助发动机起动的装置（例如：预热塞，改变喷油正时等）。

## 3. 认证申请 (第3条)
- **气体污染物**：申请时应提交发动机型式的详细说明、燃烧室和活塞图纸、气门正时数据、车辆详细说明等文件，并提交一辆样车进行试验。
- **发动机功率**：制造厂可以要求测量发动机功率，需提供相关信息并提交一台发动机进行试验。此试验不视作型式认证试验。
- **燃油消耗**：制造厂可以要求测量车辆燃油消耗，需提供相关信息并提交一辆车辆进行试验。此试验不视作型式认证试验。

## 4. 认证 (第4条)
- 如果车型满足技术要求，应通过认证。
- 授予认证号，前两位数字代表授予认证时本法规的最新修正序列号（目前为04）。
- 认证批准或拒绝应以通知书形式通知有关各方，格式应符合附录2。
- 认证车辆可加贴国际认证标志（圆圈内有大写字母E及国家代码，右侧标有法规号“R”和认证号）。
- 认证标志必须清晰、易认、耐久，位于制造厂车辆技术法规标牌附近或直接印在标牌上。

## 5. 技术要求和试验 (第5条)
### 5.1 总则
车辆部件的设计、制造和安装必须保证在正常使用和振动条件下仍能达到法规要求。

### 5.2 认证试验说明
根据车辆类型进行不同试验：
- **点燃式发动机驱动车辆**：进行I型、II型和III型试验。
- **压燃式发动机驱动车辆**：进行I型试验。

#### 5.2.1 I型试验（检验冷起动后气体污染物的平均排放）
- **适用车辆**：最大质量不超过3.5t的所有车辆。
- **试验方法**：车辆在底盘测功机上进行13分钟试验（包括4个循环），废气被稀释并按比例采样收集到气袋中，测量稀释后废气的总体积和污染物浓度。
- **试验规程**：按附录4规定进行。
- **排放限值**：根据车辆基准质量(rw)确定一氧化碳和碳氢化合物及氮氧化物总质量的限值（g/test）。试验应重复三次，结果需满足特定统计要求（例如，三次结果算术平均值低于限值，且至多一次结果可超过限值但不超过10%）。在特定条件下试验次数可减少或增加。
- **限值表（认证）**：
    | 基准质量 (rw) kg | 一氧化碳 g/test | 碳氢化合物及氮氧化物的总质量 g/test |
    |------------------|-----------------|--------------------------------------|
    | rw ≤ 1020        | 58              | 19                                   |
    | 1020 < rw ≤ 1250 | 67              | 20.5                                 |
    | 1250 < rw ≤ 1470 | 76              | 22                                   |
    | 1470 < rw ≤ 1700 | 84              | 23.5                                 |
    | 1700 < rw ≤ 1930 | 93              | 25                                   |
    | 1930 < rw ≤ 2150 | 101             | 26.5                                 |
    | 2150 < rw        | 110             | 28                                   |

#### 5.2.2 II型试验（怠速时一氧化碳排放试验）
- **适用车辆**：除压燃式发动机车辆外的所有车辆。
- **要求**：发动机怠速排气中一氧化碳的体积含量不得超过3.5%。当在与制造厂推荐的规范不相符的运行条件下检测时，不得超过4.5%。
- **试验规程**：按附录5规定进行。

#### 5.2.3 III型试验（检验曲轴箱排放）
- **适用车辆**：除装备压燃式发动机车辆外的所有车辆。
- **要求**：发动机曲轴箱通风系统不得使曲轴箱中的任何气体排入大气。
- **试验规程**：按附录6规定进行。

## 6. 车辆型式的更改 (第6条)
车型的任何更改都应通知认证机构，认证机构可认为更改无不良影响或要求进一步试验报告。更改情况的认证批准或拒绝应按程序通知有关各方。

## 7. 认证扩展 (第7条)
在满足特定条件下，已通过认证的车型可向其他车型扩展，包括：
- **仅基准质量不同**：满足等效惯量相邻组别等条件。
- **仅总传动比不同**：计算传动比变化率E，根据E值大小决定是否需重复I型试验。
- **基准质量和总传动比均不同**：需同时满足上述条件。

## 8. 生产一致性 (第8条)
- 带有认证标志的车辆应与认证车型一致。
- 应对连续生产的车辆进行随机检验，检验规程包括I型、II型及III型试验或其中一部分。
- **I型试验生产一致性限值**：
    | 基准质量 (rw) kg | 一氧化碳 g/test | 碳氢及氮氧化物的总质量 g/test |
    |------------------|-----------------|--------------------------------|
    | rw ≤ 1020        | 70              | 23.8                           |
    | 1020 < rw ≤ 1250 | 80              | 25.6                           |
    | 1250 < rw ≤ 1470 | 91              | 27.5                           |
    | 1470 < rw ≤ 1700 | 101             | 29.4                           |
    | 1700 < rw ≤ 1930 | 112             | 31.3                           |
    | 1930 < rw ≤ 2150 | 121             | 33.1                           |
    | 2150 < rw        | 132             | 35.0                           |
- 采用统计方法（如计算平均值和标准偏差，使用统计因数k）判定成批生产车辆是否满足一致性要求。

## 9. 生产不一致性的处罚 (第9条)
如果车辆未达到生产一致性要求，可以撤销已批准的认证。撤销认证应以认证表格通知其他缔约方。

## 10. 正式停产 (第10条)
如果认证批准书持有者完全停止已批准车型的生产，应通知认证部门，认证部门应通知其他缔约方。

## 11. 认证试验部门及行政管理部门的名称和地址 (第11条)
缔约方应将负责认证试验和行政管理的部门名称和地址通知联合国秘书处。

## 12. 过渡规定 (第12条)
规定了本法规不同修正版本（未经修正版本、01、02、03系列修正）的排放限值在不同日期之前的适用性和有效性。例如：
- 最初的未经修正版本的限值适用于1975年10月1日之前批准的车型认证。
- 经01系列修正的限值适用于1975年10月1日之后。
- 经02系列修正增加了氮氧化物限值，适用于1977年3月1日之后。
- 经03系列修正的限值适用于1979年10月1日之后。
- 04系列修正适用于1982年10月1日之后批准认证的新车型等。
法规附录中提供了各修正版本的详细排放限值表。

# 关键点
- 本法规是ECE关于车辆排放、发动机功率和燃油消耗测量的综合性法规。
- 核心是I型（模拟市区循环）、II型（怠速CO）和III型（曲轴箱排放）试验。
- 包含了详细的试验方法、设备要求、标定程序和计算方法。
- 强调了生产一致性和认证管理流程。
