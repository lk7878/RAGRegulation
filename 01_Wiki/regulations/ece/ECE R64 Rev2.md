# UN Regulation No. 64 (Revision 2)

**Uniform provisions concerning the approval of vehicles with regard to their equipment which may include: a temporary use spare unit, run flat tyres**

## 概览
本法规规定了关于批准配备临时使用备用单元（包括临时使用备胎）和/或漏气保用轮胎（run-flat tyres）和/或漏气保用系统（run-flat system）的 M1 和 N1 类车辆的统一要求。法规涵盖了定义、申请与批准程序、技术规范与测试（包括制动与跑偏测试）、生产一致性、过渡条款等内容。

## 法规结构

2.  Definitions
3.  Application for approval
4.  Approval
5.  Specifications and tests

## 核心要求摘要

### 1. 适用范围 (Scope)
适用于批准配备以下设备的 M1 和 N1 类车辆：
*   临时使用备用单元；和/或
*   漏气保用轮胎和/或漏气保用系统。
完全泄气状态下的漏气保用轮胎或系统被视为临时使用备用单元。

### 2. 关键定义 (Key Definitions)
*   **临时使用备用单元 (Temporary-use spare unit):** 不属于“标准备用单元”的任何车轮和轮胎总成。分为5种类型（Type 1-5），主要区别在于轮胎类型（临时使用备胎、正常轮胎、漏气保用轮胎）、车轮偏距、轮胎结构或尺寸与标准单元的差异。
*   **漏气保用轮胎/自支撑轮胎 (Run-flat tyre / Self supporting tyre):** 一种充气轮胎结构，采用技术方案（如加强侧壁），使轮胎在缺气运行模式下，至少在80 km/h的速度下行驶80 km，仍能为车辆提供基本轮胎功能。
*   **漏气保用系统/扩展机动系统 (Run-flat system / Extended mobility system):** 包括轮胎在内的指定功能依赖组件的总成，共同提供规定性能，使车辆在缺气运行模式下，至少在80 km/h的速度下行驶80 km，仍能获得基本轮胎功能。
*   **缺气运行模式 (Flat tyre running mode):** 轮胎在充气压力为0至70 kPa之间运行，基本保持其结构完整性的状态。
*   **漏气保用报警系统 (Run-Flat Warning System, RFWS):** 向驾驶员传递轮胎处于缺气运行模式信息的系统。

### 3. 技术规范与测试 (Specifications and Tests - 第5条)
*   **一般要求 (General):**
    *   用作临时使用备用单元的轮胎必须根据 UN R30 或 R54 获得批准。
    *   临时使用备用单元的负载能力至少等于车辆最高轴荷的一半（若使用限制在特定车轴，则等于该轴最大负载的一半）。
    *   Type 1, 2, 3 临时使用备用单元的设计速度至少为 120 km/h。
    *   必须在车轮外表面永久显示最大速度警告符号（80 km/h 或 120 km/h，取决于备用单元类型），并有颜色区分。
    *   允许车辆只配备一个临时使用备用单元（漏气保用轮胎/系统除外）。
    *   配备漏气保用轮胎/系统的车辆必须安装漏气保用报警系统（RFWS），或在满足 UN R141 要求的轮胎压力监测系统（TPMS）时可豁免。RFWS 需满足光学黄色警告信号、点火检查、故障指示等要求。
    *   对于以放气状态存储的备用单元，车辆必须提供可在最多10分钟内将轮胎充气至规定压力的装置。
*   **制动测试 (Braking test):** 车辆配备临时使用备用单元时必须满足附件3的要求。测试包括在不同速度（80 km/h 或 120 km/h）下进行制动，评估制动距离和平均充分发出的减速度，且测试过程中不应发生车轮抱死、车辆偏离预定路线等异常情况。

### 4. 补充信息 (Supplementary Information - 第6条)
车辆用户手册必须包含关于临时使用备用单元的使用限制、最高允许速度（80 km/h 或 120 km/h）、禁止同时使用多个备用单元、指定充气压力、充气程序（如适用）等信息。如果车辆安装了 RFWS，手册中必须说明该系统及其复位方法（如适用），并显示警告符号图像。

### 5. 过渡条款 (Transitional Provisions - 第12条)
*   自 **2018年9月1日** 起，适用本法规的缔约方不得拒绝根据03系列修正案授予或接受 UN 型式批准。
*   自 **2018年9月1日** 起，适用本法规的缔约方应仅对符合03系列修正案要求的车辆类型授予 UN 型式批准。
*   即使在此日期之后，缔约方仍应继续接受根据02系列修正案授予的型式批准，但对于未安装 TPMS 的车型，无义务为区域型式批准而接受02系列的批准。

## 附件 (Annexes)
*   **附件1:** 批准、扩展、拒绝、撤销批准或生产永久终止的通信表格。
*   **附件2:** 批准标记的示例和布置方式。
*   **附件3:** 配备临时使用备用单元的车辆的制动和跑偏测试程序。详细规定了测试条件、不同车辆类别（M1, N1）和不同制动法规（UN R13, R13-H）下的性能指标（制动距离、减速度）。
*   **附件4:** 漏气保用报警系统（RFWS）的测试要求。包括检测缺气运行模式（两种测试方法）和系统故障的测试程序、条件和合格标准。
