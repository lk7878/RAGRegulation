# ECE R39 - 关于汽车速度表及其安装认证的统一规定

## 1. 适用范围
本法规适用于L、M、N类车型（定义参见汽车结构统一规定（R.E.3）附录7）。

## 2. 定义
- **2.1 车辆认证**：指一种车型就其车速表及其安装而进行的车辆型式认证。
- **2.2 车速表的车型**：指车辆在本质方面无不同特征，但可在以下方面不同：
    - 2.2.1 正常安装轮胎的指定尺寸（从轮胎范围内选择）。
    - 2.2.2 车速表的总传动比（包括任何减速行驶）。
    - 2.2.3 车速表的型式（由测量机构误差、技术常数、量程决定）。
- **2.3 正常安装的轮胎**：指由生产厂家指定安装在车型上的轮胎或轮胎系列（不包括雪地轮胎）。
- **2.4 正常的行驶气压**：指在轮胎冷状态下，厂家要求的气压基础上增加0.2 bar。
- **2.5 车速表**：指车速测量装置中向驾驶员时时显示车辆行驶速度的部分（不包括自记式转速计的车速显示部分，若其符合型式认证要求）。
    - 2.5.1 **车速测量机构的误差**：指车速表装置本身的准确性，通过速度输入范围内的速度指示器最大和最小限值表示。
    - 2.5.2 **车速表的技术常数**：指输入周期或每分钟的脉冲与指定显示的速度之间的关系。
- **2.6 空载汽车**：指汽车运行状态中，加满燃油、冷却液、润滑油，带上工具和备胎（若作为标准配备），载有一名75kg驾驶员，无副驾驶员和载货。

## 3. 认证申请
- **3.1** 申请应由汽车制造厂家或其授权代理人提出。
- **3.2** 需提交一式三份的文件，包含对车辆型式的详细描述（涉及2.2, 2.3, 2.4, 2.5条）。
- **3.3** 向认证试验技术部门提供一台待认证的空载车辆。
- **3.4** 认证前，认证部门需确认制造厂家有令人满意的生产一致性保证措施。

## 4. 认证
- **4.1** 若车辆符合本法规要求，应给予型式认证。
- **4.2** 授予认证号，前两位数字为认证时本法规的最新修正系列号。同一认证部门不得将同一认证号授予其他车型。
- **4.3** 认证/拒绝通知书应按附录1格式通知协议各方，并附车速表安装图（不大于A4幅面）。
- **4.4** 认证标志（国际认证标志）内容：
    - 4.4.1 圆圈内字母“E”及批准国代号。
    - 4.4.2 圆圈右侧为法规号、“R”、短划线、认证号。
- **4.5** 若车辆已取得本法规及其他法规认证，4.4.1条标志不重复，所有认证号及标志垂直排列于其右侧。
- **4.6** 标志应清晰可见、不可擦除。
- **4.7** 标志应贴在靠近汽车参数标志牌的位置。
- **4.8** 认证标志布置示例见附录2。

## 5. 详细规定
### 5.1 显示要求
- 应处于驾驶员直接视野内，白天夜晚均清晰可见。量程须足以包含车型最高车速。
- **5.1.1** M、N、L3、L4、L5类车：刻度间隔为1、2、5或10 km/h。最高车速值<200 km/h时，最大刻度间隔≤20 km/h；≥200 km/h时，≤30 km/h。刻度间隔不要求均匀。
- **5.1.2** 英制单位国家销售的车辆：应标有mile/h (mph)，刻度间隔为1、2、5或10 mph，最大间隔≤20 mph，以10或20 mph作为开始车速。刻度间隔不要求均匀。
- **5.1.3** L1、L2类车：显示器读数≤80 km/h，刻度间隔为1、2、5或10 km/h，最大间隔≤10 km/h。刻度间隔不要求均匀。
- **5.1.4** 英制单位国家销售的M、N、L3、L4、L5类车：应标有mph，刻度间隔为1、2、5或10 km/h，最大间隔≤20 mph，以10或20 mph作为开始车速。刻度间隔不要求均匀。

### 5.2 准确度测试程序
- **5.2.1** 对制造厂家规定的每一种正常安装轮胎进行测试。
- **5.2.2** 测试在空载下进行，也可适当装载（总质量及轴荷分布需在认证文件中说明）。
- **5.2.3** 试验温度：23±5 °C。
- **5.2.4** 胎压符合正常行驶气压要求。
- **5.2.5** 测试车速根据厂家规定的最高车速(Vmax)确定：

| 汽车厂家规定的最高车速(Vmax) (km/h) | 测试车速 (V1) (km/h) |
| :--- | :--- |
| Vmax ≤ 45 | 80%的最高车速 |
| 45 < Vmax ≤ 100 | 40 km/h 和 80%的最高车速（若最终测试车速 ≥ 55 km/h） |
| 100 < Vmax ≤ 150 | 40 km/h、80 km/h 和 80%的最高车速（若最终测试车速 ≥ 100 km/h） |
| 150 < Vmax | 40 km/h、80 km/h 和 120 km/h |

- **5.2.6** 真实速度测量仪器精度：±0.5%。
    - 5.2.6.1 试验路面应平坦、干燥、附着力足够。
    - 5.2.6.2 若使用底盘测功机，转鼓直径至少为4 m。

### 5.3 准确度要求
车速表显示车速(V1)绝对不能低于真实车速(V2)。在5.2.5条规定的车速及该范围内，应满足：
`0 ≤ (V1 - V2) ≤ 0.1 V2 + 4 km/h`

## 6. 车型的更改
- **6.1** 任何改动需向认证主管部门汇报。主管部门可判定无负面影响，或要求进行认证测试。
- **6.2** 修改后的认证批准/拒绝及修改内容文件，应按4.3条程序通知协议各方。

## 7. 生产一致性
- **7.1** 程序应满足(E/ECE/324-E/ECE/TRANS/505/Rev.2)附录2规定及下述要求。
- **7.2** 生产车型应与认证车型一致。
- **7.3** 对车速表及其安装进行足够测试，至少包含附录3内容。
- **7.4** 认证部门可随时检查生产单位的一致性保证措施，正常频率为两年一次。
- **7.5** 若检查结果不理想，认证部门应采取有效措施恢复生产一致性。

## 8. 生产不一致性的处罚
- **8.1** 若第7.1条要求不满足或未通过第7条检查，则撤销该车型的型式认证。
- **8.2** 撤销认证的协议方应立即通知其他协议方，通知书格式见附录1。

## 9. 认证试验部门和行政管理部门的名称和地址
采用本法规的缔约方，应将负责认证试验和行政管理的部门名称及地址通知联合国秘书处。

## 附录
- **附录1**：通知书格式（认证批准、扩展、拒绝、撤销或正式停产）。
- **附录2**：认证标志的布置示例。
- **附录3**：车速表准确度的生产一致性检验。
    - **1 试验条件**：按本法规第5.2.1至5.2.6条。
    - **2 试验要求**：若满足以下关系，则认为生产符合要求：
 - M和N类车：`0 ≤ V1 - V2 ≤ 0.1 V2 + 6 km/h`
 - L3、L4、L5类车：`0 ≤ V1 - V2 ≤ 0.1 V2 + 8 km/h`
 - L1、L2类车：`0 ≤ V1 - V2 ≤ 0.1 V2 + 4 km/h`
