# 马来西亚汽车技术法规及其产品认证制度

## 1. 汽车产品准入管理的部门
- **主管部门**：马来西亚运输部道路运输司（简称“路运局”），下设汽车工程处。
- **协调机构**：马来西亚国家型式批准委员会，由道路运输司司长担任主席，秘书处设在汽车工程处。
- **委员会组成部门**：
    1.  马来西亚标准与工业研究院（SIRIM）：负责产品认证。
    2.  马来西亚国际贸易与工业部（MITI）：负责汽车产业政策。
    3.  马来西亚环境部：涉及污染与噪声控制。
    4.  马来西亚标准局。
    5.  马来西亚道路安全研究所（MIROS）：车辆安全研究。
    6.  PUSPAKOM：授权车辆检验机构。
    7.  KDRM：马来西亚海关。
    8.  KPDN：马来西亚国内贸易部。

## 2. 马来西亚对车辆的分类
马来西亚全面采用ECE法规，车辆分类与国际惯例一致。

### 表44 L类——少于四轮的机动车辆
| 分类 | 定义 | 术语 |
| :--- | :--- | :--- |
| L1 | 热力发动机排量≤50cm³，最高设计车速≤50km/h的两轮车辆。 | 轻便摩托车 |
| L2 | 热力发动机排量≤50cm³，最高设计车速≤50km/h的三轮车辆（任何车轮布置）。 | 轻便摩托车 |
| L3 | 热力发动机排量>50cm³，或最高设计车速>50km/h的两轮车辆。 | Solo摩托车 |
| L4 | 热力发动机排量>50cm³，最高设计车速>50km/h，三个车轮非对称布置的车辆。 | 边三轮摩托车 |
| L5 | 热力发动机排量>50cm³，最高设计车速>50km/h，三个车轮对称布置的车辆。 | 三轮摩托车 |
| L6 | 整备质量≤350kg（电动车不含电池），最高设计车速≤45km/h，发动机排量≤50cm³或功率≤4kw的四轮车辆。分I级（方向盘操控）和II级（车把操控）。 | 轻四轮摩托车 |
| L7 | 除L6外，整备质量≤400kg（载货车≤550kg，电动车不含电池），最大连续额定功率≤15kw的四轮车辆。分I级和II级。 | 四轮摩托车 |

### 表50 G类——越野车
- **定义**：满足MS1822要求的M类、N类越野车。根据车辆类别（如M1、N1、N2/N3/M2/M3、N3/M3>12t）有不同的技术条件要求，涉及驱动形式、差速锁、爬坡度、接近角/离去角/纵向通过角、离地间隙等。

## 3. 马来西亚汽车技术法规体系
已建立基本完善的法规体系，借鉴英国原有模式和体系。主要法规目录（表51）包括：
- **车辆的一般结构、使用和注册**：如《马来西亚机动车辆法，1959（结构和使用）》、《商用车辆的重量与尺寸》。
- **特殊车辆的结构和使用；车辆装备**：涉及安全头盔、排放控制、安全带、液化石油气系统、噪声、速度限制、安全玻璃等专项法规。

## 4. 马来西亚汽车产品市场准入管理制度和技术法规的新发展
### 4.1 采用ECE法规与型式批准体制
- 马来西亚于2006年加入联合国WP29的《1958年协定书》和《1998年协定书》。
- 在其整车型式批准制度中直接采用ECE法规，计划到2020年基本将现有ECE法规全部采用实施。
- 正在修改相关法律法规（如《马来西亚机动车辆法，1959（结构和使用）》）。
- **承认已获ECE型式批准的产品**：对于满足《1958年协定书》框架下ECE法规、已获得ECE型式批准并带有E标志的汽车零部件和系统，马来西亚予以承认，视同符合本国法规。

### 4.2 东盟地区统一与马来西亚法规发展的关系
- 东盟致力于在2020年建立统一的汽车市场准入管理制度和技术法规体系，统一采用ECE法规。
- **首批统一采用的ECE法规**：共19项（表52），涉及制动、安全带、座椅、头枕、轮胎、车速表、安全玻璃、后视镜、排放、噪声、转向装置等。
- **马来西亚的实施进度**：
    - **目前已采用**：54项ECE法规（表53）。
    - **2015年1月1日起新增实施**：24项ECE法规（表54）。
    - **2017年7月1日起新增实施**：22项ECE法规（表55）。
    - **2020年1月1日起新增实施**：19项ECE法规（表56）。
- **东盟互认**：东盟统一认证制度意味着成员国间对首批19项ECE法规的检测报告和认证互认。但车辆进入马来西亚仍需满足马来西亚已采用的全部ECE法规（如78项），其中19项可通过互认，其余项目需通过马来西亚认证（或ECE认证）。

## 5. 马来西亚汽车产品认证和批准流程
- **制度**：自2005年1月1日起，所有新车型必须通过运输部道路运输司的型式试验和批准。
- **流程**（图31）：
    1.  申请者提交材料至道路运输司。
    2.  道路运输司审查材料，安排检验。
    3.  道路运输司、国家型式批准委员会与申请者共同进行检验（车辆性能、道路适应性试验等）。
    4.  产品符合要求后，委员会审批并颁发型式批准证书。
    5.  证书信息录入政府数据库，用于车辆注册。
- **周期**：最少20个工作日。
- **特点**：
    1.  国家型式批准委员会作用关键。
    2.  申请者需自行列明所满足的技术法规。
    3.  车辆按ECE/欧盟框架指令（M、N、O、L类）划分。
    4.  制度发展方向明确采用ECE单项法规。
- **召回制度**：建立了完整的汽车产品召回制度（图32），强化入市后管理。
