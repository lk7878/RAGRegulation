# 欧盟汽车产品型式批准制度及其发展

## 概述
欧盟通过立法建立了统一的汽车产品市场准入管理制度，即**汽车产品型式批准制度**。该制度覆盖整车、零部件和系统，贯穿车辆生产、使用直至报废回收的全生命周期，确保对汽车安全、环保和节能的有效控制。欧盟的汽车技术法规体系在很大程度上与联合国 ECE 法规实现了对接和对等。

## 核心框架法规：2007/46/EC
2007/46/EC 是欧盟整车型式批准的**框架性技术指令**，于2009年4月29日生效，替代了原有的70/156/EEC。其主要内容包括：
- 欧盟整车型式批准的要求和规程。
- 车辆进行整车型式批准需要申报的车型资料信息。
- 不同车型的分类定义（M、N、O类）。
- 整车型式批准应满足的各单项零部件技术指令。
- 欧盟对技术服务机构的评价规程。
- 欧盟型式批准证书和批准标志。
- 欧盟的车辆一致性证书（COC证书）。
- 生产一致性规程。
- 对某些专用车或特种车进行型式批准的要求。

## 欧盟整车型式批准制度特点
1.  **统一市场准入**：在整个欧盟建立统一的汽车产品市场准入管理制度，各国互相承认批准结果，产品可在欧盟内自由流通。
2.  **体系完整**：对整车、零部件和系统均建立了完善的型式批准法规体系。
3.  **国际接轨**：法规体系与联合国 ECE 法规大量对接，许多欧盟单项技术指令已直接采用 ECE 法规替代。
4.  **全生命周期管理**：管理覆盖新车准入、生产一致性、在用定期检验直至车辆报废回收。
5.  **同步发展**：在新能源车辆发展上采取统一政策法规。

## 整车型式批准程序
制造商可通过两种方式获取欧盟整车型式批准：
1.  **一次性完成**：一次性完成框架指令中规定的所有单项零部件检验项目，合格后获得整车型式批准。
2.  **分阶段完成**：先分阶段获得各单项零部件/系统的 EC 型式批准证书，再凭这些证书获取整车型式批准。此为常用方式。

**关键文件**：
- **整车型式批准证书**：由成员国主管机关颁发。
- **生产一致性证书（COC证书）**：每一辆出厂车辆必须附带，是车辆在欧盟各成员国注册、上牌的**必备文件**。证书列有车辆基本数据和性能指标。

## 生产一致性控制
- **批准前审查**：审查企业质量体系（如 ISO 9000, TS 16949）。
- **批准后监督**：主管机关可随时进行现场检查或抽样验证试验。
- **责任主体**：颁发型式批准的成员国始终负责该产品的生产一致性控制。
- **处罚措施**：发现不一致可要求整改，严重时可撤销型式批准。

## 成员国实施
欧盟各成员国指定政府主管机关（通常为运输部门）负责具体实施型式批准，并指定技术服务机构进行试验和检验。例如：
- 德国：KBA（联邦交通管理局），技术服务机构如 TÜV。
- 法国：装备、运输和旅游部，技术服务机构如 UTAC。
- 英国：VCA（车辆认证局）。

## 法规体系发展：与ECE法规的融合
根据法规 (EC) 661/2009，欧盟简化了其车辆型式批准体系，**撤销了50项原有的安全和环保零部件单项技术指令，直接用相应的联合国 ECE 汽车技术法规替代**。同时，引入了新的先进安全技术要求。

然而，欧盟仍保留了**23项自身独有的技术法规**，涉及关键安全和环保领域，以及一些新的安全技术，构成了较高的市场技术壁垒。保留项目示例如下：
| 项目 | 法规示例 | 说明 |
| :--- | :--- | :--- |
| 汽车噪声 | (EU) 540/2014 | 环保范畴 |
| 轻型车排放（欧5/6） | (EC) 715/2007 | 环保范畴 |
| 行人保护 | (EC) 78/2009 | 安全 |
| 可回收利用率 | 2005/64/EC | 环保/循环经济 |
| 空调系统 | 2006/40/EC | 环保 |
| 车辆一般安全 | (EC) 661/2009 | 框架性安全要求 |
| e-Call系统 | (EU) 2015/758 | 先进安全技术 |

## 后续发展：(EU) 2018/858
2007/46/EC 已被 (EU) 2018/858 法规取代，后者于2020年9月1日起强制实施。(EU) 2018/858 在技术要求上变化不大，主要**加强了型式批准管理程序和市场监管**：
- **强化后期监管**：加强了对获准上市后车辆的合规性和一致性监督。
- **加强欧盟委员会权力**：欧盟委员会可评估成员国主管机关，并可在全欧盟范围执行市场保护措施和启动召回。
- **明确市场监管要求**：例如，每4万辆新车至少进行一次监管试验。
- **证书有效期**：M1/N1类车型式批准证书有效期为7年，其他车型为10年。

## 相关在用阶段法规
除了新车准入法规，欧盟还制定了针对车辆在用阶段的管理法规，构成完整的管理链条：
- **尺寸与重量**：(EU) 2015/719（修订96/53/EC），规定商用车辆在国际交通中的最大允许尺寸和重量。
- **车辆限速器**：2002/85/EC（修订92/6/EEC），要求某些商用车辆安装和使用限速装置。
- **年检制度**：2014/45/EU，规定了机动车辆及其挂车的道路运行适宜性试验（年检）要求。
- **商用车辆路检**：2014/47/EU 和 (EU) 2017/2205，规定了商用车辆路边检验的规程。
- **行驶记录仪**：(EU) 165/2014，要求商用车辆安装数字式行驶记录仪，并具备与卫星导航系统的接口。
- **轮胎磨损**：89/459/EEC，要求M1、N1、O1、O2类车辆在用轮胎花纹深度不得少于1.6mm。

## 总结
欧盟汽车产品型式批准制度是一个**统一、完整且与国际接轨**的市场准入管理体系。其核心框架从2007/46/EC发展到(EU) 2018/858，趋势是**不断简化法规体系（采用ECE法规）、引入更高安全环保要求、并大幅加强市场监管和后期符合性监督**。对于汽车制造商而言，理解该制度及其最新的发展动态，特别是生产一致性控制、COC证书要求以及不断加严的市场监管，对于成功进入和保持在欧盟市场的运营至关重要。
