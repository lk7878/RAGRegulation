# 俄罗斯和海关同盟市场汽车产品准入管理和技术法规

## 1. 俄罗斯对汽车产品的市场准入管理制度

### 1.1 俄罗斯对车辆产品实施的 OTTC 认证
俄罗斯对汽车产品主要采取车辆型式批准模式，具体实施形式为 **OTTC认证**（Одобрение типа транспортного средства，整车车辆型式认证）。获取OTTC证书是车辆产品进入俄罗斯市场并获得车辆注册上牌的先决条件。

- **OTTC与GOST-R、ECE认证的关系**：
    - OTTC认证是俄罗斯专门针对汽车整车的型式批准制度，参照欧盟整车型式批准模式建立。
    - GOST-R认证是俄罗斯传统的产品认证，目前主要用于汽车零部件和系统。但由于俄罗斯绝大部分汽车零部件项目采用联合国ECE法规，因此企业通常直接进行ECE认证。
    - 在申请OTTC认证时，企业通常提交已有的ECE认证证书。对于少数ECE法规体系中没有的项目，可在OTTC认证过程中单独检测，或提前进行GOST-R认证。
    - 总体而言，GOST-R证书和OTTC证书的关系，类似于欧盟认证中的EEC/EU单项零部件指令批准证书和欧盟整车型式批准（WVTA）证书的关系。

- **对中国汽车的认证要求**：
    - 由于中国未加入联合国《1958年协定书》，俄罗斯认证机构不直接承认中国认证机构出具的相关证明。
    - 承认的认证途径包括：
 1.  样车在俄罗斯当地实验室按照俄罗斯法规进行试验。
 2.  在中国检测机构进行试验，但有俄方认证机构人员目击。
 3.  通过其他《1958年协定书》缔约国颁发的ECE法规认证结果。

- **OTTC认证申请所需文件**：
    1.  附函、保证函。
    2.  申请书、产品安全性声明申请。
    3.  质量管理体系证书或生产条件说明。
    4.  国际制造商代码（WMI）、产品分类代码。
    5.  技术条件、使用指南。
    6.  申请企业注册证、地址。
    7.  工厂测试或认证测试报告等。
    8.  已有的车辆ECE认证证书或GOST-R证书。

- **主管机构**：
    - **俄罗斯联邦技术法规和计量局**（Федеральное агентство по техническому регулированию и метрологии），隶属于俄罗斯联邦工业与贸易部。该局是联合国WP29框架下《1958年协定书》在俄罗斯的政府主管机关，负责颁发并承认其他缔约国颁发的ECE法规认证证书。

- **认证方式与现状**：
    - 中国汽车出口俄罗斯一般有三种方式：有效期3年的大认证、150辆以下的小批量认证、不需要认证的二手车出口。
    - 目前，俄罗斯针对中国汽车产品只签发3年期的OTTC证书，不签发1年期证书，并已停止小批量认证。

- **认证机构与实验室**：
    - 俄罗斯管理机关目前承认的认证机构有16个，批准的可从事整车认证检测的实验室有72家。只有经批准的机构出具的证书和报告才具有法律效力。

### 1.2 俄罗斯汽车产品认证程序
针对不同的车辆进口数量实行不同的管理机制。

#### 1.2.1 大批量数量车辆认证的基本程序
1.  申请方向认证机构递交申请，认证机构在15日内决定是否同意认证。
2.  同意后，申请方向实验室提供样车。
3.  实验室进行认证试验，通过后出具试验报告。
4.  认证机构根据试验报告决定发放**俄罗斯品质合格证书**（有效期不超过三年）或根据ECE法规发放《车辆结构型式正式确认通知书》。
5.  为领取最终的**车辆型式批准书**，申请方需再次申请。批准书有效期不超过三年，信息登记在国家统一注册清单中。只有获得此批准书，才能将进口车辆运入俄罗斯境内。
6.  俄罗斯认证系统必须承认其他《1958年协定书》缔约国颁发的、尚在生效的《关于车辆结构型式正式确认通知书》。

#### 1.2.2 小批量进口车辆的特殊认证程序
- 小批量进口车辆指一个日历年度内，运入俄罗斯境内的一个类别、一个型号车辆的规定数量。
- 针对小批量车辆的强制性技术要求比较宽松。
- 对所申请系列车辆发放的“车辆型式批准书”是证明车辆结构安全性的文件。

## 2. 海关联盟统一市场建立并实施统一产品认证批准制度
2010年，俄罗斯、白俄罗斯、哈萨克斯坦三国签署协议，建立关税同盟（后发展为欧亚经济联盟），实施统一的 **CU-TR认证**（常被称为 **EAC认证**）。

- **实施时间**：相关产品目录自2013年2月15日开始分批强制执行。
- **产品范围**：需要CU-TR认证的产品目录包括61类，其中与汽车相关的有“轮式车辆和配件”、“拖拉机机械和配件”等。
- **认证机构**：俄白哈三国国内具备条件的机构和实验室，经申请成为关税同盟授权的质量认证机构。
- **证书类型**：
    1.  **海关联盟符合性声明（CU-TR Declaration）**：由申请方在认证机构参与下进行自我符合性声明。强制性清单中90%以上产品需要此证书，持证人必须是国外客户。
    2.  **海关联盟合格证书（CU-TR Certificate）**：由海关联盟统一认证注册的认证机构和检测实验室签发，任何客户都可以申请。
- **证书有效期**：分为单批次、1年期、3年期、5年期证书。除单批次证书外，均需进行工厂审核。5年期证书要求最高，通常要求企业具备俄罗斯ISO9001认证证书。
- **认证标志**：EAC标志。
- **申请资料**：需提供俄文资料，包括申请表、产品描述、ISO9001证书、技术文件、测试报告、营业执照、供货合同等。**申请人必须是俄白哈三国境内的企业或企业家**，中国工厂作为制造商体现在证书上。
- **成员国发展**：亚美尼亚（2015年1月）和吉尔吉斯斯坦（2015年5月）相继加入，目前共有5个正式成员国。

## 3. 俄罗斯及海关联盟汽车技术法规体系和项目

### 3.1 俄罗斯和海关联盟统一市场主体汽车技术法规项目清单

### 3.2 对海关联盟的统一汽车主体技术法规 TP TC 018/2011 的相关说明
- **渊源**：TP TC 018/2011是在俄罗斯联邦政府第720号命令基础上发展而来，而720号命令参照了欧盟的2007/46/EC指令。
- **技术要求**：法规附件列出了整车应满足的整体要求和单项零部件/系统的技术法规要求。
    - **绝大部分项目直接采用ECE汽车技术法规**。
    - **少数ECE体系缺项**，则采用海关联盟自身的法规要求或俄罗斯/独联体的GOST标准，例如：
 - 车辆内部噪声
 - 乘员舱内空气质量
 - 车辆稳定性
 - 车辆前视野
 - 通风供暖及空调
 - 风挡玻璃除霜除雾系统
 - 风挡玻璃刮刷系统
 - 车轮护轮板防飞溅系统
 - 车辆重量限制
 - 残障人士使用车辆
- **标准应用示例**：
    - **护轮板和防飞溅系统**：采用俄罗斯标准 **GOST R 52853-2007**。
    - **风挡玻璃除霜除雾系统**：采用俄罗斯标准 **GOST R 52031-2003**。
    - **风挡玻璃刮刷系统**：采用俄罗斯标准 **GOST R 52032-2003**。
- **对欧盟法规的态度**：由于历史和政治原因，海关联盟一般不接受欧盟的技术法规和认证批准，但完全接受联合国的ECE汽车技术法规。

## 4. 俄罗斯车辆强制安装卫星定位和紧急呼叫系统相关法规和标准
俄罗斯及海关联盟市场强制要求车辆安装基于GLONASS卫星系统的**紧急呼叫系统（ERA-GLONASS）**。

- **实施时间表**：
    - **俄罗斯本国**：M2、M3及N类车辆自2013年1月1日起；M1类车辆自2014年1月1日起。
    - **海关联盟（三国）**：M1、>2.5吨的N1、M2、M3、运输危险品的N2/N3类车辆，新定型车自2014年10月1日起，所有在产车自2016年1月1日起。后扩展至所有M和N类新定型车自2015年1月1日起，所有在产车自2017年1月1日起。
- **核心法规**：**TP TC 018/2011的2013年1月修订本**。
- **配套标准体系**：包含大量GOST R和GOST标准，涉及技术要求、试验方法、数据传输协议等（详见原文表59、60、61）。
- **标准转化趋势**：俄罗斯正逐步将自身的GOST R标准转化为独联体统一的GOST标准（例如GOST R 54618-2011转化为GOST 33466-2015）。
- **联合国法规**：俄罗斯主导制定了联合国车辆e-call法规 **ECE R144**（车辆事故紧急呼叫系统）。
- **新增要求**：2018年，俄罗斯新发布三项GOST R标准（如GOST R 57483-2017），要求车载GLONASS系统具备报告车辆事故损毁情况的功能。
