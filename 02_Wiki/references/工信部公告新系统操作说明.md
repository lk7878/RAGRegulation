# 工信部公告新系统操作流程

## 概述
本文档为工信部公告新系统的内部操作流程说明，旨在结合工信部系统操作特点与内部CTMOP系统功能，并考虑新系统带来的工作量，明确操作流程与分工。

## 内部操作流程及分工

| 步骤 | 执行对象 | 操作内容 | 备注 |
| :--- | :--- | :--- | :--- |
| **需求沟通** | 销售 | 与企业沟通申报需求，初步收集申报数量、项目等信息 | |
| **方案提供** | 企业 | 填写线下EXCEL方案表，包括视同说明等统计表内容 | |
| **资料收集** | 审核组 | 过渡期间，负责收集企业提供的方案及视同报告等基础资料 | 过渡期间，由整车主检暂时代为进行收集 |
| **方案审核，修订** | 审核组 | 对企业提供的方案进行审定，提出修改意见，并由主检将更正方案反馈给企业 | 过渡期间，由整车主检暂时代为进行审查 |
| **任务下达** | 计划科 | 根据企业提供的方案表（可不含实测报告号的统计表及样车信息表），在CTMOP中下达任务（任务到部门，部门再进行分配） | 目前CTMOP只支持任务到部门 |
| **任务接收** | 检测部门 | 主检在CTMOP接收任务，并生成统计表号、报告号 | 主检在接收任务后，才生成统计表号和任务号 |
| **报告出具及审批** | 检测部门 | 各检测部门将报告上传到CTMOP中进行三级审批 | 所有部门报告传到CTMOP，也完成报告收集步骤 |
| **报告、资料发送** | 检测部门 | 整车主检将审批后的报告、视频、填充单报告任务，完整车报告号的最终版统计表、样车基本信息表、参数核查表、照片等，其他各类资料发送给计划科对应任务下达人员。 | 报告审批后，检测部门将经过审批的报告、视频均以车型命名后打包发送给计划科对应人员在公告系统中进行上传。 |
| **统计表创建、提交** | 计划科 | 将确定的统计表、样车基本信息表等信息录入装备中心网站 | |
| **报告上传** | 计划科 | 将收集的报告、视频文件等资料上传装备中心（不含单报告） | 主检需在场地系统同步申报 |
| **最终提交** | 审核组 | 利用管理员账号，在系统中进行最终审核，提交车型 | 过渡期间，暂由现行专家组进行最终的把关。账户由业务部管理，进行验证码分配。 |
| **资料存档** | 技术质量部 | 每批次完成后，对收集的视同报告、资料等进行统一汇总、存档 | |

## 说明
1.  **专职审核团队组建**：中心组建专职方案审核小组，成员由各部门抽调业务骨干6-7人（以入司2-5年，暂未取得主检资质的骨干为主）挂靠到计划科，计划科现有人员再选拔6-7人。共14人左右的专职团队，负责方案的对接、审核、统计表填写、提交等，人员由计划科统一管理。
2.  **过渡期间安排**：专职审核团队组建过渡期间（暂定3个批次），为保证方案审核及时性，暂由整车主检与企业进行方案对接、制定，并由现行14位专家组在装备中心系统中负责对最终方案审核和及时提交。目前的14位兼职审核专家，共用系统的管理员账户，按照既定的企业分配名单和区域分工进行方案的最终审定和提交。对于本部各部门单报告，由各部门主检所在对应部门及科室的审核专家进行审定。具体分工如下：
    *   整车（1科谢亚玲、2科褚观耀、3科陈雄）
    *   电子通信陈立东
    *   安全中心王东伟
    *   部件与材料廖梦楠
    *   动力测评张大志
    *   重排室及发排室崔连波
    *   轻排室及健康测评室胡君
    *   区域专家负责区域内报告。
    *   动态验证码暂时由业务部进行分配，需要登录时，进行点对点发送。
3.  **资料规范要求**：各类表单、文件、视频、照片等提供者，均需严格按照规范填写，规范命名，保证上传时能被系统正确识别（要求见系统数据提供要求说明）。
4.  **报告出具安排**：所有部门报告出具、传递必须做好安排，不能在最后关头集中出具报告、上传资料，避免系统、操作人员工作量拥堵。
5.  **区域中心参照执行**：各区域中心，参照流程自行进行内部职责分工（企业对接、任务下达、统计表创建、报告等资料上传、最终方案提交等内容）。
6.  **账户权限管理**：新公告系统的人员账户、权限开通由综合部进行统一管理。
7.  **资料存档管理**：技术部负责统筹安排申报过程资料、视同报告的统一存档管理。
8.  **高峰期动态调整**：申报高峰期，根据系统及操作情况再进行动态调整，如有必要，由各部门认领企业，协同进行系统操作。
