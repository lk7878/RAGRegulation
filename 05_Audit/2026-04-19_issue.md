### 模板安全问题

当前 `02_Schema/templates/audit.md` 的问题：
- `tp.file.move()` 会移动**当前活动文件**
- 当 Templater 以 "Create new note from template" 模式调用时本应安全（新文件已创建并激活），但在某些场景下（时序问题或特定 Obsidian/Templater 版本），它可能移动原激活文件

**修复方案**（待用户确认是否立即改）：
在 `tp.file.move()` 前加入防护：
```javascript
const currentFile = app.workspace.getActiveFile();
if (currentFile && !currentFile.name.startsWith("Untitled")) {
    new Notice("Template aborted: active file is not a new untitled note. This would overwrite your file.");
    return;
}
```

这样如果用户在任何已有文件上按 Alt+N，模板会直接退出而非破坏数据。
